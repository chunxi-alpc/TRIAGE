# CARE 模块一 V4：历史实验

[实验索引](../README.md) · [当前模块一 V6](../../src/module1/README.md) · [V5 后续](../care_module1_v5/README.md)

本目录保留 2026-10-18 的 Qwen3-8B 证据修复实验。V4 属于历史比较，当前模块一入口使用 V6。

## 主要入口

| 文件 | 内容 |
| --- | --- |
| [原报告](REPORT.zh.txt) | 三组比较、结果、错误和限制 |
| [原运行说明](README.zh.txt) | 环境、公开结果复算和服务器原始输入 |
| [冻结协议](PROTOCOL.zh.txt) | 预先设定的比较、指标与记录要求 |
| [指标](data/metrics.json) | 192 条样本的保存结果 |
| [逐例预测](data/model/predictions.jsonl) | 各方法的判定与证据记录 |
| [复现入口](reproduce.py) | 公开指标复算与可选的有权源数据重建 |
| [冻结清单](FREEZE.json) · [公开文件校验](PUBLIC_SHA256.json) | 输入、代码与公开交付文件的来源核验 |

实验含 16 条规则、32 条完整来源病例及控制修改，共 192 条样本。完整结构化方案判定正确 140/192，直接判定为 136/192。相对于结构化但不核对证据的方案，完整方案纠正 21 条判定，同时新增 21 条错误。判定与证据同时正确为 93/192，已知样本证据定位为 68/137。结果只支持局部改善，未证明判定与证据可靠性同时稳定提高。依据见 [原报告](REPORT.zh.txt)。

原始完整病例及含受限原文的模型输出保留在服务器。删减后的引用不能用于重新进行证据核对；公开预测可用于复算原指标。详细复现条件及数据边界以 [原运行说明](README.zh.txt) 为准。
