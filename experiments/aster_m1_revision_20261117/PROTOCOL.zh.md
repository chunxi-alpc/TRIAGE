# 自适应 M1 修订：按反对称配对效应选择预测特征

## 状态与范围

本修订基于 `2558da64513bcbc74b224d63aedda1e66c3d9dfb`。原实验、结果、主稿及默认入口均不修改。本分支已实现服务器准备、统一队列入口、特征提取、配对修补、M2/M3、四种预测及固定敏感性分析。实际完成状态以 reports/aster_m1_revision_20261117/ 的逐模型记录为准。

原始版本有32项CPU测试。新增共同模式及数值校正回归测试，实际服务器测试记录另存于 reports/aster_m1_revision_20261117/。训练入口的模拟连通测试作为软件验证记录。真实模型由服务器既有统一队列运行。

沿用此前取消性能置信区间和固定51头重跑的范围。新增原模型、独立截距、修正不加截距、完整修正四个点估计对照。原模型和独立截距须在同一输入、评分和检查点下比较。本文只调整M1，不同时更换M2或M3。

## 1. 审计结论

原始计算未被证明算错，但筛选统计量与研究目标不对应。

1. 初筛置换梯度与激活差的来源对应关系，检验的是来源特异的对应关系，不是该头对指定反事实干预是否有效。即使一个头在线性模型中真实影响分数，若其梯度跨来源相同，则全部置换统计量都等于观测值，置换p值为1。该反例已加入回归测试。
2. 确认阶段要求同一病例的受控变化超过不同指南来源的随机激活替换。后者同时可能改变患者、条件、标签方向和表示距离，不是“没有当前干扰效应”的有效零干预。其效应更大不能反证真实配对无效；跨来源供体仅可保留为扰动压力诊断。
3. 原绝对修补幅度可用于衡量响应大小，但不能确认C/F标签对齐的证据方向。修订后同时保存大小和方向，允许反向响应头被选为预测特征；不将其描述为有益证据头。
4. 要求干扰头集合与证据头集合同时非空，附加了后续M2/M3并不要求的功能分组条件。非空并集即可构造共同特征；各类标签只描述当前干预响应，不表示功能独立。
5. 空集合之间的Jaccard为1不证明机制稳定。后续此类相似度应记为不适用，并另报非空率。来源数不足、统计量不支持、缓存失败、特征零秩和模型无收益必须分别记录。

BY校正本身不是实现错误。本修订不通过把BY换为BH、增大q值、扩大供体数量或挑选有头的配置来制造成功。

## 2. 修订后的科学问题

主问题是：**从训练数据选择对指定配对变化有响应的表示特征后，受约束读出能否在未参与当前拟合的来源上降低A/P分数波动，同时控制C/F修正，并相对独立截距增加任务效用？**

“找到统计显著的纯干扰头/纯证据头”属于另外的机制假设，不再作为预测模型运行的必要条件。自身替换只是数值控制，不是语义零假设。新选择器没有逐头FDR保证，不声称得到纯功能模块。

## 3. 冻结的数据与方法

保留2,540对训练数据、80/20/40来源划分。80个训练来源按固定种子20261117分为40个候选筛选来源和40个精确修补来源；两个集合不重叠。每个阶段每类至少16个来源，不能从开发或测试来源补齐。M2/M3及自然节点截距仍只使用全部80个训练来源。

开发20来源仅评价修订后完整流程并定位工程问题。由于此前已用于方法开发，不能称为全新独立验证。40来源是历史复用留出集，不自动恢复为未接触测试集。本修订属于看到旧负结果后的探索性设计，所有修改需记录，不能追溯性地宣称预注册。

主流程使用所有纳入来源的配对，先在来源内平均，再在来源间平均。不能让配对多的来源支配选头，也不再只取字典序第一个配对。

### 3.1 双端梯度候选筛选

对每个头h与配对j：

```math
G_{j,h}=\frac12\bigl(|\langle a_h^R-a_h^L,g_h^L\rangle|+|\langle a_h^R-a_h^L,g_h^R\rangle|\bigr).
```

按来源平衡聚合。每类保留累计归因分数达到95%的最小排序前缀，边界并列全部保留。该规则自动决定候选数，不固定51头，也不使用跨来源梯度置换p值。95%是新冻结的工程超参数，不是置信水平。

必须具有两端梯度。旧缓存只保存部分左端梯度时，先导出缺失输入清单，在新目录补提取；禁止把右端梯度填零或静默退化为单端。注意力头编号仅在同一检查点内有效。

### 3.2 配对内精确修补及自身替换

在独立的训练确认来源上，对每个候选头保存四个模型前向结果：左端接受右端激活、右端接受左端激活，以及左右两端各自接受自身激活。另复算未干预分数，与旧缓存对齐。

```math
I^f_{j,h}=\ell(x_j^L;a_h\leftarrow a_h^R)-\ell_0(x_j^L),\quad
I^r_{j,h}=\ell(x_j^R;a_h\leftarrow a_h^L)-\ell_0(x_j^R).
```

定义 u_L=ell(L←R)-ell(L←L)、u_R=ell(R←L)-ell(R←R)，c=(u_L-u_R)/2。选头幅度为 m=max(abs(c)-(e_L+e_R+t_L+t_R)/2,0)。共同模式 (u_L+u_R)/2 和两侧绝对效应均单独保存作诊断，排序只使用 m。自身替换误差超过 `1e-4 + 1e-5*|原分数|` 时停止并记录工程失败，不根据选头数量放宽容差。这些容差是数值验收设置，尚须在真实运行中通过检查。

同时记录：

```math
c_{j,h}=\tfrac12[(\ell_{L\leftarrow R}-\ell_{L\leftarrow L})-(\ell_{R\leftarrow L}-\ell_{R\leftarrow R})],\quad
r^{CF}_{j,h}=(y_j^R-y_j^L)c_{j,h}.
```

有向统计量区分正向与反向响应；经数值校正的 abs(c) 用于预测特征筛选。对称式能在交换配对端点时保持标签对齐量不变。不能把负方向删掉后宣称证据响应均为正向。

### 3.3 自适应最终集合

按确认来源平衡聚合数值有效幅度，每类保留累计分数达到90%的排序前缀，边界并列全部保留。取四类并集作为共同头集合，允许重叠。累计“质量”只指该非负排序分数之和；头间存在交互，不能解释为保留90%的总因果效应。

保留比例90%也是工程超参数，不是新颖性或有效性的证明。80%和95%可作为预先固定的敏感性分析，使用同一批精确修补记录，并完整报告；不能选择测试结果最好的比例替换90%主配置。

不要求干扰集合和证据集合分别非空。并集为空，或者后续M2投影秩为零时，标记“仅截距回退”，不补足头数，不宣称自适应成功。若实际缓存或数据不足，应报失败，而不是当成零效应。

### 3.4 固定后续模块

继续使用原E1的低维M2（秩上限16）、M3逐对硬预算0.2923349、正则0.01和仅训练自然节点的截距校准。新入口调用原 `training._m2` 与 `training.refit_m3`。不引入完整正交补、无硬预算M3或正斜率校准。需要研究那些版本时单独立项，避免多个模块变化后无法归因。

## 4. 不再把随机供体用作必须超过的门槛

跨来源随机替换仅列为压力诊断，不决定新M1是否运行。额外的匹配供体诊断须先约定研究目标，再匹配指南来源、当前节点、患者决定性事实、配对类别、端点标签和激活位移尺度。仅“同来源”仍不充分；缺少匹配供体时报告覆盖不足，不能自动换用跨来源供体。真实反事实配对本身也须接受语义审核，代码的标签检查不能替代医学审核。

## 5. 执行与验收

先完成Qwen单模型：CPU预检与缺失梯度清单 → 数值冒烟 → M1/M2/M3 → 开发点估计 → 冻结 → 复用留出评价。完成一个有效的全流程（正或负结果均可）且工程验收通过后，才扩展其余六个检查点；不能按Qwen是否显著变好来选择是否报告其他模型。

所有候选头都须完整修补。默认预检上限200,000次确认前向（包括自身替换和未干预复算）。超额时只记录资源阻断，不截断头、不复用不完整结果，不自动启动任务。可在运行前单独批准更高资源上限；这不是统计阈值。

旧原始激活和分数只有在模型权重、分词器、输入、模板、答案词元及评分代码指纹一致时才可复用。旧随机供体效应、旧显著性、旧选头结果及其下游参数不能充当新M1结果。新增自身替换及缺失梯度须真实计算。新代码不自动访问旧真实/随机修补缓存。

主评价同时报告A/P RMS与中心化方差降低率；C/F修正RMS、有向响应、方向退化、超原预算比例及分位数；自然/干扰路径正确数与纠正/新增错误数。原模型和独立截距必须保留。均为点估计，不自动生成性能置信区间，不新增固定51头重跑。

独立运行目录保存协议哈希、来源清单、候选、全部配对修补、M1/M2/M3参数和失败信息。禁止覆盖原报告；中断后的记录保留，中断后需检查阶段产物，显式 --resume 才可续跑；先重验检查点与输入身份，复用本轮完整提取记录和完整配对修补文件。

## 7. 报告与论文措辞

原实验应保留为：“所测试的来源置换与跨来源随机供体超额效应筛选，未形成完整运行所需集合；该结果不检验一般意义上的干扰相关表示是否存在。”

本修订尚不能写成有效方法结果。新结果产生后，方法、实现与表格必须对应同一协议。即使选出了更多头，也只说明工程选择器产生了特征，不自动说明干扰消减、证据保护或任务效用改善。

参考方法学：Zhang & Nanda, *Towards Best Practices of Activation Patching in Language Models: Metrics and Methods*, ICLR 2024；Heimersheim & Nanda, *How to use and interpret activation patching*, 2024。这两项工作支持谨慎区分干预方式和解释范围，并不验证本文提出的95%/90%规则。
