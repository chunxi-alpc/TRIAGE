分析指标：

- 阈值遵循：同一顺序下，原阈值与新阈值两个答案都符合各自金标，才算正确翻转。每例两对，最多 88 对；它们不是 88 个独立患者。
- 顺序影响：同一阈值下交换规则顺序后答案改变。每例两对，最多 88 对。
- 病例四格模式互斥分类：四格都遵循金标；四格固定同一有效动作；四格都选物理第一条；四格都选物理最后一条；解析失败；其他混合模式。
- 固定动作中另查是否等于原闭卷答案、原金标或新金标。闭卷一致性是行为证据，不证明模型内部机制；PR24 闭卷 SDPA 与当前 eager 的实现差异保留。

所有 44 例来自 nscl_3，且筛选了两目标分支已召回的子集；结果用于区分阈值、位置和固定动作偏好，不能外推为完整 84 例或其他疾病的总体效果。
