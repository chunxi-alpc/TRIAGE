# 给老师的阶段汇报：真实注意力干预与结构修复

老师，这轮已在原服务器完成 Qwen3-4B-Base 的真实 GPU 实验：96 例开发集扫描、192 例固定设置评估、反向及错配对照、三种键编辑方法，以及自动结构修复。全部病例、未知状态和无操作均保留。

**结论：已经验证注意力分数和实际分配能够被改变，但还没有建立“正确适用结构通过注意力干预稳定改善决策”的完整证据。当前最明确的收益来自结构接口修复和结构提示。**

- 192 例中，原始基线 **71/192、主要配对 0/24**；仅参考结构提示 **160/192、15/24**。动作双向干预为 **73/192、0/24**，与结构提示组合为 **161/192、15/24**。
- 同时增强患者证据的最佳开发集配置，在评估集达到 **77/192**，纠正 6 例、破坏 0 例，但主要配对仍 **0/24**。符号反转回到 71/192；规则状态错配后仍为 **77/192**，因此不能把提升归因于正确的规则状态。错配对照保留原证据增强，尚未分离证据增强本身的作用。
- 查询对齐键编辑确实实现了接近目标的分数改变，但为 **73/192**；学习均值方向与随机方向均 **72/192**，主要配对均 0/24，未显示学习方向优势。
- 修复排除条件标签含义、恢复完整缓存输出并补跑 17 个缺失请求后，规则状态正确率从 **68.06% 升至 97.22%**。修复结构仅作提示为 **158/192、14/24**，加动作干预为 **159/192、14/24**；直接执行修复后的规则反而达到 **177/192、20/24**。

本轮最值得保留的是结构修复。在这个合成路由任务上，直接规则执行已优于再次交给大模型选择分支；目前结果不支持继续以学习方向必然有效为前提扩展。单例零强度近似检查的 BF16 候选分数最大差为 0.125，小幅增益也须谨慎解释。

以上均为实际 GPU 输出；数据已经使用过，结果属于探索性机制实验，不是独立临床确证。逐例预测、注意力变化、参数、错误分析和复现命令均随新草稿 PR 保存。
