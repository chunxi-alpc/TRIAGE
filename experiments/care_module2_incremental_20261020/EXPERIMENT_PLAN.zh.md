# CARE 模块二增量实验：N1–N5 科学协议 V2

日期：2026-10-20。**仅对应过去未充分验证的研究问题。** 历史方法已经做过的旧数据实验一律不重复；本文件不是新的模型结果报告。

## 总命题与四个证据层级

希望学习一个不添加事实知识、不改基座权重、接受低维外部选择指令的接口。记输入文本为 x，模型为 f，算子为 `I(z; layer, position, beta)`，z 是来源、可决断或规则适用性等**控制选择**，而不是目标答案。

四种证据必须分开：

- L0 **算子确实执行**：匹配层头词元位置、非零差值、零操作恒等、RoPE/GQA/精度检查。
- L1 **语义因果性**：同一接收输入上，施加不同控制改变预定语义目标；跨内容供体和非目标控制排除抄答案、长度/位置和泛化伪差。
- L2 **复杂方法增量价值**：相同控制信息、干预预算、训练/开发选择规则下，优于简单文本策略、确定性执行、直接 attention-score bias 或相应不训练空间。
- L3 **真实上游链路**：使用固定 A1 预测信号，处理 T/F/U/技术失败与错误传播后仍取得 L2 所见收益；oracle 只能给出机制上界。

每项均可以得到负结果；L0、probe AUROC、向量可解码性或谱特征均不能推出 L1–L3。

## 阶段 S0：先构建答案真值与数据隔离（CPU）

旧本地 `CARE_module2_A1_preexperiments.zip` 的 600 条样例包括 routing 120、relevance 48、source 120、determinacy 120、joint 192。它们能作为操作/解析开发夹具，但当前 24 个主题主要覆盖有限的底层规则语法；`joint` 还没有独立的 A=T/F 因素。不得直接采用其既有 test 子集作为独立机制确认。

要先做独立的**可执行 truth oracle**，覆盖规则 A 适用性、问题 R 相关性、来源政策 C/P、信息是否充分 D/Q、合法动作及追问属性集合。答案由结构化规则求值；**不得从待测模型预测或学习算子产生 gold**。

实验数据两个层级：

1. **探索开发轨：** 可复用/修订旧 24 主题及其 12/4/8 train/dev/test 草案，但强制按真实底层逻辑族复查。如原模板共用同一个逻辑结构，则并非独立家族。已看过旧合成结果的不应标为确认集。
2. **真正留出机制轨：** 新建且冻结至少 24 个跨不同底层逻辑结构的家族；规则运算与组合不同，不是只换主题名/数值。按可证明的基础逻辑家族和事实簇分组，先冻结再划分；建议 12 train / 4 dev / 8 test，数量和独立性审计不过关时缩小结论范围，不靠后验补例提高显著性。

同一基础患者事实、属性重述、逻辑同构式、来源事实组、成对反事实和候选重排必须进入同一 partition。全面保存 `family_id`、`underlying_mechanism_id`、`root_case_id`、`pair_id`、`fact_group_id`、`split`。

**数据写入防泄漏：** 给模型的 prompt 仅是当前输入和必要的外部可见控制，评测答案、目标来源 gold、oracle decision/route 和隐藏组号仅保存在 scorer；控制组的 gold z 只能进入单独标识为 oracle 的 intervention，不能写到模型提示或训练集以外的拟合样本。任何筛样/标签转化的依据都要在实验日志显示。

## N1：规则相关性 R × 适用性 A 的独立选择

**缺口：** PR #3/#8 和历史 O2 很大程度聚焦 A，不能证明针对任务查询的 R 与规则事实适用 A 可正交、可因果地区分。

对每个基本规则构建四格 `(R,A) = (+,+),(+,-),(-,+),(-,-)`。同一患者/规则中，R 通过任务问题改变，A 通过决定性患者事实改变；确保两种操作都不会隐含改变第三个因素（如动作合法性、证据措辞），并经 oracle 逐格验证。至少包括真、假、关键例外、析取分支、数量阈值、无关属性、顺序置换，以及不同动作长度。为了避免仅靠虚构表面词识别标签，测试须有结构性不同的家族。

训练：从 train 成对反事实激活拟合 `U_R`、`U_A`（同层同位置时检查基底重合/秩退化）、单轴质心差和谱混合 `Cov_mix(λ)=λ Cov_R/tr(Cov_R)+(1-λ)Cov_A/tr(Cov_A)`，λ 只能在 dev 选择。PCA/协方差必须记录中心化、是否按家族平衡、取样权重、差分符号，防止将随机差分翻号误当有效随机投影对照。

新测试方法（相同新数据）：

- 无干预。
- 显式 R/A 策略或结构提示；若 oracle 结构作为辅助，标为 oracle-only。
- 同控制信息的直接 score bias（固定目标 query/head/token，dev 独立公平选强度）。
- R-only、A-only、R+A/谱混合投影；适用性符号必须明确。
- 符号错配、规则错配、位置错配、强度匹配随机轴和独立成对重新配对轴。
- 确定性正确规则执行的上界，但不与预测系统混为一个可部署方法。

**主要单位：** 完整四格 family block。主指标为四格均正确比例；次指标逐格准确率、误选不适用动作、误选无关动作、原正确非目标损伤、实际受编辑 causal score 的均方根与符号。算法不仅要改善目标，还要在 `R−A+` 中避免把“适用”误当“相关”。

**明确排除：** 不重跑原 384 例的 B1–B4、旧三随机种子或同一键替换的统计网格。

**失败门槛：** 在新训练/开发设置里无法独立操纵 R/A，或学到的轴无法在新逻辑家族里超越直接 bias，就停止 N1 的大规模头/秩搜索，完整报告负结果。

## N2：来源 C/P 的双向选择与跨内容交换

**缺口：** PR #10 已完成 8B 上下文冲突及一个均值残差方向的真实 GPU 测试，但没有证明固定 4B 上同一中性输入经一个外部低维控制即可双向选来源，更没有严格跨内容 IIA。

定义 C 为当前有来源的上下文片段，P 为当前模型可能已具备的事实知识。要区分两条轨道：

- **N2-mechanism：** 受控的虚构事实或显式前文 prior，仅用于低维控制及供体复制的内部因果诊断；**不能称为真正参数知识 P**。
- **N2-knowledge：** 经无选项、不同问法、不同答案呈现方式（如候选换序）在固定 4B 上独立验证的稳定已知事实；仅此轨可以作“上下文与参数知识竞争”主张。数据源有固定版本和时间戳，排除题干与候选泄漏；历史 PR #10 结果不能替代 4B 的能力检查。

对每个可行接收实例提供中性完整提示 `x`（含与已知事实矛盾的 C），不写“遵循 C/遵循 P”。运行 `I_C(x)`、`I_P(x)` 两次；**接收文本、候选和查询保持不变**。目标 gold_C 来自接收实例 C，gold_P 来自接收实例闭卷事实；事实必须不同且均明确。训练政策可在 train 中有 C/P 明示文案以提取方向，但测试的政策比特由外部 intervention 输入，不能把答案注入 z。

最少对照：中性无干预、同一比特的显式 C/P 文本政策、train 来源均值残差方向、低秩投影/坐标替换、残差随机方向、可定义时直接 context-token attention bias、无信息扰动。文本控制改变 token 长度，因此不能冒充同输入神经干预；在“给模型相同来源选择信息”层面比较任务效益，并单列直接内容恒定对照。

**核心 IIA：** 接收者和供体事实主题、答案必须可不同；对 train 和 test 不同事实组的 donor，传递指定轴/子空间坐标，其余接收激活尽量保留；报告同题同标签、跨题同标签、跨题反标签、随机供体和答案相同/不同的分层。评分始终用**接收者**的两种 gold，额外监测答案向供体正确选项漂移，以隔离内容复制而非政策切换。

**主要指标：** 同一个接收实例 C 和 P 两次均答对率；报告每一向成功率、中性上下文误采纳率、closed-book 稳定性、供体答案复制率和跨事实组迁移。不能以任一单向提升代替双向仲裁。

**能力门槛：** 先统计在无选项/换序下稳定已知的独立事实组及题材。若严格已知组不足以支撑按组迁移分析（预期至少 8 个独立事实组且覆盖至少 4 种内容领域），主结果降级为有限机制分析，不再宣称真实 P 控制，也不根据测试失败反向寻找容易的 test 事实补集。

**失败门槛：** 无法在相同接收 x 上双向控制、只复制 donor 答案，或显式来源策略明显更有效，则不扩大来源空间搜索。

## N3：决策充分性 D/Q 的独立机制

**缺口：** 过去 A1 或 V6/V7 的 U（某规则适用性未知）不是全局决策是否必须追问。一个条件未知，结论可能依然唯一；模型若对一切 unknown 都追问，属于错误机制。

用**合法补全 oracle**定义真值。已知信息固定，对所有符合规则约束的未知属性赋值，得到可能合法动作集合 `S(x)`：

- `D` 当且仅当 `|S(x)|=1`，模型应该执行唯一动作。
- `Q` 当且仅当 `|S(x)|>1`，模型应该询问能减少不确定性的决定性属性。不存在可区分的补全时应报告定义错误，不凭语言直觉设 Q。
- Q 的真值是一个或多个**可接受的、对决定有信息增益的属性**；不强迫唯一措辞，必要时记录最小属性集和询问顺序。

每个不同逻辑机制产生：全已知 T/F、关键未知、无关未知、未知但由已知 OR/例外决定、多个未知和多规则优先级等条件。做最小对比，保持答案选项/长度平衡，确保“unknown”词面在 D 和 Q 中都有。

方法：无干预、中性及明确追问政策、简单任意-未知-就追问启发式、独立可执行规则补全 oracle 上界、train 配对残差均值轴、低秩 D/Q 坐标操作、匹配随机方向。测试政策 bit 的获得必须区分 oracle 诊断与真实可预测信号。

**主要指标：** 家族平衡 D/Q 策略正确率（D 输出动作，Q 正确追问）；**安全护栏**：Q 误直接决定率、D 不必要追问率、追问决定性属性命中率和补充答案后最终动作正确率，逐指标报告而不能用平均掩盖过度追问。

**失败门槛：** 只能把所有未知输入推向追问、不能区分 D/Q，或不优于显式规则判断流程，则 N3 保留为负结果，不在联合阶段宣称轴有效。

## N4：C/P × D/Q × A=T/F × 规则顺序的可组合性

**缺口：** PR #9/#11 的旧结构与注意力联用并没有检验 C/P、D/Q、适用性与顺序的四因素可组合性；N4 只在 N2/N3 轴的单项机制确实通过之后正式运行。

造出 **2×2×2×2=16 条件**的基本机制块：来源政策 C/P、决策充分性 D/Q、目标规则适用 T/F、规则顺序原序/反序。每个组合必须逻辑自洽且能由 oracle 计算独立目标答案；不能为了填满 16 格把 Q 情况的“应追问”误设为具体动作。若单机制不能生成完整合法块，在拆分前删除该机制并记录原因，不许基于 test 表现删格。

冻结 N2、N3 的各自训练参数，并冻结经 N1 选定的规则控制；如果 N1 失败，则使用简易 score bias 作为规则控制，注明失败组件。联合评测不重调单轴参数，不把读到的测试效果反馈到各轴。

比较：各轴单独，双轴叠加与顺序互换、全部轴组合，以及简单的显式流程 **“先判断 Q/D，再选择来源，最后执行适用规则”**（对照有相同选择信息；oracle 真值版本仅作为上界）。报告阶段消融、非目标动作的串扰和非法确定答案。

**主要指标：** 16 条件完整块正确率；辅助逐格准确、无关规则损伤、组合不交换性及 source/decidability cross-talk。投影在几何上正交不是语义可组合性的证据。

**失败门槛：** 如果 N2 或 N3 单轴无有效语义作用，则停止正式联合 GPU 网格，仅可作小型可观测性诊断，不得将其作为二维接口成功结论。

## N5：冻结语义 A1 预测驱动的下游迁移

**缺口：** PR #12 已有冻结 A1 和 24 例 Qwen 对比（10/15/10/15），但尚未在更多可连接真实 A1 预测的病例中，对新的路由接口、直接 bias、同信息量文本提示作公平比较。

只引用 A1 冻结输出，不允许任何 A1 调参或重训。候选来自 PR #12 原 `new72`/历史输出，按原始 `case_id + rule_id + 患者文本哈希 + 规则哈希 + A1 方法版本` 连接。原 24 例旧四臂只读，不重复相同前向；新的 Qwen 评测仅对**此前没有该新方法同输入结果**且能定义合法下游任务/动作的病例执行。

真实可得信号：T=+1、F=−1、U=0、技术失败=null；保留每个母集病例和无有效信号计数。遵守 `configs/care_module1_for_module2.json` eligibility，不能按参考 gold、A1 正误或模型是否被干预纠正选样本。主政策必须保持一致：预测 T/F 有动作才可定位并干预；U/失败作为无信号/不可用记录，不擅自变成来源 C/P 或追问 Q。

主要同输入方法：无干预、A1 明示文本状态、A1 规则过滤、A1 直接 score bias、A1 低维路由。oracle 状态下的同法仅报告机制上界，显式声明不是可部署链路。所有方法使用同一可观测 A1 状态，不把 oracle 标签混入 prompt 或 projection selector。

**主要指标：** 在同一预先定义评测集合上，A1 低维路由对“同 A1 信号直接 bias”的配对增量；也报告对文本状态提示的增量、病例及配对正确率、原正确保持、错误 T→误导动作、覆盖率、纠正/损坏及 A1 正误分层（仅事后诊断）。若有效病例不具备动作或合法答案 gold，标记 blocked 而非补造任务答案。

**解释边界：** 旧 A1 例已经用于开发/回归，故是固定预测的迁移探索；不得称为独立临床验证。若需要全新上游输入，单列未来工作，须另外批准固定 A1 单次推理，**不包括在本任务**。

## 对所有阶段共同适用

数据、模型和算子前向采用一份冻结 manifest；缓存以 `model_sha + tokenizer_sha + full_prompt_hash + intervention_spec_hash` 唯一化。旧权重与推理实现优先复用 PR #8/#11，但不重跑旧结果。Python 环境与 GPU 型号通过运行时记录，不预设可用。

每次实验必须生成每例日志：输入/输出 SHA、split/family/root IDs、模型 revision、控制信号的来源（train/dev-derived、frozen_A1、oracle）、层头 token spans、干预几何/校准误差、原候选 logits/最终答案、失败码、所用 seed 和消耗前向次数。日志中不得带私密凭据。

所有阶段先运行 CPU 真值测试及有限的模型 hook smoke；只有阶段门槛通过才投入该阶段的正式新前向。每项都以**负结果可复现**为允许的成功交付，不继续过度网格探索。
