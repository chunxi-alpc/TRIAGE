伤害＝原答案正确而新方法错误的条数/全部记录；这是答题退化，不是临床伤害。完整 JSON 另列相对原答对样本的退化率。覆盖率＝启用方法的比例，另报动作到选项的映射覆盖率。孤儿选项保留原注意力；直接映射的孤儿选项质量为零，融合仍保留原答案概率。

所有条件判断来自本次真实 GPU 调用；完全相同的条件输入在本次运行内缓存，缓存键和使用情况逐例记录。选项、病例、条件和规则集合统一；动作裁剪仅将非胜出动作文本替为固定占位符，保留条件及完整选项。旧分支门控仍按原规则级 max 方式，作为明确的历史对照。

限制：单随机种子；10 个开发树；只评分答案字母，未进行长文本生成；不共享跨配置 KV 缓存；未运行独立测试。树区间未作多重比较校正。实际成本按 GPU 小时列出，未假定货币单价。
