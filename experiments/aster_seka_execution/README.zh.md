## 已核验的结果

* PR33/35逐例与351个候选的只读复算通过；原失败记录保留。既有最强概率融合后，注意力增益不稳定，不能据旧结果宣称有效。
* SEKA原作者实现和两个Qwen检查点已实际运行。现有Qwen3-8B与论文Qwen3-8B-Base分别记录，投影不混用。Base的5份权重和分词器已对照固定官方对象验证。
* 原作者合成文件实际100行配对、200个三元组，完整传统投影600次前向。Qwen3-8B及Base的投影和来源核验通过。目录历史名称full200中的200是请求上限，不是实际配对数。
* Qwen3-8B、CounterFact官方5000:10000：SEKA efficacy 98.02%，匹配零强度51.50%，无干预51.50%，PASTA适配版82.20%。每例数值与官方指标已独立复算。SEKA对零强度纠正2332、退化6；按4885个实体分组bootstrap的差值95%区间[45.15,47.93]个百分点。这是标准集上下文服从能力，不能解释为临床准确率。
* PASTA使用SEKA作者提供的Qwen移植和KV相关头选择，不是原始PASTA完整头搜索。CAD为实现适配，Spotlight为论文重实现；两者16例GPU检查已完成，独立审计继续进行。
* AdaSEKA四专家已构建并核验，完整CounterFact默认参数对照正在运行；论文强度3另列计划。原官方FP32实现显存不足；存储优化在首个合格三元组上经4次前向验证，选定层标量、所有key及logits逐位一致。原OOM记录保留。官方无效专家头的均匀回退行为须单独披露。
