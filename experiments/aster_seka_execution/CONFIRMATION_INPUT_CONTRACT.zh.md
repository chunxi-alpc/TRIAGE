# 正式评测输入接口

confirmation_contract.py提供方法/源文件/模型与投影/五类种子域的冻结检查，要求实际开发评分和功效分析证据；不是额外用户批准流程。mega_confirmation_reader.py只在冻结后读取完整7458条原生测试输入，标签和参考路径不进入MethodInput。

服务器5项合成测试通过，覆盖7458条虚构记录、440个虚构指南组、冻结前不读文件、指纹变化拒绝及标签隔离。没有执行真实外部测试，也没有创建正式冻结。后续仍需将最终选定的生成方法接入该输入接口，并完成MedPIC冻结绑定及所有正式推理；不能把接口检查当成整条正式评测链路已完成。
