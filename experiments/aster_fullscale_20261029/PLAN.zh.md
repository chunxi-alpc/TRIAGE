# ASTER 全量临床指南忠实性实验计划

版本：2026-10-29。此目录是新实验规划，不覆盖历史结果。本提交不启动 GPU 全量推理。

## 数据与分工

**MEGA-CDP 主实验**
- 官方 train_val 登记规模：34,895 个病例、1,834 棵决策树。
- 官方测试集登记规模：7,458 个病例、440 棵决策树。
- 按决策树/指南簇将 train_val 分为拟合 70%、选择 15%、内部确认 15%。同一树下的病例、反事实变体和最小对必须留在同一分区。
- 模块一（ASTER 定义：学习适用性方向/子空间）只使用拟合分区中通过逻辑与语义核验的金标最小对。模块二（处置盲适用性判断）的阈值与路由规则只在拟合/选择分区确定。官方测试集在所有参数冻结前不得查看结果。
- 内部确认集用于流程诊断；官方测试集才是主结果。

**MedGUIDE 外部验证**
- 原始数据 7,747 个病例、55 棵来源指南树；已有反事实构造器报告 3,645 个候选病例满足当前 A/B/C 构造条件。
- 按来源指南树分为开发 60%、验证 20%、外部留出 20%。这是从原始 train split 内部建立的来源树留出，不是官方测试集。
- 必须检查 MedGUIDE 与 MEGA-CDP 的指南来源、规范化文本及病例/路径指纹重叠。发现同源指南时，重叠样本单独标记，不宣称独立外部验证。
- A/B/C 是受控反事实任务，不自动等于真实临床金标；原始 MCQA 和合成反事实结果分开报告。

## 分母和纳入规则

1. 报告原始分母、每一层筛选后的分母和明确排除原因。
2. 不因模型答错、拒答、格式错误、模块一预测 U/NONE、技术失败或干预无效而删除有效样本。
3. 模块一无信号、模块二弃权、模块三不可达和技术失败分别计数。端到端主分析保留所有有效病例，并按预注册规则计分；覆盖子集分析只能作为补充。
4. 模块一的学习分母是通过独立核验、能构造正负最小对且词元对齐成功的最小对数，不是原始病例数。逐级报告原始病例、可构造病例、语义/逻辑核验通过的最小对、词元对齐成功的最小对。
5. 最小对只改变决定分支的患者事实；指南、动作、选项、顺序及其他事实固定。不能把未提及自动当成假；UNKNOWN 必须按明确定义构造。

## 必须比较的方法

- 原模型、完整指南、无干预。
- 模块二预测路由 + 模块三 ASTER 编辑（主方法）。
- 相同模块二预测下的直接注意力分数偏置。
- 原始均值方向、反向方向、固定随机种子的同范数随机方向。
- 模块一金标路由的 oracle 上限：仅用于拆解模块二路由误差，不作为可部署主结果。
- 零强度/零门控恒等对照。
- 可选文本高亮/仅提供适用规则对照，必须单列，不与相同输入的注意力干预混为一谈。

所有方法使用相同病例、提示、解码参数、答案解析器和有效分母。保存原始输出与失败状态。

## 主指标与统计

- MEGA-CDP：以官方路径一致性/分支指标为主，同时报告病例宏平均、微平均、完整路径成功率、无效输出率和干预覆盖率。
- MedGUIDE：原生 MCQA 准确率与受控反事实分支/处置遵循分开报告；反事实结果不得写成原始官方任务准确率。
- 所有方法报告配对纠正数、退化数、净变化、置信区间和分层结果。
- 统计单位是指南/决策树簇。病例、提示、变体和多次生成不是独立指南样本。主比较采用指南级配对 bootstrap 或预注册的簇级检验。
- 同时报告零强度恒等性、模型输入/权重指纹、分词边界、执行成功率和计算成本。

## 执行顺序

1. 生成数据清单与按指南树分组清单。
2. 审计数据质量、跨集合泄漏、跨数据集同源关系和最小对语义。
3. 在 MEGA-CDP 拟合/选择分区学习方向并冻结所有参数。
4. 内部确认集只作诊断，不再据此调参。
5. 冻结代码、权重、提示、方向、头、强度、评价器和统计脚本。
6. 运行 MEGA-CDP 官方测试，保留全部有效病例和失败。
7. 用冻结配置运行 MedGUIDE 来源树留出外部验证。
8. 生成分母流程图、完整对照表、指南级统计和可复现报告。

## 解释边界

若最小对不能可靠核验、存在同源泄漏、零强度不等价或答案解析不可靠，先修复并重新冻结，不跑全量测试。若 ASTER 不优于直接偏置/随机方向，必须报告当前实验未证明学习方向具有额外收益，不能通过换子集、换强度或删除失败案例补救。金标路由只是机制上限，不是端到端成绩。忠实执行给定指南不等于临床正确或安全。

当前目录先提供通用的按指南分组拆分和泄漏审计工具。脚本要求显式指定已核验的指南/决策树字段，不猜测私有服务器文件的 schema。模型前向仍需适配现有 ASTER/流水线入口；本提交不代表全量推理已运行。
