# B 编辑机制实验协议（独立诊断）
日期：2026-10-30。对象：PR42 主稿配对键差分、差分二阶矩谱子空间内的有向均值、RoPE 后缓存键平移。PR41 查询谱投影不纳入本实验。
本协议先于脚本落盘。官方冻结配置与所有已有结果仅只读；不进行选参。

## 假设、主要指标与标准
B1 数值实现：固定已旋转查询 q，规则位置 j 的理论分数差为
Δs[h,j] = gain[r] * q[h]ᵀ R(j)v / sqrt(d)，实际值为 q[h]ᵀ(k'[j]-k[j])/sqrt(d)。
按层、KV头、共享查询头、目标词元保存全部矩阵；bf16 量化残差单列，不能把理论值当成实测值。
CPU float64 公式误差 <1e-10；原缓存和值缓存不变；非目标位置不变；GQA 映射头号为 kv*group_size + shared。
这些不通过时停止真实实验并修复独立诊断代码。

B2 在线双向读取：正/负患者均使用该根节点规则金标准路由，只编辑根规则的编号与处置词元。
正向应增加适用规则注意力并减少不适用规则注意力。对照 baseline、reverse、mean、
score_bias、random（固定5种子20261030..20261034）。增益读冻结配置，不拟合。
未知状态 NONE 应零编辑；不能解释为三态通用临床金标。
保留 root-gold 与 predicted-root 独立运行选项，不把后者用于证实方向机制。

B3 位置与查询变化：位置0为患者后缀forward最后一个查询，决定第一个生成词元；
位置1/2/4/8/16为同一 baseline token 序列下的后续forward。
所有方法使用 baseline 共享 teacher-forced 序列，分离编辑效应和生成轨迹改变；
同时保存同一 edited q 下撤销全部编辑的局部注意力质量，区分直接键效应与查询变化。
首token重新forward完整患者后缀，不能复用未编辑后缀的logits。

## 样本与统计
默认8个已有confirm来源簇，每簇最多1配对，3状态；仅为已有年龄根规则反事实，不是医生裁定。
所有失败保留，分母为预定来源、配对、状态、方法，不把头/词元/正负配对当独立样本。
正负联合指标为每簇“适用质量变化减不适用质量变化”的平均，两状态等权；
报告正向纠正/反向退化簇计数、来源簇bootstrap 95% CI（固定种子，2000次），随机5方向的簇均值零分布。
仅5随机方向时最小置换p为1/6；不宣称p<.05。
机制通过：双状态平均指标CI下界>0且优于反向对照，并至少4/5随机方向均值；
局部数值成立而机制标准未过，只能说算子可执行，不能证实方向特异性。
若可用来源<8，全量运行并明确范围；技术失败>20%停止扩大规模，先排除实现/资源问题。
未知态用于零编辑核验，不并入正负主效应。
