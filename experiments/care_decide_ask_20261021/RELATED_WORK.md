# 研究定位与已有工作：不宣称“首个追问方法”

本文件是论文选题和实验的文献定位，不是系统综述。定稿前应完成系统性检索并检查与同类方法重叠的实质范围。

| 工作 | 已经研究什么 | 我们仍需验证的区别 |
|---|---|---|
| [QuestBench（Li 等，2025）](https://arxiv.org/abs/2503.22674) | 信息不足时应该问哪项必要变量；多为缺一个决定性变量的约束求解 | 同时考虑“虽然有未知但已经可行动”的反例，并决定何时不问 |
| [KnowNo（Ren 等，2023）](https://proceedings.mlr.press/v229/ren23a.html) | 使用保形不确定性使语言模型在机器人决策中适时求助 | 本路线将**逐规则状态集合**经显式逻辑与优先级传播到最终**可能动作集合**，这项组合的新颖性仍需验证 |
| [AxBench（Wu 等，2025）](https://proceedings.mlr.press/v267/wu25a.html) | 在其模型与任务上，提示策略优于多个表示层干预方法 | 历史神经控制负结果不意外；主方法必须超过简单提示和硬标签流程 |
| [Human Interventions as Labels（Zavattari 等，2026-10 预印本）](https://arxiv.org/abs/2610.21708) | 针对部分具备资格的模型，定位“明明可以行动却过度追问”的内部方向及门控 steering | 不能把探针＋一维方向作为新论文独占贡献；如果分析内部表示，只作为机制附录 |
| [CARE-Bench（Hua 等，2026）](https://arxiv.org/abs/2608.03731) | 真实患者交互中选择追问还是评估/转诊时机 | 已存在 CARE-Bench 名称；我们不取同名，不假称患者分诊的第一套 decide-or-ask 评测 |
| [MediQ（Li 等，2024）](https://arxiv.org/abs/2406.00922) | 临床互动问答及什么时候向患者提问 | 本路线更聚焦含例外、优先级和不完整条件的可执行规则状态传播 |

**谨慎的新颖性命题：** 用冻结的规则级三值状态及其**联合**不确定性集合，计算所有合法补全下的行动集合，并在存在无关未知与结论不变未知时选择直接决策。已有 KnowNo/QuestBench/临床追问研究与此有相邻甚至部分重合问题，论文必须承认并通过公开强基线检验增量。

**不要照搬外部评论的未经验证表述：** 保形理论不是每个病例或每次 DECIDE 都有 α 风险上界；“概率校准”不是当前 A1 输出；真实临床事件上的保证还需要可信规范、专家标注和分布检查。
