1. 从本目录运行 PYTHONPATH=. python -m unittest discover -s tests -v。先核查三个示例：关键未知时 ASK、无关未知时 DECIDE、未知但决定仍固定时 DECIDE；修复新 bug 时追加 CPU 回归测试。

3. 另需把自然语言规则、优先级和可询问属性映射为受审计的结构化政策。当前原型只接受布尔 DSL，医学指南编译器还未实现；手工独立审查 gold 与 AST，不以同一待测 LLM 的解析作为 gold。

6. 至少三个模型，包括一个指令模型；所有模型/提示/评分源/α 网格/数据家族/阈值在测试前冻结。按家族聚类评价，并记录完整分母和失败病例。
