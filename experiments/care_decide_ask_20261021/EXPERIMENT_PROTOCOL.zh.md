# 新论文实验：只检验“该决定还是该追问”

**状态：事前实验方案；新的大模型效果、正式独立确认和临床有效性均未测。** 不在旧 N3 测试集继续调参，不重跑旧 B1–B4、N2 来源盲搜和 N4 联合网格。

## E0：先冻结有独立真值的实验数据

用可审计的布尔条件、AND/OR/NOT、互斥约束、阈值谓词和规则优先级**先构造政策与合法补全 oracle**，再生成自然语言问题，不能用被测模型的回答当 gold。每个机制至少包含六类最小对：

1. 充分信息：允许唯一合法动作；
2. 关键属性未知：不同合法补全导致不同动作；
3. 无关属性未知：缺了信息，但最后动作仍唯一；
4. 未知被 OR、例外或优先规则覆盖：仍可行动；
5. 多个未知：必须选择真正改变动作的属性，必要时多轮追问；
6. 顺序、否定、例外、数值阈值、动作同名/不同名和语言改写。

**严格分家族：** 同一逻辑 AST、逻辑同构结构、原始事实组、所有反事实成员不得跨 train/dev/calibration/test。PR #17 与旧 600 条样例已被看过，只能做探索或单元测试。新确认集建议至少 30 个未见机制家族、500–600 条病例，同时要求有足够独立**校准**家族，不能把它们和测试家族混用；这是预算草案，不是正式功效证明。使用 pilot 的配对错误分歧、家族内相关与预设最小效应进行功效模拟后再冻结样本量与 SHA。

对于 family-level 同时覆盖所有病例所有规则的 α=0.05 校准，独立校准家族少于 19 时阈值可能为无穷。若无法验证跨家族可交换性，必须将统计覆盖结论限制在假设范围内，并报告子组覆盖和分布偏移。

## E1：先验证“把未知等同不可决定”是否真实存在

至少三个模型，包含一个基础模型、一个指令模型、一个不同模型家族。模型名称、版本、提示、生成预算、解析方式在看到测试输出前锁定。比较无特别提示、明确“信息不足要追问”、思维链、先枚举未知再判断、任何未知即追问、可执行规则 oracle（仅上界）。

按**关键未知/无关未知/结论不变未知/全部已知**分别报告：

- 应问时直接错误决定；
- 可决定却无谓追问；
- 具体问对了哪个决定性属性；
- 回答后动作是否正确。

只有真正有两个以上模型出现可重复的两种错误之一，才可称为值得解决的一般现象。否则不要强行论证 LLM 普遍不会判定。

## E2：比较真正可部署的方法（信息输入必须公平）

在相同冻结 A1 状态与相同患者/政策上：

| 方法 | 输入 | 目的 |
| --- | --- | --- |
| 直接 LLM | 患者+指南 | 基础能力 |
| Any-U→ASK | 冻结 A1 硬状态 | “有未知就问”的最强简单启发式 |
| 显式三值提示 | 同一冻结 A1 | 排除简单政策传递 |
| 硬 A1 + 可执行行动集合 | 同一 A1，但不含概率 | 未校准执行器的增量价值 |
| 新固定评分 + 联合保形 + 行动集合 | 另需正式评分和校准 | 本论文候选主方法 |
| 完全正确真值 + oracle executor | 独立真值 | 机制上界，非可部署 |

**现实缺口：** A1 只有 T/F/U 硬标签，新评分器与文本规则 AST 编译器未完成。若无法在校准前冻结可信评分，保形主方法不可运行，也不可声明 α 保证。任何 REVIEW 和无解析信号留在分母。

## E3：校准能否把错误决定控制住，代价是多少？

固定评分和 train/dev 选择后，分别校准 α∈{0.01,0.05,0.10,0.20}，测试集只能在冻结后评一次。

必须输出：所有规则同时正确覆盖比例；P(错误决定且给出动作) 的**无条件实测概率**；在模型实际 DECIDE 样本中的错误率（描述性，**不保证≤α**）；DECIDE/ASK/REVIEW 频率；可决断样本的不必要追问率；该追问样本的属性命中率；补答案后最终正确率及追问轮数。画**风险—追问率曲线**，不能把零错误但全部 ASK 当成成功。

按病例联合校准、按独立家族先取最大分数再校准两种方法要单列；当 α 太小导致阈值无穷/只会追问，原样报告。跨指南/不同医院/事实机制变化下，不能把可交换性保证未经检验迁移到新域。

## E4：问哪个属性，问几轮？

与随机选择缺失属性、第一条 U 规则和使用同样信息的简单策略比较。用合法世界补全估计问某属性后可能行动集合是否缩小；没有可信世界概率时，当前代码对世界均匀加权，**不能声称最优信息增益或全局最小追问数**。若单问题不能马上缩小行动集合，允许靠减少可能世界逐步问，多轮的轮数和回答后成功率单独报告。

## E5：独立迁移和外部任务

- 新逻辑 AST 和新的患者表达，不只是换主题词；
- 换另一模型家族，冻结评分/校准协议；
- QuestBench Logic-Q 用于“该问哪个属性”的单独外部诊断，不能取代无关未知/不必问的负例；
- 已有 **CARE-Bench（arXiv:2608.03731）** 专门评估患者分诊中的问与行动时机，不得把新数据集命名为 CARE-Bench。若许可允许，可设小规模人工审查的外部任务切片，但没有可审计 DSL 的真实病例不能作为“形式保证已成立”的证据。

## 预注册与统计

主要报告**在固定追问/审查率下的错误决定率**，同时报告**在固定风险预算下的无谓追问率**。使用同一病例的配对比较和家族聚类 bootstrap，报告原始计数、风险/追问率曲线、多重检验与家族分布；不能只报整体 accuracy。至少预先冻结一个 primary 对比，不靠测试上挑 α 或删掉失败病例。

按真值控制、冻结 A1 硬预测、新评分校准三层分别报告；控制状态正误 × 决策执行正误做 2×2 错误归因。若方法对“只要有 U 就问”和“相同规则信息的显式确定性执行”没有优势，应如实报告并减少论文贡献主张。

**阶段停止条件：** 没有独立可执行规则 AST 或没有可信 T/F/U 概率评分时，停止校准风险保证路线，仅交付三值执行器的未校准结果与对应缺口。所有新模型效果均待未来实际运行，本协议并不填任何设想性能。
