# 方法的数学含义与保证边界

## 1. 三值规则与行动集

输入为有结构化条件、优先级和明确默认动作的政策 `π`；已知事实构成观测 `o`。给每条规则 `r` 一个可能状态集合 `Γ_r ⊆ {T,F,U}`。其中 T/F 是规则条件已明确成立/不成立，U 表示规则条件在当前观测下尚无法判定，执行时可按所有仍允许的 T/F 补全展开。

令 `W(o,Γ)` 为同时满足观测、政策约束和规则预测集的世界。对每个 `w`，按固定规则优先级执行得到 `π(w)`；定义：

`S(o,Γ) = { π(w) | w∈W(o,Γ) }`。

- 若 `W=∅`：数据或评分矛盾，返回 `REVIEW`，禁止把空集合当作“所有世界决策一致”。
- 若 `|S|=1` 且唯一动作不是预先指定的人工复核标记：返回 `DECIDE` 和唯一动作；若唯一动作为 `REVIEW` 类人工复核动作，则返回 `REVIEW` 而非自动决策。
- 若 `|S|>1`：返回 `ASK`，询问尚未知且可以收缩行动/世界集合的属性；收到回答再推理。

本原型的目标是**安全地决定是否行动**，而不等于获得真正自然语言追问、完整患者属性解析或医学可执行指南编译。实现使用布尔 AST、显式 `priority`、可选约束和 `default_action`；数值范围需在上游编译为可审计布尔谓词。

## 2. 同一病例所有规则的联合保形校准

需要一个**独立获得、在校准前固定的状态评分器**，对每个规则输出 `p_r(T), p_r(F), p_r(U)`（合法概率归一化）。冻结 A1 当前只导出硬状态，不满足这一前置条件。

对校准病例 i 中的每条规则 r，以独立真值 `z*_ir` 构造不一致分数：

`a_i = max_r [ 1 - p_ir(z*_ir) ]`。

对独立**病例**（不是各条规则）的 `a_i` 做 split-conformal 校准：`k=ceil((n+1)(1-α))`，若 `k>n` 则阈值为 `+∞`，否则使用第 k 个升序值 `q`。在测试样本上构建：

`Γ_r = {s∈{T,F,U} : 1-p_r(s) ≤ q}`。

在校准病例和新病例可交换、评分器在校准前固定、规则标注正确的条件下，有：

`P(∀r, z*_r∈Γ_r) ≥ 1-α`（在新病例上的**边际联合规则状态覆盖**）。

若真实行为由政策 π 严格决定，且在覆盖事件中实际合法世界确实保留在 `W(o,Γ)` 中，则得到：

`P(输出 DECIDE 且所决定的动作错误) ≤ α`。

**注意：这不是** `P(错误 | 输出 DECIDE) ≤ α`，也不是对每一位患者、每一子群或任意分布转移的保证。置信集越宽时可能频繁 ASK/REVIEW，零错误决定可能只是“从不决定”，必须报告追问/决策覆盖率。

如果数据在病例内部强相关，但不同家族可交换，可先对每个家族**所有病例所有规则**取最大不一致分数，再按独立家族校准，使新交换家族的整体覆盖有边际解释。少于 `ceil(1/α)-1` 个校准单位时阈值往往为无穷，实际预测集会退化为全部状态；这不是代码故障，而是样本不足的保守结果。按家族校准不保证跨机制类型的数据分布偏移。

如果某条规则评分无法获取或解析失败，预测集退化为 `T/F/U` 全集，并保留技术失败标记，不能把失败当作已知 F，也不应删除样本改善分母。

## 3. 追问目标

从仍未观测的属性中，选择回答后**期望可能动作数减少最多**者。当前原型以 `W` 中的各可行世界均匀加权，仅用于动作信息增益排序；若无可靠世界分布不能称最优期望信息增益。多步追问的最少总轮数没有理论保证；若单个问题不能立刻缩小动作集，可用世界数减少作为可解释的后备准则。

若合法世界约束、属性可回答性或策略优先级不存在/矛盾，返回人工 REVIEW，而不生成貌似确定的动作。外部人工答案需再通过 schema、范围和一致性校验。

## 4. 可能导致保证无效的主要情形

- 校准/测试病例或家族不可交换（包括跨医院、指南版本、模板分布变化）。
- 使用测试结果调节评分模型、量化精度、提示或阈值，或把多个强度取最好的那个。
- 规则文本到逻辑 AST 解析错误、漏掉适用范围/优先级/禁忌，或事实记录与现实不一致。
- 将 A1 的硬 T/F/U 或 Qwen 的候选字母 logits 当作 A1 三值概率。
- 校准时漏掉失败记录，或者将同一家庭/规则的多条记录当独立校准样本。
- 输出 `REVIEW` 时从风险分母删除该样本。

这是一份**待实测的理论与工程设计**，不是仓库已经证明形式保证或临床安全的声明。
