# U4 位置差异定位与重新验收

执行隔离修正后，完整 P4 在 Qwen 的 U4 未通过。Qwen 硬门控 81%、普通文本裁剪 78%，绝对差 3 个百分点；Llama 为 65.5% 与 66%，绝对差 0.5 点。两模型 U1 最大键差为零、U2 一致率 100%、U3 差距为零。Qwen 门控分数更高也不豁免用户的 U4 等价检查。故本轮 P5 未启动，P6 未运行。

两个模型在保持相同位置编号的裁剪对照上，预测一致率均为 100%；最大选项概率差分别为 1.98e-5、1.40e-5。这支持位置编码变化是差异来源。普通裁剪会删除词元并压缩后续位置，单独遮住处置的键不会自动压缩位置。

本次修改：硬门控仍保留完整输入并屏蔽竞争处置的键，同时将其余词元的位置编号压缩到普通裁剪的坐标。没有改变普通文本裁剪的对照定义、样本、答案或 U4 的 1 点门槛；新增保留原始位置的硬门控对照，保留先前负结果。

这是一项额外的位置处理，不能声称纯粹的对数注意力偏置在原位置下就严格等价于普通文本裁剪。有限强度门控仍使用原位置。P5 报告全部强度，并检验按 SW/AC 平均准确率选出的同一个有限强度是否在两卷上各自不低于普通裁剪超过 2 点；位置压缩的硬门控即使通过，也不能代替有限强度的能力验证。参数选择仍只在开发集进行。

新 P4 已在 GPU 0、1 启动：每模型 200 例；只有两模型全部通过才自动启动新 P5，每模型 517 个输入、16 种配置。预计分别约 30–40 分钟和 3 小时。未完成之前不报告新准确率。P6 仍需满足原方案的数据与人工核验要求。

旧代码、协议、完整结果及报告位于 results/position_mismatch_before_fix。所有实验均在服务器执行，未用测试集。
