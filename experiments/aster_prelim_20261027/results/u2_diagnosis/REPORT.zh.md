# U2 不一致定位与修复

此前 Qwen 3/200、Llama 7/200 病例的四卷分支读出不一致，均涉及并列或近似并列分数。

对全部不一致病例及每树一个正常对照，进行了两类实验：固定长度只替换被遮蔽处置；保留原始处置长度变化。可见 token 完全一致。

固定长度替换下，BF16 和 FP32 的两模型分支 logits 最大差均为 0。变长度时，BF16 最大差为 Qwen 1.0、Llama 0.375；FP32 分别降低至约 0.000168、0.000090。FP32 下诊断集四卷 argmax 全部一致。

这支持低精度与序列形状敏感性造成近似并列翻转，而不是已发现处置内容绕过遮罩。采用 FP32、关闭 TF32 进行完整 P4 重新验收。按用户最新要求，U2 不再以 99% 一致率为硬门槛；仍报告完整数据与固定长度因果对照。
