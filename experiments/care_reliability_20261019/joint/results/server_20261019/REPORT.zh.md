# 模块一与联合真实实验结果

真实实验已完整结束：192 例、8 个规则家族，主要分析为 24 个标准表述配对。六卡结构推理共执行 1090 个唯一 TrialMatchAI 请求，V6/V7 共享相同请求输出；两个版本各评估 576 条规则。Qwen 完成 2496 条答案记录（含 192 条基线）、4032 次真实前向，无缺失输出，768 项同提示零控制全部通过。

| 结构来源 | 仅结构提示 | 直接偏置 | B4 与查询校准 |
| --- | ---: | ---: | ---: |
| V6：主要配对正确 | 0/24 | 0/24 | 0/24 |
| V7：主要配对正确 | 0/24 | 0/24 | 0/24 |
| 参考正向门控：主要配对正确 | 15/24 | 15/24 | 15/24 |
| 参考双符号门控：主要配对正确 | 15/24 | 15/24 | 15/24 |

完整上下文无干预基线也是 0/24 主要配对正确。全部 192 例的病例准确率：基线 71/192（37.0%）；V6 三方式均 60/192（31.25%）；V7 三方式均 61/192（31.77%）。两组参考结构的仅结构提示与学习干预均 161/192（83.85%），直接偏置均 160/192（83.33%）。

V6 仅开放 1/576 个规则门控，且该规则状态错误；V7 开放 0/576。两个版本各有 155/192 例出现至少一个条件解析异常（并非最终答案缺失），共 484 次条件失败记录。V7 的三种方式答案完全相同，因此本次预测结构实验没有提供学习干预有效的证据。低误用率同时伴随低适用病例正确率，不能单独解释为模型改善。

规则状态本身的准确率由 V6 的 369/576（64.06%）提高到 V7 的 392/576（68.06%），但没有转化为主要配对答案收益。160 条参考真规则中，两版本均把 127 条判为 U，只正确判真 33 条；这 33 条又全部因证据冲突而关闭。因此正确真规则的干预覆盖均为 0/160。

127 条真到 U 的规则中，V7 有 110 条涉及 Not Violated 固定映射为 U、74 条涉及生成截断、38 条涉及条件文本不匹配，只有 9 条涉及模型明确输出 Unclear；这些原因可以同时存在。不能将全部 U 都称为语义未知，也不能把全部损失只归因于证据门控。详细规则统计见 ../../../checks/work_verification/threshold_rule_gate_summary.json 与 unknown_rule_attribution.json。

参考结构明显优于预测结构，且主要配对结果不随干预方式改变。这支持优先解决结构预测与状态映射问题；不能把参考答案辅助的诊断结果当成实际预测模块的效果。V7 关闭了 V6 唯一错误门控，但没有恢复正确规则的有效覆盖。

正式完整流水线耗时 4341 秒（72.4 分钟）；最慢结构分片 4161 秒，结构峰值保留显存 15.184 GiB，Qwen 阶段 176 秒、8.783 GiB。用卡为 0、1、2、3、6、7。运行器结束通知曾因僵尸进程的 PID 等待而延迟；以上均为实际模型运行时间。

本批数据是开发阶段已接触结构与措辞的新合成机制测试，不是独立临床验证。表面变体不按独立样本解释。完整结果见 metrics.json；原始日志、请求映射、模型版本、模型权重与文件摘要见 ARTIFACTS.json 及运行来源记录。
