## 当前主要问题

规则状态正确数为 V6 369/576（64.06%）、V7 392/576（68.06%），这是次要结果；主要成对终点未改善。V6 仅允许干预 1/576 条规则且状态错误，V7 为 0/576。160 条参考适用规则中，两版本均只判出 33 条适用，而这 33 条全部因证据冲突关闭。127 条参考适用却被判为不确定的规则中，V7 有 110 条涉及 `Not Violated` 固定映射 U，74 条涉及生成截断，38 条涉及精确目标文本匹配拒绝，9 条涉及模型明确 Unclear；这些原因可重叠。提示词把 Not Violated 定义为确认不违反，把 Unclear 单独用于缺信息，当前映射存在需要修正的问题。

两个版本在 155/192 例中包含至少一个原子解析问题，但所有病例仍保留并完成答案评分。不能把解析拒绝和标签转换造成的 U 全部称为模型语义不确定，也不能仅凭不开启干预而声称可靠性提高。详见[用户要求的门控与筛选分析](checks/work_verification/threshold_review.zh.md)。

## 运行与保存

模块二最终六任务耗时 116.4 秒，6,905 次实际前向，588 次零控制通过，峰值显存 7.76 GiB。结构预测用六张允许卡，共 1,090 次真实 Phi 请求，经精确请求共享供 V6/V7 使用。联合 Qwen 完成 4,032 次前向和 768 次零控制，耗时 176.3 秒，峰值 8.78 GiB。结构与联合总耗时约 72.4 分钟。

运行中修复了 BF16 非单调实际扰动导致二分搜索漏点的问题，保留原 15% 门槛并统一重跑六任务。原始失败、修复数值证据及完整逐例记录均保存于[结果归档](results/work_20261019/README.zh.md)。模块一与 Qwen 使用各自原环境，通过带来源信息的结构文件连接。测试记录仅用于实现验证，未作为模型效果。
