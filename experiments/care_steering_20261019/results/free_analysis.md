## Completeness and limitations

- Nonparametric bootstrap intervals can collapse to [0,0] or [1,1] on uniform strata; these intervals do not establish zero population uncertainty or equivalence.
- scoring_plus_gate_seconds adds saved gate time to model scoring time; tokenization, some hook preparation, model loading, and direction extraction are excluded. Peak memory values are process high-water marks, not per-item resets.
- Free-generation row timings allocate batch wall time across items; they are not isolated per-item latency. Reused completions are valid method outputs but must not be counted as independent model calls or summed as actual total compute. gate_seconds=0 in this follow-up denotes unmeasured per-item gate time; full run wall time includes gate execution.
- One evaluation seed is present; intervals measure variation across rule families, not model/direction training seeds.
- applicable: absent/unknown in 96/960 rows; dependent metrics omit unknown metadata.
- new_action_selected: absent/unknown in 736/960 rows; dependent metrics omit unknown metadata.
- This is an exploratory follow-up analysis; primary_scope is null and any source-test Holm values are descriptive multiplicity adjustments, not a preregistered confirmatory test.
- task:equipment_routing: only 8 families; intervals and significance are exploratory.
