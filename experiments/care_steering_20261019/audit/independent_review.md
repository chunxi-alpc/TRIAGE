# 独立审查

当前审查针对服务器保存的第一轮完整结果：440 条合成数据、384 条事实数据，以及 1280 条目标任务预测（含 dev；test/transfer 共 960 条）。审查程序见 `audit/independent_review.py`，详细结果见同目录 JSON。此文不把未实施的完整 CARE 当作已复现。

## 通过的核查

- 独立从可见观察和规则文字重新计算 440 条数据的适用性、旧规则有效性及正确动作，均与标签相符。
- 44 个规则家族严格分配到 train/dev/test/transfer；没有跨划分重复的完整提示，事实问题经大小写和标点归一化后也未发现跨划分重复。
- 三组数值翻转对只改变一个年龄数值；例外对只改变暂停标记；每对规则和选项保持一致。
- 预测记录的标签、规则误用标记、成对标识与原数据一致；非零残差干预恰好修改一次最后提示 token，零系数不修改。
- C_reduced 的模块一仅接收 patient 与 structured_rules，未直接读取答案或适用性标签；未知、失效旧规则无可用回退、无冲突时关闭干预。
- 所检查的事实训练冲突输出没有同时命中新旧两个答案的情况。但字符串包含匹配仍比严格语义判断宽松。
- 统计程序的六项软件检查通过，包括整家族重采样、精确符号置换、缺失方法不补零、完整翻转对要求及 Holm 校正。

## 当前结果的可支持结论

主测试集 160 条、16 个家族。准确率 A 60.625%、B 46.875%、C_reduced 56.25%、D_adapt 60.625%。C 比 B 高 9.375 个百分点，家族 bootstrap 95% 区间为 [1.25, 17.5] 个百分点；家族符号置换 p=0.0615，两项主检验 Holm 校正 p=0.123，因此不能按预设主检验宣称显著改善。

不适用时的新规则误用率，B 为 44/64=68.75%，C 为 47/64=73.4375%。C 的总体准确率较 B 高，不表示 C 已降低相对于 B 的规则误用。C 也未超过 A 的总体准确率。

D 的 dev 系数 0、0.05、0.1、0.2 均得到 0.60 准确率，预先指定的最小系数优先规则选择 0。主 D 因此等于无键干预；该结果既不能证明原 CARE 有效，也不能证明它无效。非零 D 的 dev 结果已留存。

## 必须随报告保留的限制

1. CARE 原上传文件尚未完成核对时，C_reduced 和 D_adapt 均不得称作完整原方法。C 使用受限确定性数值/三值逻辑与精确句子匹配，不包含完整自由文本解析、Phi-4 或 BioLinkBERT。结构化规则本身是人工提供的输入。
2. 目标数据是虚构路由任务，旧规则和新规则都出现在提示中。这不是实际医疗验证，也不是已验证的参数知识与上下文知识冲突。
3. 划分独立的是规则家族；逻辑模板和部分动作词汇可共享。设备迁移只更换领域表述和保留家族，不能称为新的推理结构或广泛跨任务迁移。
4. 当前全部 1280 条预测的原始最高概率下一 token 都不是选项字母。结果来自对四个字母的约束评分，不能写成自由生成正确率；如需回答模型实际会输出什么，应补充自由生成验证。
5. 仅单模型、单方向随机种子，事实方向严格筛选后只有 11 个训练对。16 个患者测试家族和 8 个迁移家族下，区间与检验应视为探索性结果。未拒绝损害假设不能证明无冲突性能等价。
6. 模型计分耗时不含 tokenization 和部分 hook 准备；加 gate 耗时后也不等同于完整端到端时间。显存记录为进程累计峰值，不能相加或视为逐例峰值。
7. 公开事实数据可能出现在模型预训练中；这里的划分只能控制本次方向提取和调参的数据使用，不能证明消除了预训练污染。
8. 新增敏感性对照必须独立标记，不能根据 test 结果替换已冻结的主要系数。进一步追加的预测应重跑审查和统计，更新记录数与结果版本。
