# 规则读取与答案读出的后续诊断

**日期：2026-10-28。本文件在新增模型前向前固定。** 这是看到首轮结果后制定的探索性诊断，不是新盲测或外部预注册。

首轮实现和结果固定于 f3a17f721118407d6a9855d8faf48cbbb90e9770（PR #40）。最新主线 2e16df8c 将离线方向学习从旧模块二改为模块一，处置盲评估改为模块二。运行路径和原实验目录保留历史编号；本轮仍研究相同的离线方向与模块三执行通路。

## 问题与已知依据

首轮谱方向联合增益 4 在全部 24 个确认提示上提高正确/兄弟规则注意力比，但没有改变任何 A/B 答案。已有数据的只读复算表明：基线 22/24 次选择最后规则，改变患者事实使 2/12 个匹配配置翻转答案，交换规则顺序使 10/12 个匹配比较翻转。

本轮区分三个问题：原编辑对最终分数的影响是否较小；将同一通路的实际绝对读取推高后，答案是否按路由方向响应；模型及读出能否使用显式给定的规则 ID。结果不用于重选头、调整默认增益或挑选确认样本。

## 冻结资产与完整分母

- 保持 Qwen/Qwen3-0.6B-Base，revision da87bfb608c14b7cf20ba1ce41287e8de496c0cd；CPU float32、eager、eval、batch 1、4 线程，原 PyTorch/Transformers 环境。
- 保持原 triplets.jsonl、operators.npz、selection.json 及其摘要；不拟合新方向、不选择新头。
- 冻结四头为零基编号 (13,4)、(23,6)、(6,2)、(22,7)，编辑规则编号与处置的并集。
- 使用首轮全部 24 个唯一确认提示，来自 3 个指南、6 个基础患者状态、12 个指南/处置映射/顺序配置。相反患者保持配对。
- 保留所有布尔模拟患者，包括自然语言谓词之间可能不一致的组合。标签仅表示树谓词逻辑，不表示自然临床病例；不依据答案删除、修正或筛选样本。
- 原 216 条及答案边界修正记录不覆盖。全部新增条件另存本目录。

## 固定八个条件

| 条件 | 操作 | 解释 |
|---|---|---|
| baseline | 原提示零编辑 | 重放锚点与全词表读出 |
| projected4 | 同一方向、oracle 符号、增益 4 | 首轮条件重放锚点 |
| projected32 | 同一方向、oracle 符号、增益 32 | 原增益的八倍，单个预定应力点 |
| projected_minus32 | 同一方向、相反 oracle 符号、增益 −32 | 学习方向的反向控制 |
| score_plus8 | 正确规则 +8、兄弟规则 −8 nats | 所选通路的强直接读取控制 |
| score_minus8 | 正确规则 −8、兄弟规则 +8 nats | 强直接读取的反向控制 |
| note_gold | 原完整提示加入正确路由文本 | 显式 oracle 标签通路控制 |
| note_sibling | 同模板将适用规则 ID 换为兄弟规则 | 显式文本反向控制 |

共 24 × 8 = 192 条完整记录。baseline 可复用当次后段准备已经计算的真实基线，仍逐提示保存记录。模型加载、指南预填充、数值验证的额外前向单独统计，不把记录数当作独立样本数或总模型调用数。

32 与 8 均在本轮前向前固定，不扫描、不根据结果继续加大。它们不是默认超参，不满足键范数、QK 扰动或计算预算匹配，不据准确率差判断哪一种算子优越。

## 精确执行与文本控制

沿用原指南前置协议：指南无干预预填充，每个患者使用独立缓存视图，编辑后执行整个患者/问题后缀。学习方向只翻转系数一次，不同时翻转方向和系数。直接偏置作用所有后缀查询、相同四头对应的 GQA 查询组和相同规则位置。

文本条件不编辑缓存。在原 Answer: 之前插入以下固定模板，并保留其余原文本：

    Routing result (provided by the rule parser):
    Applicable rule: {applicable}.

正确与相反注释仅替换一个 A/B 标签。首次前向前将模板确定为单个适用规则 ID，避免同时出现正/负两个标签而引入额外否定处理或末标签偏好；不扫描多个模板。文本直接给出了 oracle 标签，因此只作为输出通路能力控制，不证明处置盲评估、患者推理或主方法有效。追加文本导致后缀长度和位置改变，不能把它当作严格同扰动预算比较。

所有条件采用规范单 token 续接“ A”/“ B”（362/425），逐次核验完整提示前缀稳定。无截断，长度上限 4096；原指南前缀的 token ID 和目标位置必须不变。

## 记录与诊断指标

1. 每条记录保存 A/B logits、正确标签间隔、受限预测、正确率，以及全词表中的 P(A)+P(B)、各候选概率和前五个词元。该概率质量不等于最终自由生成的格式遵循率。
2. 保存四头实际 gold/sibling/其他位置注意力质量、编号/处置角色质量，以及单位方向在实际改变后查询上的响应摘要。较大键编辑会改变后续查询，不能只根据系数符号推定实际作用。
3. 逐条件报告全部 24 提示的正确、纠正、伤害、预测翻转、选择最后规则比例，及全部 12 对的两患者全对比例；按 3 指南分层。
4. 对学习方向、直接偏置、文本注释三条通路分别计算同提示的正向与反向正确标签间隔差，保留两侧完整结果。
5. 描述实际 gold/sibling 质量是否达到 0.8、0.9：既报告四头平均的提示比例，也报告逐头比例。没有达到时不声称已使通路饱和；阈值不用于继续调节幅度。
6. 复算原基线仅改变患者事实、规则顺序、处置映射的全部匹配对，对答案间隔及预测变化作描述性比较。
7. 无新的显著性检验、确认集参数选择、最佳条件选择或正例筛选。只有三个指南，主要展示完整观测与分层结果。

## 数值验收与停止条件

24 个 baseline 和 24 个 projected4 与首轮规范读出逐条核对候选 logits、各查询头/目标词元注意力、提示长度，容差分别 1e-5、1e-6。每个患者后验证原指南缓存逐张量未变。

对每个指南中按 case ID 排序的首个配置、两名患者、四种强编辑条件，比较完整后缀与精确后段执行，共 3 × 2 × 4 = 24 项，容差同上。源码、模型、输入、协议和算子摘要冻结后才开始新前向；不在不一致的检查点上恢复。

完成全部 192 条记录后停止本轮推理。保留所有结果，不以正反对照是否产生希望的答案效果决定是否追加剂量。
