# ASTER M3 后续实验：P0–P3

本实验在服务器 `gcx@10.29.128.115` 的 `gcx261014` 环境运行，仅使用 GPU 0、1。原模型、已完成的 M3 权重和历史结果保留；新结果写入仓库内 `results/aster_m3_followup_20261107/`。

## 实验范围

|阶段|执行内容|主要比较|
|---|---|---|
|P0|复算原 7,458 例路径的直接配对统计；补齐金标准路径缺失节点；补跑 6 个纠正、2 个退化的节点诊断|辅助参考、自身参考、完整阅读及旧闭式方法|
|P1|固定已有权重，在 MedGUIDE 原 200 题上评测，并计算与 MedGemma 既有预测的共同错误|完整阅读、旧闭式、已有 M3、bias 及后续编辑器|
|P2|训练三个同层随机头版本、全部候选头和全部头版本|随机头匹配原 51 头的层分布、秩、参数量；较大集合为容量上限|
|P3|使用 A/P 保持、C/F 翻转及 F_same 同侧数值配对训练|干扰 N、信号 S、联合 NS，以及无配对损失的 online_n|

预先指定的新主方法为 `paired_ns`。支持空间与选头消融分别报告，不按测试成绩改选主方法。共有 9 个新训练配置，均训练 3 轮，以原 100 例开发集的自主路径准确率选轮；并列取较小编辑量，再取较早轮次。

`paired_n`、`paired_s`、`paired_ns` 和 `online_n` 均以当前头表示作为参考，只需一次末位置评分。两侧原始配对的 CE、保持/翻转损失与原版病例监督共同训练。各配对类型按类型平均；实际配对数从 `data/pairs.jsonl` 读取。F_same 修改当前条件涉及的数值字段，同时保持条件真值和祖先条件不变。

## 数据和对照

MEGA 沿用 200 例训练、100 例开发、7,458 例官方测试。旧测试集已用于历史研究，因此不称为新的盲测。P0 固定金标准路径的总分母为 45,627 个节点，复用已保存的节点分数，只补缺失项。标准路径指定评估位置，标签不进入提示。

MedGUIDE 保留原题提示和选项，属于原生选择题迁移；题目提示中没有完整指南树。辅助参考仅使用 `profile`，不用 `path`、`answer_text` 或答案。没有选项映射的 profile 不作为独立直接读取参考基线。

校准使用每任务一个加性偏置：MEGA 修正“是”的 logit，拟合数据为原训练节点；MedGUIDE 修正 A 选项的 logit，使用另选的 200 题校准病例。该对照只代表这一具体单参数校准形式。

MedGUIDE 原 200 题覆盖 53 个页面、17 个疾病家族，已经属于探索样本。扩展数据排除这些题目，并与校准病例按疾病家族分开；当前配置包含 4,955 道扩展题、9 个扩展家族。已有试测或新版配对编辑器在 200 题上超过完整阅读时，才启动扩展评测，且同时评测所有预设方法。未触发时报告为“跳过”，不能把待评测数据规模写成已完成分母。

## 统计和结果

- MEGA 按指南来源聚类；MedGUIDE 按实际出现的疾病家族聚类，试测和扩展集的聚类数分别计算。
- 直接比较使用 20,000 次来源 bootstrap、整来源配对置换和病例级精确 McNemar。逐项消融区间不作为经过多重比较校正的确认性结论。
- 固定节点结果和自主路径结果分列；首错节点纠正不等于整条路径纠正。
- 训练、选轮及推理代码保存逐例分数、纠正和新增错误。节点 gate 与编辑量是所编辑头的平均值。
- 报告只把完整分母的方法列入成绩表。未开始、部分完成以及条件跳过均明确标记。

主要入口：

```bash
source /home/gcx/gcx261014/bin/activate
python -m experiments.aster_m3_followup.controller
```

控制器先并行执行新版训练、节点补评与校准，再完成已有方法试测、全量评测及报告生成，使用保存记录续跑。稳定运行后无需人工持续监控。

CPU 报告复算：

```bash
CUDA_VISIBLE_DEVICES='' python -m experiments.aster_m3_followup.report
```

`--final` 只表示请求最终汇总；实际缺少计划结果时仍返回 `in_progress`。完整结果见 [REPORT.zh.md](../../results/aster_m3_followup_20261107/REPORT.zh.md)，直接统计见 [P0](../../results/aster_m3_followup_20261107/p0/REPORT.zh.md)，配置见 [configuration.json](../../results/aster_m3_followup_20261107/configuration.json)。

完成后，控制器将汇总、压缩逐例结果及同步文档推送至独立分支 codex/aster-m3-p0-p3-20261107。模型权重、原始输入与运行日志保留在服务器。
