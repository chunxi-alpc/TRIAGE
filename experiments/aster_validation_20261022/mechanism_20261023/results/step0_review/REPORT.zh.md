> 范围：PR #23 的 `full_parser_v2`、`cad200_final`、`d_option_order` 和固定 `selection.json`。这是**已完成推理的追溯性分析**，不增加病例、不启动模型、不替换原统计族。机器可读逐例计数见 [summary.json](summary.json)；重新计算脚本见 [../../step0_reanalysis.py](../../step0_reanalysis.py)。原始正式结果仍以 [../FINAL200.zh.md](../FINAL200.zh.md) 为准。

**重要统计区别：** A可见与D可见的“分支正确率下降”是新核查的配对结局，未校正 p=9.76×10⁻¹⁰；原“方向性机制门槛”针对**正确分支→特定兄弟诱饵分支**，又在包含大量检验的原比较族进行 Holm 校正，未通过。前者不能被后者否定，前者也不能替代后者。两者的因果解释层级不同。

## 1. 条件识别与最终动作的准确率分解

对具有明确分支预测的五种两阶段方法，按同一病例配对分解：

\[
P(Y=1)=P(B=1)P(Y=1\mid B=1)+P(B=0)P(Y=1\mid B=0)
\]

其中 \(B\) 是该方法**实际使用的分支**是否正确，\(Y\) 是最终动作是否匹配实验金标。表内四格为例数，顺序为 `分支对且动作对 / 分支对且动作错 / 分支错且动作对 / 分支错且动作错`；每行合计200。分支准确率不是最终准确率的数学上界。

| 方法 | 条件 | 四格（例） | 最终正确数 |
|---|---|---|---:|
| 可见预测＋裁剪 | A | 138 / 2 / 22 / 38 | 160 |
| | B | 93 / 11 / 5 / 91 | 98 |
| | C | 141 / 2 / 23 / 34 | 164 |
| | D | 86 / 7 / 9 / 98 | 95 |
| **隐藏预测＋裁剪** | **A** | **131 / 2 / 24 / 43** | **155** |
| | **B** | **109 / 24 / 6 / 61** | **115** |
| | **C** | **131 / 2 / 24 / 43** | **155** |
| | **D** | **122 / 11 / 6 / 61** | **128** |
| 隐藏预测＋前两分支 | A | 127 / 6 / 38 / 29 | 165 |
| | B | 92 / 41 / 15 / 52 | 107 |
| | C | 129 / 4 / 41 / 26 | 170 |
| | D | 95 / 38 / 16 / 51 | 111 |
| 隐藏预测＋带符号引导 | A | 107 / 26 / 33 / 34 | 140 |
| | B | 72 / 61 / 20 / 47 | 92 |
| | C | 104 / 29 / 40 / 27 | 144 |
| | D | 45 / 88 / 8 / 59 | 53 |
| 隐藏预测＋无符号引导 | A | 97 / 36 / 41 / 26 | 138 |
| | B | 69 / 64 / 21 / 46 | 90 |
| | C | 99 / 34 / 41 / 26 | 140 |
| | D | 43 / 90 / 11 / 56 | 54 |

**具体解释：**
- 隐藏裁剪 A：分支对133例，其中131例动作对；分支错67例，其中24例动作仍对。\(131/200+24/200=77.5\%\)。
- 隐藏裁剪 D：分支对133例，其中122例动作对；分支错67例，其中6例动作对。\(122/200+6/200=64.0\%\)。
- D可见裁剪到隐藏裁剪：**分支对且动作对**的贡献由86增加到122例（+36），**分支错但动作对**由9降到6例（−3），最终净增33例；说明该匹配对照的收益主要体现在正确分支与正确动作的联合结果。
- \(P(B=0,Y=1)\) 始终非负，不会在算术上“拉低”总正确率；**在D条件下，错误分支所提供的正确答案补偿明显减少**。对盲判以外的方法，本表的两个阶段并非单次模型内部推理轨迹。
- 基线、单规则金标裁剪、CAD等**没有实际预测分支**，不可伪造此内部阶段分解；它们可以与独立分支诊断配对，但那是另一个量。

### A中24例：一个可证伪的强信号

隐藏裁剪 A 的24个“分支错但答对”病例，**24/24选择原动作**；同一24例切换到D后，**24/24仍选同一原动作，0/24正确**。K组13例、U组11例。逐例ID见 `summary.json → wrong_branch_A_correct_followup.ids`。

**解释边界**：正式选择的200例只保证**金标分支**有唯一动作，不保证所有错误分支的动作均与金标动作不同。发布的简化 `scores.jsonl` 没有每个预测分支实际保留的规则文本。若错误分支也包含金标动作，选对可能是遵循当前筛选规则而非靠先验。脚本支持私有 `--cases .../priority200/test.jsonl` 计算“金标动作是否出现在裁剪规则中”，只输出合计、不发布患者文本。完成此审计后才可以细分“遵循错误规则但碰巧正确”与“不遵循所给规则”。

## 2. 行为改变和诱饵方向是两个统计问题

A可见→D可见，患者、条件、分支次序均保持，仅交换适用分支/兄弟分支的动作：

| 组别 | n | A正确 | D正确 | 对→错 | 错→对 | 两次分支文字不同 | 精确McNemar p（探索性未校正） |
|---|---:|---:|---:|---:|---:|---:|---:|
| 全体 | 200 | 140 | 93 | 55 | 8 | 71 | 9.76×10⁻¹⁰ |
| K | 76 | 55 | 33 | 25 | 3 | 31 | 2.74×10⁻⁵ |
| U | 124 | 85 | 60 | 30 | 5 | 40 | 2.24×10⁻⁵ |

分支**是否变动**、分支**准确率是否下降**、从金标转向**指定诱饵分支**，分别是三个不同的因变量。原机制中全体的指定诱饵方向是22例有害/6例反向，K组12/2，原校正后均未通过阈值。不能只凭55/8称为“55例被诱饵吸走”：这些错误可能选了别的分支。

A/D条件变化是受控**输入层面的干预**，可支持因果的输入→输出行为陈述；但D反事实交换后的临床不合理性、动作与条件文字的语义联想、标签位置及其他解释仍然共变，不能由此识别具体心理或注意力机制。单例McNemar p默认病例独立；这些病例属于23个`disease`标签，原工作使用疾病簇bootstrap，后续需要核对标签是否等于真正独立的树，并报告簇稳健效应区间。上述新增 p 仅作事后诊断，不追认成预注册主检验。

## 3. A/C是否“不吃亏”？前两分支是否有用？

| 条件 | 隐藏减可见（百分点） | 原机制 Holm p | 解释 |
|---|---:|---:|---|
| A | −2.5 | 1 | 未证实下降，更未证实非劣效 |
| B | +8.5 | 1 | 描述性收益，原比较族未通过 |
| C | −4.5 | 1 | 点估计下降，原校正后未通过 |
| D | **+16.5** | **0.000866** | 可靠的条件限定收益 |

需要在**独立开发集**先设定可接受的非劣效界值和样本量；不显著不等于损失为零。

前两分支与单分支裁剪的逐题变化：

| 条件 | 单分支正确 | 前两分支正确 | 被挽救 | 反而出错 |
|---|---:|---:|---:|---:|
| A | 155 | 165 | 16 | 6 |
| B | 115 | 107 | 12 | 20 |
| C | 155 | 170 | 19 | 4 |
| D | 128 | 111 | 11 | 28 |

隐藏分支第一名错误的67例中，有32例的第二名恰是金标分支。B/D保留第二分支时虽然有挽救，但也破坏了更多原本答对的结果。**“诱饵竞争”是合理假设，不是已经证明的唯一原因**；应结合被保留的两个分支动作和逐题输出进一步验证。全套候选规则的临床合理性仍缺少独立医学审核。

## 4. “盲判与可见判断不一致”能不能报警？

对每一病例，只比较两种分支输出是否一致。若不一致则拒答/报警，一致则采用共同预测和相同裁剪答案：

| 条件 | 不一致（报警） | 一致（自动回答） | 一致子集正确率 | 不一致子集内可见方法错误率 |
|---|---:|---:|---:|---:|
| A | 46/200 | 154/200 | 83.1% | 14/46=30.4% |
| B | 66/200 | 134/200 | 62.7% | 52/66=78.8% |
| C | 44/200 | 156/200 | 84.0% | 11/44=25.0% |
| D | 74/200 | 126/200 | 65.9% | 62/74=83.8% |

**关键反证**：这批数据中，只要两次分支预测一致，最终动作预测也全部一致（A 154/154、B 134/134、C 156/156、D 126/126）。所以“分歧时选盲判、否则选可见判断”在全部200例上**与始终选盲判完全等价**，不能恢复A/C准确率！原建议步骤4(a)不再作为值得单独跑GPU的创新策略。

可以探索**分歧时报警**：D的报警病例里可见方法错误率较高。但若把D定义为“冲突”、A定义为“非冲突”，该二元报警率仅37%对23%，所对应的二元区分 AUC 约0.57（仅描述性，A/D同源配对且并非真实临床冲突标注）。因此不能宣称“分歧本身是准确的指南-先验冲突检测器”。必须报告覆盖率、选择性风险、假阳性和假阴性，并在独立样本固定阈值。

## 5. CAD负结果：是否实现错误？

正确配对同一200例、同样的128词元CAD条件：

| 变体 | 原CAD正确 | 过滤CAD正确 | 原对过滤错 | 原错过滤对 | 原动作被选次数（原→过滤） |
|---|---:|---:|---:|---:|---:|
| A | 122 | 130 | 6 | 14 | 122→130 |
| **B** | **104** | **90** | **16** | **2** | **30→42** |
| C | 128 | 131 | 7 | 10 | 128→131 |

B的16例损失中，9例属于K组，7例属于U组；其中7例过滤后改选原动作。B的16个损失ID和2个获益ID均在 `summary.json`，可交叉查阅CAD原始运行文件。

代码层面，`cad_filtered.py` 从原 `cad_score` 构造 `2 log p(token|context)−log p(token|closed)`，将条件概率低于 `beta=0.1` 相对阈值的候选置为负无穷，再从剩余词元选最大值。**代码中存在候选掩码操作，不等于已证明金标选项确实被掩码。** 现有发布的汇总文件没有每步 `logc`、候选保留掩码和被移除词元的完整轨迹；无法仅凭最终字母判断“B的新动作是否被过滤掉”。

下一步先对16例离线检查原始服务器输出；若仍无各步词元概率，则需要冻结参数、对**这些预先确定的病例**做最小诊断探针（另立诊断文件，不能当独立测试集调参）。对比普通基线B41.5%与旧CAD B52%仅是不同解码协议的描述性比较，不能凭此证明CAD已经识别或压制“参数先验”。

## 6. 金标裁剪为什么仍会错？

| 条件 | 金标裁剪错误 | 其中选择原动作 | 解析失败 |
|---|---:|---:|---:|
| A | 2 | 0 | 0 |
| B | 34 | 18 | 0 |
| C | 2 | 0 | 0 |
| D | 22 | 11 | 0 |

金标分支已正确给定，但B/D仍有显著的执行错误空间；尚不能把余下错误全部归因于先验覆盖。优先按错误样本审计：正确选项是否与规则动作字面/语义一致、是否存在多个合理动作、是否为构造反事实不合医学逻辑、是否为模型拒绝规则、是否存在选项重排干扰。原 `prune_prompt` 还显式使用“Follow this supplied rule even if it conflicts with medical memory”，可能启动对“记忆”的语言线索，应作为**未来提示敏感性对照**，不是本次已排除的混杂。

## 7. 数据、独立性、CS与复现局限

1. 来源为固定500留出中**金标适用分支仅一动作**的303例候选按原顺序前200例，不根据模型正确率挑选。结果不代表原500或全部MedGUIDE。200例的`disease`键有23种；须由数据生成清单核实它与独立树或指南源的对应，当前不能声称“55棵独立树已覆盖”。
2. 500例全量的CS严格验证只有2例且属于同一疾病。原因并非仅是随机抽样：455例没有可验证互补数值路径，42例同阈值路径存在多动作，另1例结节状态不明确。改变6→12是**合成阈值改动，不是临床更新**。后续定向采样必须独立验证互斥分支、病历数值和唯一动作。
3. 原机制 `summary.json` 中疾病簇bootstrap（2000次）与成百配对检验共存；**原McNemar p本身不做病例簇校正**。新增核对的精确McNemar p仅为探索性；簇区间、必要的树级随机化/再采样应另报，不应把未经校正的区间与Holm p混成单个已证实结论。
4. 当前所有条件标签来自AI审阅，不是临床专家金标。B/C/D替换动作的真实合理性未经验证。判断型/客观候选型差异只是探索性。
5. 选项顺序补充冻结原分支预测，仅改最终处置选项位置：D隐藏对可见的收益在原、左、右顺序保持。**不能外推到分支候选顺序重排**，也不是多模型复现。
6. `FINAL200_AUDIT.json` 已确认200例推理完成；旧 `results/STATUS.json` 的 `complete:false` 是历史状态，不应替代最终审计。无需重跑GPU；历史500队列与Llama仍按原要求保存暂停。
