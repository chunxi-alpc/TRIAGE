# FlexAttention 实际工程验证

服务器PyTorch 2.8.0+cu128，GPU6。12组FP32/BF16、GQA、因果/盲判/硬门控/软分数对照通过；三层传播中受保护位置的最大变化为0。

Qwen3-8B和Llama3.1-8B各1条开发输入、4种模式，共8次接口对照，答案选项全部一致。最大选项概率差为 0.034875；没有宣称BF16逐位相同，也不据此声称性能或效率提升。完整数值见results.json。

本次成功运行耗时 46.65 秒，峰值已分配显存 30.30 GiB。之前缺少Python.h的编译尝试未计入成功运行耗时；头文件仅提取到本实验目录。

复现：`bash experiments/aster_e0_e8_20261024/run_flex_validation.sh`。当前后端只用于单条无填充的完整序列。既有Engine和锁定性能实验未替换；SEKA/头选择尚未实现。
