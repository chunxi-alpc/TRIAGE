## 数据与实际实施

- train 288 例／12 个规则家族，dev 96 例／4 个家族，confirmation 192 例／8 个家族；沿用 PR #9 划分。
- dev 有 12 个标准配对、全部表述 36 对、16 例目标规则 U；confirmation 为主要 24 对、全部表述 72 对、32 例目标规则 U。每臂保留完整分母，错误和无操作均不删除。
- Qwen 使用原环境和本地 Qwen3-4B-Base，36 层、32 查询头、8 KV 头、BF16。分数偏置只修改指定层的最后 1 或 16 个因果可见查询行，T 动作加分、F 动作减分、U 动作不动；不编辑答案 logits。未选查询的输出沿用原 SDPA。
- 无结构提示臂保持原始完整提示，参考状态只决定掩码；E 额外通过参考证据位置决定掩码。没有从提示删除分支或动作。
- 每例保存目标字符位置与词元位置、实际 QK 分数前后与变化范围、实际 softmax 注意力质量、四候选 logits、正确答案相对最强错误答案的 margin、最终预测和耗时。注意力前后是同一次前向、同层在局部编辑前后的对照；最终 margin 另与原始无编辑基线比较。
- 仅一次小样检查：动作词元定位正确，实际正负分数变化约 +1/−1；零强度预测相同，候选 logits 最大差 0.125。手动重算查询行与 SDPA 存在 BF16 数值差异，不能把小幅变动解释为稳健收益。没有逐例重复零前向、扰动匹配、置信度门控或四头同号门控。

## 失败分析与解释范围

基线主要24对中有16对在条件变化前后仍输出同一字母；C为15对、E为13对，且主要配对仍全部失败。仅参考结构提示降为4对不变并达到15对正确。E的非适用病例只正确10/80，未知病例17/32；干预没有解决分支转换和未知处理。结构提示的主要作用不能被归入注意力编辑收益。

所有65个保存的阶段臂分母完整、无技术失败；重复基线和复用直接偏置已明确标识。逐例错误与纠错/破坏在 `analysis_outputs/errors_and_changes.jsonl`，分家族、表述、T/F/U指标在 `all_arm_metrics.json`，动作混淆和配对不变记录在 `failure_analysis.json`。这些是已保存输出的分析，不是额外模型实验。
