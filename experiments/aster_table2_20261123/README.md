# ASTER 表2补测

实现正文第3节的自适应M1、层级加权M2和无约束岭读出诊断。正则系数按开发集A/P加权平方残差选择，随后固定参数评价受控留出集。

入口：
- prepare.py：复用全头激活，按来源五折生成M1候选及匹配对照，整理已有和缺失修补分数。
- worker.py、suffix.py：在GPU 0、1、5、6上补算缺失的逐头单向分数；后缀重放保持单输入和原计分精度。
- finish.py：按来源效应选择头、拟合层级加权子空间、选择λ，并输出开发和留出指标。
- metrics.py：权重、岭回归、未中心化R²和证据覆盖残差定义。
- report.py：回填主稿表2、附录表C15，并输出报告和数值表。
- controller.py：启动四个GPU进程，等待退出后自动完成CPU统计及文稿更新；--publish将本分支提交并推送。

环境为/home/gcx/gcx261014，工作目录为/home/gcx/aster-table2-20261123。配置及输出见[实验目录](../../reports/aster_table2_20261123/)。原始输入、激活和修补缓存保留在服务器。

本任务评价M1/M2与无约束岭诊断；受约束M3、概率校准和路径任务实验按主稿各自配置记录。
