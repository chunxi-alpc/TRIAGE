# 模块二机制预实验：共享方向、在线迁移与双向读取

版本：2026-10-28；本文件在本轮研究前向前固定。方法依据 main `e3d2bfb8da539c15527d607c155af73e44788eeb`。

## 目标与主张

本轮验证模块二最直接的三个主张：训练方向在未参与拟合的规则上是否保持有向变化；该方向能否迁移到指南前置的在线查询；固定正负增益能否控制规则读取。受约束 A/B 编号选择是次要终点，处置生成、模块一预测和完整系统不属于本轮实验。

这是开发集上的机制预实验。复用前轮已经公开的 12 个指南及划分，不称作新的盲测或独立测试集；本轮重新采集全部模型表示和指南前置编辑结果，不将旧患者前置结果改名。

## 与当前正文对齐

离线保持患者→问题→指南，目标为编号与处置词元的并集。三状态逐一验证目标 token ID、绝对位置和总长度；不截断。逐 token 配对差分先取外积，再在一对内部平均，最后最小对等权。

固定秩 `m=2`、最多 `K=4` 个头、`epsilon=1e-8`、投影均值下限 `1e-6`、数值秩相对容差 `1e-8`。投影均值归一化为方向。Sep 使用正文的 `Mean(z)/(Std(z)+Mean(abs(u))+epsilon)`。选头要求 Sep、Read+、Read−分别为正，不增加事后有效性阈值。没有有效头时保存空专家并实行零编辑。

在线改为指南→患者→问题→回答前缀。原指南文本不变，仅移动区块并重算位置。实际完整文本一次分词，在该词元序列上确定指南前缀边界。指南前缀无编辑预填充，按患者复制独立缓存视图，编辑后处理完整患者/问题后缀。不是只在最后一个查询前编辑。

## 指标与分析

1. 方向：未见规则 `Delta^T mean_j(k+−k−)`、余弦和正向比例；按指南、处置映射、顺序报告。配对 A/B 的差分相加/相减，区分规则相对变化与共同患者事实响应。它是更强的相对对照，仍不声称消除了全部语义混杂。
2. 在线迁移：Read+、Read−和逐样本/逐共享查询头符号分布，患者前置与指南前置对照。选头只使用选择集，确认集不参与排名。
3. 双向读取：正确规则与错误兄弟规则的注意力质量、`log(M_gold/M_other)`，分别报告两名事实相反的患者；各头及全选头均值保留。
4. 次要决策：A/B 编号准确率、两患者均正确比例、正确编号 logit margin、纠正和由对变错数。不是自由生成或处置执行。
5. 机制补充：枚举 6 个训练指南的 64 个成组符号配置，只检验有向均值；外积谱不变，不将其冒充谱显著性检验。选择规则和检验单元明确保留，结果不用于再选方向。

描述性区间以指南为重采样单元；只有 3 个确认指南，区间条件于当前冻结模型和算子，不提供跨模型或全临床任务保证。全部方法/固定增益保留，无最佳测试剂量选择。

## 示范样本的预定选择规则

一组示范包含相同指南、处置映射、顺序下的两名相反患者。按 `projected/both/gain=4` 的两患者最小 `Delta log(M_gold/M_other)>0` 定义双向读取成功。

- 典型：成功组中最小效应最接近成功组中位数者。
- 强效：两患者最小效应最大的组。
- 边界：全部组中最小效应最小且与前两例不重复者。

并列以稳定 case ID 排序。没有成功组时明确报告，不改变规则寻找成功。样本是解释性挑选，不作为总体收益估计；全部 12 个候选病例对及排名一起保存。每个示范同时显示编号输出是否改变。
