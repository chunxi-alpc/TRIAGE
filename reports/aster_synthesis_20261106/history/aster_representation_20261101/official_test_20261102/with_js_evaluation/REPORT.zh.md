# 含 JS 损失的处置盲内部干预评测

比较第18层、秩4、第3轮的两个冻结检查点。`full` 训练时使用额外的 JS 分布一致性损失，`no_js` 是论文主方法。两者均使用原指南和处置重排后的分支监督。

MEGA-CDP 官方测试划分包含7,458例、418个来源簇。每例均已保存两种方法的结构化路径和终点处置。完整路径、英文与中文 BERTScore 三项指标均按全部7,458例汇总。

| 指标（%） | 含 JS | 无 JS | 含 JS 减无 JS（百分点）及95%来源簇区间 |
|---|---:|---:|---|
| PathAcc ↑ | 88.13 | 89.21 | -1.07 [-1.73, -0.36] |
| DTW-PCC ↓ | 77.21 | 77.15 | +0.06 [+0.01, +0.10] |
| OT-PCC ↓ | 79.79 | 79.78 | +0.01 [-0.01, +0.03] |
| LNDS-PCS ↑ | 52.10 | 52.18 | -0.09 [-0.19, +0.02] |
| 结论语义 Acc ↑（有效评分子集） | 87.86（n=1,549） | 85.98（n=1,701） | 两列覆盖不同 |

含 JS 选对 6,573 条完整路径，无 JS 选对 6,653 条。加入 JS 后，163 例从错变对，243 例从对变错。两种方法的技术失败和无效输出均为0。完整路径的终点通过同一棵规则树查表得到。

共有 7,378 例复用同一病例、相同步骤序列的 BERTScore 结果。其余 80 例复用 4,465 个已打分步骤对，补算 1,721 个。英语编码器为 RoBERTa-large 第17层，中文为 BERT-base-Chinese 第8层，匹配阈值0.2，路径汇总沿用论文代码。差值区间按来源簇重采样2,000次。

结论 Acc 沿用论文表1对照行的口径。含 JS 在同一病例上产生的步骤和结论与已获评的主方法相同时，复用同一裁判的五次有效评分。两种方法在这 1,549 个相同输入上的 Acc 都为 87.86%。因此上表的两列 Acc 不能用来估计 JS 的净收益。无 JS 列按本次存档重新汇总，论文表1的历史截面为86.16%（n=1,690）。
