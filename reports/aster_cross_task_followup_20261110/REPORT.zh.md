# 固定 MEGA 头：截距诊断与修正训练结果

本轮为已看过既有测试结果后的探索性后续实验。结论与参数均按保存的结果文件整理；没有按测试集成绩重新选参。

## 主要结论

- 截距解释了部分配对正确性下降。MedPIC 开发集原模型为 11/44，原 C 的自然截距下两个版本均为 8/44。tail_pair 换源任务截距或零截距可恢复至 11/44；tail_robust 四种截距中最高为 9/44，因此不能把全部下降归因于截距。
- 增加标签改变对分类监督（G1）没有带来稳定准确率提升。MedPIC tail_pair 相对 G0 提高 1.06 个百分点，95% 区间为 [−1.55, 3.65]；其他 G1 对 G0 比较持平或下降。
- 删除标签改变对修正惩罚及训练后幅度缩放（G2）后，整体准确率没有改善。NLI4CT 的干扰降低率达到 92.01%，但证据响应保留率降至 35.13%，测试正确数从原模型的 378/500 降至 366/500。
- MedPIC tail_robust 的 G0、G1 均选中增益 0、源任务截距 0.140；其 71/188 来自截距调整，没有获得网络修正收益。
- 保留负结果：NLI4CT G1 tail_pair 相对原模型下降 2.20 个百分点，95% 区间 [−4.47, −0.21]；G2 两版本均下降 2.40 个百分点，区间 [−4.85, −0.22]。这些下降的区间完全低于零，不能表述成“所有差值区间都跨零”。

## 实验设置

保留 NLI4CT、MedPIC 的既有划分、51 个 MEGA 头、99 维输入、128 宽度、既有特征投影、标准化和解码。三个种子为 11、22、33，等权集成。每个新增训练从对应 C 初始化检查点与原初始化增益出发，训练 1,200 步，学习率 0.0003，权重衰减 0.001。

|组别|训练与选择|
|---|---|
|G0|复用原 C 已训练网络，仅重新选择输出增益和截距|
|G1|原损失增加权重为 1 的标签改变对 BCE，保留原保护项与训练后幅度缩放|
|G2|与 G1 相同，但删除标签改变对修正惩罚及训练后幅度缩放|

新增标签改变对 BCE 按病例组均衡，每对两侧各占一半；不加入同标签患者变化对 F0。MedPIC 两侧已属于自然拟合样本，因此是增加监督权重；NLI4CT 同时补入原自然 BCE 未覆盖的陈述变化样本。其余无关干扰损失、自然 BCE、初始化锚定项保留。G2 删除版本特有保护项后，两版本的训练目标相同，仍分别训练并按各自候选增益选参。

每个任务、组别和版本独立在开发集选定配置，再评价测试集。增益候选为 0、0.25、0.5、0.75、1，另加入对应原 C 增益；每个增益搭配源任务、自然样本、联合、零截距。源任务截距取对应版本的 MEGA 原截距；自然截距沿用既有自然拟合样本平均 BCE；联合截距的自然样本和标签改变对各占一半，两部分分别按病例组均衡。所有新估计截距只用拟合集。

开发集标签改变对全对数下限为 NLI4CT 44/66、MedPIC 11/44。合格候选按整体正确题数、标签改变对全对数、干扰降低率、更小增益、更小截距绝对值依次选择。增益 0、截距 0 始终保留为原模型候选。所有选定配置均满足开发集下限；测试集不保证维持该下限。

全部在服务器 gcx261014 环境运行。24 次新增训练使用物理 GPU 6，完整运行约 1.77 分钟；稳定运行时观察到进程显存约 534 MiB。截距诊断与评价使用 CPU；没有重新选头或运行大模型。

## 指标与验证

干扰降低率为 1 − 修正后无关对分数差方差 / 原方差；证据响应保留率为按标签改变方向加权的分数差总和之比。证据修正 RMS 是标签改变对上的修正分数差 RMS，不受截距影响；机器结果中的 correction_rms 则包含最终截距。证据响应保留率接近 100% 不代表回答更正确。

既有 A/C 分数已复现，最大绝对误差小于 4.4×10⁻⁶；仅更换截距的配对分数差误差小于 1.5×10⁻¹⁴；增益和截距均为零时精确还原原模型。保存后的推理接口也与批量分数一致。
