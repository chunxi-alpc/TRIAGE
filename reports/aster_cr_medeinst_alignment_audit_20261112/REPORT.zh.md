# ASTER-CR：MedEinst F 与 MEGA F 兼容性审计

审计日期：2026-11-12。**建议从核心训练中移除 MedEinst F，改用 MEGA 内部 F。** 当前 4368 对 MedEinst 的实际任务全部是两候选鉴别诊断，不是固定指南条件的真假判断；抽样语义审查还发现大量多事实修改、没有有效证据变化或不足以支持排序翻转的配对。该结论不等于“全部 MedEinst 医学标签错误”，也不否认它作为诊断基准的用途。已确认的 7 对 S2 仅保留为单独标记的跨任务辅助实验候选。

本次完成 4368 对程序普查、600 对完整叙述的 AI 语义审查，以及既有模型产物的只读诊断。600 对包含先行试点 60 对；不是另加 60 对，也不是 4368 对全量医学复核。三个独立上下文各审 200 对，每对只由一个上下文审查，没有重复评分，不能估计审查者间一致性。请求配置为 Astra Extra High、gpt-6-astra、xhigh；精确后端快照和 Pro 服务标识未暴露，没有临床专家审查。未重拟合 M1/M2/M3、运行基础模型前向或使用 GPU；CPU 来源分类器属于审计诊断。总结果见 [summary.json](summary.json)，逐对记录见 [semantic_review.jsonl](semantic_review.jsonl)。

**1．当前 4368 对 MedEinst F 是否与 MEGA F 严格兼容？**

不严格兼容，首先是预测目标不同。MEGA-CDP 原生任务是依据指南生成临床决策路径，包括单轮病例和多轮问诊；ASTER 再从决策树节点构造“当前条件成立／不成立”的二元任务及 A/P/C/F 配对。因此本报告的“MEGA F”是项目内部构造的患者事实反事实，不是原生基准提供的同名类别。[MEGA-CDP 原论文](https://arxiv.org/html/2608.26592v1)

MedEinst 原生任务是输出诊断名称，覆盖 49 种疾病，比较 control 与 trap 的诊断表现，指标包括 control 准确率、两侧全对率及以 control 正确为条件的 Bias Trap Rate。ASTER 从每对两侧发布的正确诊断中取出两个候选，按字典序排序，以第一候选对应“是”、第二候选对应“否”。这是由真值预先缩小候选空间的两候选诊断任务，不能称为原生 49 类或开放诊断。[MedEinst 原论文](https://arxiv.org/html/2601.06636v1)

因而，MEGA 的“是／否”分数表达固定条件成立与否的支持，MedEinst 的同名分数表达两个诊断之间的相对偏好，其正负方向依赖候选字典序。输出词和数值类型相同，不代表目标、概率解释或分数尺度相同；保持候选不变也不足以建立任务等价。

原始链条已追溯：10609 对原始训练数据，经程序筛选剩 10111 对，经历史 Qwen3-8B 有标签审核及确定性排除剩 8228 对，再按 148 个诊断变化类型抽取并冻结 4368 对，最终进入实际拟合提示。历史审核看到了两侧发布标签，且明确允许多事实变化，不能用其“通过”替代本次单事实、先盲审后揭示标签的判断。全部 4368 对的叙述、发布标签、共同候选、二元映射与实际提示均核验一致，未发现转录或映射错误。这个实现层面的完整性不能证明原始反事实标签的医学依据。

发布文件没有逐病例 DDXPlus ID 映射、生成时疾病概率、所用证据条目及专家裁定记录，无法进一步恢复每对原始标签的依据。数据卡写 train 10689 对，实际文件为 10609 对、21218 行；test 为 5383 对、10766 行，两文件总计 31984 行。差额 80 对的原因没有证据解释，本报告采用实际文件分母。[MedEinst 数据卡](https://huggingface.co/datasets/zhui711/MedEinst)；本地来源与代码定位见 [source_notes.zh.md](source_notes.zh.md)。

**2．S1／S2／S3／S4 各占多少？**

S1 要求同为固定条件真值任务、单个决定性事实及受支持的翻转；S2 是固定候选下，单个医学事实足以合理逆转相对诊断支持的跨任务辅助候选；S3 为明确不兼容，如多个独立事实、没有真实证据变化或翻转与证据明显冲突；S4 为事实计数、医学排序或标签支持仍不能确定。S3 是相对于本次使用标准的分类，并非“全部医学内容错误”。

试点后在标签揭示前冻结 v2 标准：一个新症状事件及其内在描述计作一个事实，独立可共存的症状分别计数，重复或释义不增加事实，删除叙述不等于明确否定。S2 不要求每例都有确诊检查，但要求相对支持发生足够清楚的逆转。试点按该口径复核后纳入主审；盲审判断先保存，再揭示标签，锁定判断不因标签改写。详见 [rubric.zh.md](rubric.zh.md)。

600 对按 148 个发布诊断变化类型分层、层内无放回随机抽样，种子 20261112；除已普查的小层外，每层至少两对。各层抽样比例不同，不能直接把样本百分比当作总体百分比。

|类别|样本计数／600|加权总体比例估计|近似 95% 区间|保守的每类别 95% 区间|
|---|---:|---:|---:|---:|
|S1 严格兼容|0|0%|0%|0%|
|S2 跨任务辅助候选|7|1.399%|0.649%–2.992%|0.160%–46.108%|
|S3 明确不兼容|512|82.986%|80.224%–85.432%|42.376%–95.513%|
|S4 证据不足或不确定|81|15.614%|13.105%–18.503%|4.304%–56.777%|

S1 为零由全部 4368 对的实际任务普查确定，不是仅凭样本零命中推算。其余近似区间使用含有限总体修正的分层方差和 logit／delta 近似；S2 只有 7 次命中，不能把其较窄区间解释为具有可靠精确 95% 覆盖率。保守区间使用各层精确超几何界限及 Bonferroni 合并，因小层多而很宽；它们分别对单个类别成立，不是四类别联合同时覆盖区间。两类区间都以当前 AI 分类为条件，不包含医学审查误差或模型共享偏差。[分层估计](stratum_estimates.csv)、[抽样清单](sampling_manifest.json)

另有 3768 对未做语义审查。管理清单把它们暂列 S4，因此全清单显示 S4 为 3849＝81＋3768；这是待审状态，不能解释为医学不确定性的总体发生率。样本中 287 对有多个事实变化，分层加权估计 39.919%；38 对没有新增有效事实，估计 7.450%；143 对标记需要专家判断；2 对被标记存在额外无关背景变化。问题标记与最终类别不是互斥分组，不应相加。具体判断例子见 [examples.md](examples.md)。

**3．MedEinst 能否继续承担 M3 的证据保护？**

不能让全部 4368 对继续代表核心任务的医学证据保护。当前 M3 仅对 A/P 做回归，对 C/F 限制“修正引入的两侧分数差变化”，即限制修正项之差的绝对值不超过预算。它保护的是原模型响应，不直接训练诊断标签正确，也不保证原响应方向正确、反事实足够或任务相同。

当前真正进入约束的 C 635 对和 MedEinst 4368 对，在数值容差内均为零超预算；接触约束边界的分别为 C 10 对、MedEinst 4 对。这支持求解器遵守了既定数学约束。MedEinst 的原始方向与发布标签一致率却只有 73.397%，原始两侧全对率为 22.276%；修正后分别为 73.466% 和 21.932%。这些是当前两候选适配任务、以发布标签计的描述性结果，不是对标签医学真实性的新确认。

7 对 S2 也不能自动投入保护：其中原始方向与发布标签一致仅 6/7，两侧全对仅 3/7；a0373 的盲审支持相对诊断逆转，但模型原始分数方向相反。这不应把其语义分类改成 S3，却说明即使配对机制可用，保持原分数差仍可能保持错误响应。S2 的作用需要单独实验，明确任务和指标；若只让它参与 M3、排除出 M1/M2，应作为独立模块消融，而不是悄悄改变主比较算法。[辅助候选及原始响应](audited_auxiliary_candidates.json)

**4．是否保留全部 4368 对？**

不保留在核心训练中。没有必要为了延续总量 10006 而放宽兼容标准。保留历史清单和结果作为对照、保留原始数据的诊断研究用途，与继续把它们叫作严格 MEGA F 是不同决定。本次已确认 S2 只有 7 对，其余未审数据不能按估计通过比例直接放行；S4 也不能当作已证伪的数据。

程序普查排除了若干简单实现问题：选中训练集与 test 的发布 case_id 交集为零，完整端点文本交集为零，选中集内无完整重复配对。原始 train/test 的 339 个 case_id 交集已在选择前排除。但进一步去掉年龄／性别表头及纯 Markdown 包装、保留其余临床文字和数字后，211 对选中训练配对与 221 个测试病例形成 539 个完全一致的有序叙述模板匹配，诊断变化类型也全部一致；训练内部另有 82 个重复模板组，涉及 218 对。[模板匹配](demographic_template_matches.csv)、[汇总](template_overlap_summary.json)

另一个全文字符 TF-IDF 最近邻检查中，22 个训练配对有相似度至少 0.98 的其他训练配对，9 个有至少 0.98 的测试配对；对应 0.95 阈值为 413、391。这是文本相似候选检索，不是同一患者判定，详见 [near_duplicate_candidates.csv](near_duplicate_candidates.csv)。

前述去除人口学表头后的完全匹配，是已经确认的临床叙述模板跨划分重叠，不是同一患者的证明。年龄和性别可能影响医学判断，去除后相同不等于全部临床信息相同；缺少 DDXPlus 映射也使底层患者重叠不可核验。现有证据不能量化这种模板重叠带来的分数膨胀，更不能推断基础模型预训练污染。MEGA 的 fit 与 dev/test/new60 来源及病例则已在现有元数据范围内核对无交集。需要按已知模板簇补充诊断，而非把“无完整文本重复”写成全面无泄漏。

**5．是否优先使用已有 666 对 MEGA F？**

是。它们覆盖 646 个病例、80 个来源，中文 335 对、英文 331 对；18 对来自历史构造、648 对来自后续生成。全部 666 对均已找到原始病例，病例原文和条件节点匹配，指南及定义保持不变，仅修改患者侧，标签发生翻转；原始侧标签与原始路径记录核对 666/666 一致。149 对保存了程序规则元数据。[程序普查](mega_f_program_audit.csv)、[原始路径标签核验](mega_original_label_check.json)

这些结果使其比跨任务 MedEinst 更适合优先承担固定指南条件下的 F。但这是全量结构与来源核验，不是本次新完成的 666 对全量临床语义复审；修改侧标签仍来自合成反事实及既有审查，不能因此宣称所有医学事实已由专家确认。

现有模型在这个未用于当前冻结拟合的池上重放，59/666 对超过同一修正预算，最大超出 0.3781。池内部分底层病例与已有训练共享，它不是独立测试集；这些配对当时未进入约束，因此也不是求解器违反了已施加约束。这个现象提示应直接保护目标任务的 F，不能作为“MedEinst 已造成损害”的因果证据。[逐对分数诊断](pair_score_diagnostics.csv)

相同绝对预算 0.2923349 的相对含义也不同：MEGA F 的原始分数差绝对值中位数为 55.575，MedEinst 为 3.608；逐对预算／原始差绝对值的中位数分别为 0.526% 和 8.102%。共有一个预算，并不代表两任务获得相同强度或同等临床意义的保护。

**6．当前 10006 对是否存在来源与类别混杂？**

存在明确的设计混杂：A 4368、P 635、C 635 全来自 MEGA，F 4368 全来自 MedEinst。F 与其他类别的比较同时改变患者事实类型、数据来源、提示结构和预测任务，不能单独解释为“事实变化”的效应。

输入结构也不同：MEGA 提示包括完整决策树、指南说明、病例及当前条件，MedEinst 使用英文症状项目列表和两候选指令。原始输入 token 中位数分别为 MEGA F 1606.5、MedEinst 332；长度、语言与格式都可能被模型读取，尚未被本设计单独控制。

来源本身很容易区分：仅检查鉴别诊断指令的格式规则，来源分类准确率为 100%；结构特征分类同样为 100%。用每个原始病例一个端点共 5710 例，MEGA 按指南来源分组、MedEinst 按发布病例分组，做五折分组逻辑回归诊断，冻结 N 坐标上的来源平衡准确率为 99.851%，配对差分 ΔN 上仍为 84.659%。标准化仅在各探针训练折拟合，但被探测的 S/U/N 原来使用全量旧训练数据学习，因此这些值是既有表示的描述性诊断，不是嵌套训练下无偏的来源泛化估计；本次未使用测试标签。原始端点投影到证据 S 和干扰 U 后的来源平衡准确率分别为 100.00% 与 99.89%，也不能单凭可分性证明这些方向有害。[source_diagnostics.json](source_diagnostics.json)

应沿模块解释这种混杂。M1 使用同一配对内的变化归因，不是直接用一个 MEGA 样本减去一个 MedEinst 样本。纯加性的来源常数会在配对差中抵消，任务相关梯度、尺度和医学内容差异则未必抵消。F 与 C 的前 64 候选头重合 45 个，归因向量余弦为 0.774；最终 51 头中没有仅来自 F 候选集合的头。F 的精确干预代表按 44 个原始诊断选择，C 按 80 个指南来源选择；代表的统计单位也不同。因此不能凭来源易识别，就断言“选中的头主要在识别来源”。

M2 的加权均值、尺度以及由 C/F 估计的证据子空间 S 都可能受 MedEinst 影响，并通过后续正交处理影响最终 N。干扰子空间 U 的直接估计只使用 A/P，不能写成 MedEinst 直接参与 U 拟合；但共享标准化和 S 仍可间接改变最终表示。N 保留来源信息也不自动证明干扰修正失效。在当前设计下，来源与任务无法分开，探针不能裁定来源、格式或医学内容各自的贡献。[实现与代码索引](source_notes.zh.md)

**7．混杂是否足以影响论文核心结论？**

足以使一项关键归因缺少支持：不能把旧混合实验直接解释为“在同一指南判断任务中，消除了干扰，同时保护了单事实医学证据”。F 的任务不一致、样本语义资格及尺度差异都触及这项解释。它们不证明全部效果由来源捷径造成，也不证明旧指标是伪造的；本次没有替代拟合，不能声称性能必然提升或下降。

尤其不能把接近 100% 的证据响应保留率当作医学正确率。既有指标为
`sum[(y右−y左)×修正后分数差] / sum[(y右−y左)×原始分数差]`。
它衡量有符号总体响应的相对保留，可能超过 100%，分母接近零时不稳定，也不要求每对方向正确或两侧预测正确。MedEinst 保留率为 99.991%，同时原始两侧全对率只有 22.276%；MEGA F 池保留率为 99.937%，却有 59 对超出预算。高总体比值不能替代逐对约束、方向和准确率。

目前可以保留的结论是：既有约束在训练配对上满足预算，旧模型的各项实测结果仍按原任务和分母成立；来源信息在表示中可被识别，数据结构不支持原先更强的同任务解释。尚待实验确认的是：换成 MEGA F 后，是否改善目标任务的事实保护、路径正确率及新增错误，同时保留 A/P 的修正收益。把这两层分开，比直接宣布“效果无效”更符合现有证据。

**8．下一轮最少、最有价值且最有区分力的实验是什么？**
