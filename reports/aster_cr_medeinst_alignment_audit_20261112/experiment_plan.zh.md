# ASTER-CR 数据来源最小对照实验计划

本文件仅设计实验；本次没有拟合 M1/M2/M3，没有运行基础模型前向传播或 GPU 训练。来源识别的 CPU 逻辑回归只是审计诊断。

## 要回答的问题

在相同 A/P/C、相同 F 数量、同一模型及拟合流程下，来自 MEGA 的患者事实配对，是否比 MedEinst 配对更有效地保护 MEGA 的事实响应，并维持干扰修正收益？另行检验经过本次语义审核的跨任务辅助证据是否有用。两种来源同时具有任务差异，因此来源替换实验识别的是“来源和任务组合”的效果，不能单独识别文本风格的因果效应。

## 三个主要方案

|方案|A/P/C|事实变化配对|总量|解释|
|---|---|---|---:|---|
|E-A：MEGA-only|冻结 A=4368、P=635、C=635|MEGA 合格池的全部 666 对 F|6304|统一指南条件任务的核心方案|
|E-B：MEGA + MedEinst|同上|冻结 4368 对 MedEinst；复用原清单和权重|10006|历史混合方案；保留历史结果|
|E-C：审核后的混合数据|同上|仅本次已逐对确认的 S1/S2；记总数 K|5638+K|S1 标记为核心 F；S2 标记为 F_aux，单列任务和结果；S3/S4 排除|

E-C 是检验辅助数据价值的研究对照，不是预先认可的核心训练方案。S1 为零时，E-C 不具有来自 MedEinst 的严格 MEGA F；不得把 F_aux 改名为严格 F。审核未覆盖的 3768 对也不能依据抽样通过比例进入 E-C。K 的具体清单见 `audited_auxiliary_candidates.json`；若 K=0，E-C 记为“无合格配对，不能按原设定拟合”，不复制样本填补。

为比较数据选择本身，E-C 数值拟合时沿用现有四组的计算流程：A、P、C，以及“事实变化约束组”。后一组中 S1 与 F_aux 的语义标签始终分开保留，类内仍按数据集、来源、病例、变体分摊。这样可比较相同算法下过滤前后的效果；不能据此宣称辅助任务等于指南任务。若希望把 S2 限于 M3 而不进入 M1/M2，那是另一项模块消融，不混入本轮三个主要方案。

## 必须增加的样本量匹配

1. **优先完成 E-A666 与 E-B666**：两者均保留全部冻结 A/P/C，F 各 666 对，总量均为 6304。E-A666 就是 E-A；E-B666 从冻结 4368 对中，按发布诊断变化分层、固定种子 20261112 无放回抽取 666 对。它与 E-B10006 分开命名，不能替代或覆盖 E-B。
2. **过滤效果比较 E-AK、E-BK、E-CK**：令 k=min(666,K)，分别取 k 对 MEGA F、未经过本次语义筛选的冻结 MedEinst F、已审核 S1/S2，三组均为 5638+k 对。同样固定分层规则及种子；不重复采样扩容。K 很小时，这只提供小规模辅助证据对照，不能用其结果宣称充分验证。
3. 主比较先用 20261112。若启动完整样本选择稳健性检查，预先固定 20261113、20261114 两个附加抽样种子，并完整报告三个种子；不根据测试结果挑种子。测试集保持不变。

**最少且最有区分力的下一步，是两个新的拟合：E-A666 和 E-B666。** 历史 E-B10006 直接复用。只比较 E-A6304 与 E-B10006 会把数量变化与来源变化混在一起，因此不作为来源效应结论的唯一依据。


样本量匹配的具体配额规则：每个集合按其可用分层的总体比例，使用最大余数法分配 k 个名额，层内固定种子无放回抽取。MEGA 按指南来源分层，MedEinst 按发布诊断变化分层；配额允许为零，不强求在 k=7 时覆盖 80 个来源或 148 个诊断变化层，也不沿用本次审计“每层至少2对”的规则。目前 K=7，E-C 共 5645 对，E-CK 使用这7对全量；E-AK/E-BK 也各7对。该小对照不能独立支撑总体来源优劣结论，优先级低于各666对的主比较。

## 固定条件

- 基础模型：复用服务器同一只读目录 `/home/gcx/TRIAGE/models/modelscope/Qwen3-8B`，模型参数不训练；BF16 前向、同一 tokenizer、system prompt、聊天模板、上下文限制、单输入批形状、最终位置和 FP32 输出投影。现有 config/tokenizer_config 未记录上游模型 revision；不能补写一个假 revision。实施时使用同一现有模型目录及已有版本记录，在所有方案中复用同一实际权重，不重新下载或升级。
- 每组独立重做 M1/M2/M3；不把 E-B 的已选头或子空间当作 E-A 的结果。M1 固定 51 头、每类归因前 64 候选、相同双向精确干预、A/P 与 C/事实变化组的合并排序。MEGA 代表按来源选择，MedEinst 按原始诊断选择；这些规则不因结果改变。复用原始激活/精确干预缓存可以，复用另一组学到的头排序不可以。
- M2 固定 rank=16、相同加权标准化与 SVD、相同数值设置；A/P 各占干扰估计的 1/2，C/事实变化组各占证据估计的 1/2。S1/F_aux 只在计算分组上共用接口，不混同监督语义。
- M3 固定正则项 0.01，绝对预算 0.2923349，逐对约束，相同求解器与容差；A/P 回归总权重 4887，A/P 各 2443.5。主实验不按新结果重调预算。另报告相对预算 delta/|原始分数差|，揭示相同绝对预算的尺度差异；它不是新增超参数。
- 总体类质量各 25%，类内按现有数据集—来源—原始病例—变体规则。组间来源总质量因来源配置本身变化，这是实验因素；不能强行给 MEGA-only 添加虚拟 MedEinst 权重。硬证据约束没有可通过平均权重抵消的样本量效应，这也是数量匹配的理由。
- 自然节点截距使用相同 761 个 MEGA fit 节点，独立重新估计；测试标签不参与。截距是 MEGA 校准，MedEinst 的字典序“是”不能视为同一种患病概率；其诊断准确率另列。
- 相同来源划分：沿用已有 MEGA 来源划分；本轮核对未发现 fit 与 dev/test/new60 的来源或病例交集。MedEinst 依据发布 case_id 和本次识别出的模板簇分组记录；不把未知 DDXPlus 患者映射当作已验证。
- CPU 诊断不是上述实验的训练结果。正式执行前再向用户报告 GPU 0/1 的占用、显存、规模和时长；本次不启动。

## 评价与固定分母

主评价首先复用冻结 MEGA test。A/P 的连续分数指标分母 2293 对（A 2283、P 10）；C/F 分母 40 对（C 33、F 7）。自然节点准确率分母为已有的 372 个有标签节点，**不是全部路径中的节点数**；自然完整路径 806 条，干扰路径 2418 条。所有组使用同一 ID 清单；原始与新预测有任一缺失时先报告缺失，不更换分母。

MEGA new60：自然节点有标签分母 4928，总输入节点 15839，其中 10911 无标签，不能纳入准确率分母；自然路径 802，干扰路径 2406。连续 A/P 分数指标可包含冻结清单中的无标签配对，但准确率只使用其有标签子集；两种分母分开写。MedEinst 5383 对仅作跨任务诊断评价，报告两候选口径；其中的模板重叠在固定主结果之外作预先定义的分组诊断，不悄悄删除测试病例。

每个方案报告：
- A/P 分别及合并的方差降低率：1−Var(d_corrected)/Var(d_raw)，同时报告 RMS 和方差分母。
- C、MEGA F、MedEinst F_aux 分别的修正 RMS、证据响应保留率、超过预算比例、原始方向一致率、两侧全对率；禁止只给合并 C/F 一个高保留率。
- 保留率沿用 sum[(y_right−y_left)d_corrected] / sum[(y_right−y_left)d_raw]。同时给原始分母，接近零时不解释该比值；它可能超过 100%，并非临床正确率。
- 自然节点、自然路径、干扰路径准确率；修复错误和新增错误给出共同原始模型及 E-B 的逐项转移计数。路径是整体路径正确与否，节点和路径错误不相加。
- 同一条目配对比较，MEGA 按指南来源簇做 2000 次 bootstrap；MedEinst 同时给发布病例簇及已发现模板簇的诊断区间。模型审查误差不包含在这些区间中。

test 中严格 F 只有 7 对，不能用其接近 100% 的保留率支撑广泛的事实响应结论。利用现有 80 个 MEGA fit 来源及其 666 对 F，补充已有五折来源验证：各折仅用训练来源独立拟合，验证来源从未用于该折 M1/M2/M3；保持 A/P/C 同源分割。666 对全池的本次重放只是训练池诊断，不能当成新的独立测试集。已有测试已多次使用，下一轮也应标记为冻结重复评价，而非首次确认性评价。


次级迁移评价沿用原冻结项目，不因本次审查换题：NLI4CT 为 500 个原生判断；MedPIC 为 188 个原生问题、940 个二元输入，原生准确率与二元输入错误不能相加；MedCounterFact 为 198 个原始问题、789 个替换变体、91 个综述来源簇，原有上下文长度排除保持。new60 的连续 A/P 分数指标共 47532 对，其中 14799 对有标签、32733 对无标签。完整冻结分母见 `evaluation_denominators.json`；所有方案复用同一评价 ID 清单及其原生评分定义。

## 结果判定

若 E-A666 在 MEGA F 修正、超预算及新增错误上优于 E-B666，且 A/P 稳定性及路径准确率未出现相应退化，支持改用 MEGA 内部 F。若二者相近，仍不能把 MedEinst 的诊断监督改称同任务监督；只能说明该规模下替换效果有限。E-C 若改善辅助诊断指标但未改善 MEGA F，只支持跨任务辅助用途。任何情况下，都不因需要保持 10006 对而降低 S1/S2 标准，也不根据测试效果重新修改本次语义分类。
