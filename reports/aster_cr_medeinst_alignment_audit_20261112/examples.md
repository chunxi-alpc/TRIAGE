# 实际审查示例：兼容性与医学标签支持分别判断

以下均是实际已完成记录的去标识化概括，只保留解释判定所需的临床变化，不复制原始叙述、年龄／性别组合或完整病例。编号用于关联 [semantic_review.jsonl](semantic_review.jsonl)，不能把这组解释性例子当成随机样本或据此推算比例。分类遵循 [冻结标准](rubric.zh.md)；AI 相对排序审查不是临床专家裁定。

**没有可展示的 MedEinst S1。** 全部 4368 对实际提示都是两候选诊断，严格任务条件不满足。下文最后一例来自 MEGA 内部 F，仅作同任务参照，不能算作 MedEinst S1。

**S2：新增一个症状事件，足以改变固定候选的相对支持。**

记录 a0412，配对 `medeinst:train:case_38995`。原有系统性自身免疫疾病的支持性表现保留，修改侧新增一个具有急性缺血特征的持续胸痛事件。胸痛性质及放射等描述属于同一个新事件，没有因文字属性较多而机械计为多项独立事实。

盲审相对排序由 SLE 转向 Possible NSTEMI / STEMI，与随后揭示的标签方向一致，最终为 S2。这表达当前两候选下急性问题的相对优先级变化，不表示原疾病消失，也不表示已确诊心肌梗死。实际原模型方向及两侧标签均正确；仍只列作跨任务辅助候选，不能推导出分数与 MEGA 条件分数同尺度。

**S2：删除一个关键诱因，但“没有叙述”不等于“明确没有”。**

记录 a0373，配对 `medeinst:train:case_60372`。修改删除反复剧烈呕吐／干呕这一诱发事件，另处呼吸困难只是重复描述。盲审认为在固定的食管破裂与可能急性心肌梗死两个候选中，删除关键诱发证据可使后者获得更强相对支持，因此为 S2；并未把省略理解成证实从未呕吐。原始叙述未明确完整时间联系，这一点保留在判断理由中。

这个例子尤其说明数据语义与模型响应要分开：发布方向获得盲审支持，但当前基础模型的分数变化方向不支持该方向，且并非两侧全对。因此 M3 保持原模型响应，可能保持错误方向。此诊断不改写已经锁定的 S2 分类。[原始响应记录](audited_auxiliary_candidates.json)

**S3：标签方向可以合理，但同时改变多个独立医学事实。**

记录 a0043，配对 `medeinst:train:case_183140`。修改同时省略呼吸困难、删去一组皮肤表现，并新增缺血型胸痛事件，共三个独立临床信息变化。盲审相对排序由 SLE 转向 Possible NSTEMI / STEMI，与发布标签一致，但单事实要求明确不满足，因此为 S3。

这里不需要否认诊断优先级变化的合理性；问题在于无法把模型响应归因于单个患者事实。删去症状叙述仍不等于肯定症状不存在，皮疹描述组也没有按每个修饰词重复计数。

**S3：文本位置变化，没有净临床证据变化。**

记录 a0037，配对 `medeinst:train:case_205185`。痰液相关陈述被移动，其他显式症状描述仍然保留，修改后的层级组织还存在问题。阅读两侧全文后，盲审没有发现有效的新事实；同一慢性阻塞性气道疾病急性加重候选在两侧均获得更强支持。

发布标签从 Bronchitis 转向 Acute COPD exacerbation / infection，但该翻转没有对应的净证据变化，最终为 S3。它说明字符差异、非空编辑、存储标签翻转同时成立，也不能保证存在医学反事实。

**S4：一个属性变化，没有足够证据确定诊断排序翻转。**

记录 a0394，配对 `medeinst:train:case_110540`。修改只把疼痛位置换到常见淋巴结区域，事实数为一。原侧相对支持 Cluster headache；修改侧的疼痛位置不能直接当作已经查明淋巴结肿大，也没有足够信息建立 HIV 初次感染的优先排序。

发布标签为 Cluster headache → HIV (initial infection)，但盲审对右侧排序不确定，最终为 S4。单事实只是必要条件之一，不能单凭编辑数量就把病例列作可用辅助证据；这里也不将证据不足直接说成标签必错。

**S4：文字澄清是否增加医学信息仍不确定。**

记录 a0052，配对 `medeinst:train:case_99391`。原来泛指症状的“活动加重、休息缓解”被明确关联到胸痛，但原先指代可能已经包含胸痛，也可能主要指其他症状。因而不能可靠决定这是新增证据还是既有信息的澄清，事实数保留为未知。

固定候选为 Acute pulmonary edema 与 Possible NSTEMI / STEMI，盲审未确认发布的相对翻转，最终为 S4。该例体现冻结规则：指代不明确且足以影响资格时，应保留不确定性，不为得到某个类别强行指定事实数。

**同任务参照：MEGA 内部 F 中跨越年龄阈值，指南条件固定。**

实际配对 `new-1378-G16:F:398`，对应内部病例键 `mega:train_val:1378:13`。患者年龄从低于条件阈值改为达到阈值；被问的年龄条件、指南及定义保持不变，原侧条件标签为 0，修改侧为 1。这里的分数变化对应同一个明确条件从不成立到成立，目标没有变成不同疾病之间的排序。

本例已通过原始病例、条件树节点及原始路径标签核验，并具有明确程序规则依据。它说明优先采用 MEGA 内部 F 的任务层面理由，不代表本次完成了所有 MEGA F 的新临床专家审查，也不增加 MedEinst 的 S1 数量。[MEGA 结构审计](mega_f_program_audit.csv)、[原始标签核验](mega_original_label_check.json)
