# 固定训练数据：10,006 对均衡配置

本配置已由用户确认为后续 ASTER-CR 配对数据实验的默认训练数据。配置入口为仓库根目录的 `configs/aster_cr_training_default.json`。

|类别|配对数|来源|标签关系|
|---|---:|---|---|
|A|4,368|MEGA 既有合格 A 全量|保持|
|P|635|冻结 E1 的 MEGA P|保持|
|C|635|冻结 E1 的 MEGA C|翻转|
|F|4,368|已审核的 MedEinst 训练集固定子集|翻转|
|合计|10,006|MEGA 5,638 + MedEinst 4,368|保持 5,003；翻转 5,003|

这是标签保持与标签翻转数量均衡，不是四类样本数量相等。固定数据以 `data/selected_pair_ids.jsonl` 为配对清单，`data/fit_pairs.jsonl` 为训练索引，`data/unified_train.jsonl` 为统一配对原文。后续直接读取这些文件。

F 从 8,228 对已接受 MedEinst 训练配对中按修改前后诊断组合分层，使用最大余数法分配比例配额、种子 20261112 在层内抽样；已选出的 4,368 对固定保留。F 全来自 MedEinst。

训练沿用本轮实际配置：四类在混合统计中各占 25%；类内按数据源、来源、原始病例和病例变体分摊。M2 的 A/P 两类等权，C/F 两类等权；M3 的 A/P 回归总权重为 4,887，其中 A/P 各 2,443.5，C/F 使用逐对证据约束。来源总体权重为 MEGA 75%、MedEinst 25%。现有模型参数配置见 `configs/initial_frozen.json`。

当前模型为 Qwen3-8B，M1/M2/M3 已独立拟合并完成冻结评价。后续涉及新模型或新方法时沿用该数据清单，并按对应实验独立拟合。E1 继续作为冻结基线，原 E-Multi 作为历史对照。

本次选择属于查看现有结果后的后续默认数据决策。原始 10,006 对配对清单和本轮训练配置是在查看结果前确定的；本次仅确定沿用它，没有重新筛选配对、调整权重或重新拟合。当前结果支持 MEGA 干扰稳定性和 MedEinst 证据保护改善，尚不支持整体准确率优于 E1，也未证明它是所有候选中的统计最优数据配置。

人工抽查状态仍为待完成；既有程序检查和模型语义审核不称为临床专家审核。测试集继续冻结。完整结果见 `TEST_RESULTS.zh.md` 与 `RESULTS_NOTE.zh.md`。

复现程序为 `code/build_balanced.py`。它在已有冻结标志时复用当前清单；完整重建使用独立目录。当前决定不启动新的训练或扩展数据生成。

GitHub 同步固定配对 ID 清单的压缩文件 `data/selected_pair_ids.jsonl.gz`，其内容与服务器的 `data/selected_pair_ids.jsonl` 相同，仅含配对 ID、病例 ID、来源和类别。配对原文、训练索引、模型及大缓存继续保留在实验服务器；默认配置中的相应路径以服务器实验仓库为根目录。原始复现程序及训练入口也保留在服务器。
