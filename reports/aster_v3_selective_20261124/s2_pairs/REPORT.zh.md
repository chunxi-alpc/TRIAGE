# 冻结候选在 80 个训练来源上的折外配对结果

在 1,342 个 C/F 对上，R0、E1_pair_only 和 J_zero 的双端全对数均为 1,173，证据方向正确数均为 1,338。E1_pair_only 的拟合外超预算数为 25，J_zero 为 36。A/P 分数差方差相对 R0 的降低率分别为 3.50% 和 −0.35%。

| 同折配对指标 | R0 | E1_pair_only | J_zero |
|---|---:|---:|---:|
| A/P 方差降低率（%） | 0 | 3.50 | −0.35 |
| A/P 双端全对 | 4,970/5,003 | 4,971/5,003 | 4,971/5,003 |
| C/F 修正 RMS（logit） | 0 | 0.1225 | 0.1277 |
| C/F 证据方向正确 | 1,338/1,342 | 1,338/1,342 | 1,338/1,342 |
| C/F 超预算 | 0/1,342 | 25/1,342 | 36/1,342 |
| C/F 双端预测随标签翻转 | 1,174/1,342 | 1,174/1,342 | 1,174/1,342 |
| C/F 双端全对 | 1,173/1,342 | 1,173/1,342 | 1,173/1,342 |
| F0 两端保持相同预测 | 73/82 | 73/82 | 73/82 |
| F0 双端全对 | 73/82 | 73/82 | 73/82 |
| F0 修正 RMS（logit） | 0 | 0.0757 | 0.1087 |

A/P 和 C/F 使用 80 个训练来源、五折留出上的公共 Dataset B 配对。F0 另取同一 80 来源框架与相同冻结折上的历史配对池，其中 11 个来源提供 82 个标签保持的事实变动对。每对以原配对 ID、来源、折及双端 UID 定位。裁决均按分数大于零预测正类。证据方向正确要求两端分数差与标签差同号；双端全对要求两端符号各自与金标相符。超预算沿用每对原档案的 δ 与 1e-9 数值容差。

F0 的 R0 和 E1_pair_only 双端、J_zero 的 82 个左端均已有同折分数。82 个右端按原输入 UID 读取缓存头激活，应用该折已冻结的 M2、J 参数及训练中心，截距取零。五折各抽取一个已有 J_zero 分数的左端，按相同投影和读出复算，最大绝对差 7.11×10⁻¹⁵。[逐折对照](f0_projection_checks.csv)

新增标量分数及来源和 UID 见 [F0 端点表](f0_endpoint_scores.csv)。公共配对上，J_zero 的 A/P 方差降低率 95% 来源区间为 [−2.73%, 1.75%]；C/F 修正 RMS 区间为 [0.1191, 0.1368]；C/F 双端全对率为 87.41%，区间为 [84.18%, 90.42%]。

复用 12,854 条 R0/E1 配对输出和 9,144 个 J_zero 折外端点分数，对 6,427 个 J_zero 配对完成评价。旧报告已验证 J_zero 与 J_shared 的配对分数差在数值容差内一致，方差、修正 RMS、超预算率沿用对应旧区间。J_zero 的双端决策按实际零截距分数统计。新增区间按 80 个来源共同重采样 2,000 次，无 F0 的来源在该子组的分子、分母贡献均为零。现成区间在 [指标及分母](metrics.csv) 中逐项标注，整数见 [逐来源统计](by_source.csv)，J_zero 的逐对去标识增量见 [配对结果](j_zero_pair_results.csv.gz)。
