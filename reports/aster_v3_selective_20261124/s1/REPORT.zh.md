# S1 首错归因与 S3 条件核验

在已用的 80 个拟合来源中，R0 和 J_zero 的归档首错合计涉及 245 个不同的病例节点。两条能直接核对测量对象、单位和阈值的规则，在 2 个来源的 33 个自然节点中纠正 7 个原始错误，误修 0 个。20 个开发来源没有出现这两条规则。该结果衡量已用来源上的局部机制。

## S1 首错证据

从 PR #87 的已存 R0/J_zero 边界取两方首错的并集，按病例、版本、指南节点和折内 UID 去重。自然路径的 R0 首错为 163 条，J_zero 为 159 条。两法并集含自然节点 163 条和干扰节点 418 条，共 581 条，跨 46 个来源。自然首错来自 42 个来源。实际路径转移直接读取档案。

|证据状态|自然记录 / 163|干扰记录 / 418|不同病例节点 / 245|
|---|---:|---:|---:|
|既往案例阅读|7|19|8|
|新增程序可核对的数值判断|6|10|6|
|新增待复核的文本或标签矛盾|2|6|2|
|原因待审|148|383|229|

每个自然病例有三个处置改写版本。来源及版本分母见 [来源统计](source_counts.csv)，不同病例节点分母见 [去重统计](case_node_counts.csv)。245 个不同病例节点中 229 个（93.5%）的归因待审。既往 8 例来自服务器 E1 代表性案例阅读，涉及否定、并列、数值、主次条件、时间和适用范围。归档没有这 245 个节点的合格临床盲审。供后续复核的 [索引](blinded_review_index.csv) 只含病例和指南定位信息。复核者可按病例键读取患者与指南，避开金标签、预测和方法状态。

按真实指南 ID、节点 ID、来源及条件文本，关联 PR #85 所用规则表中 470 条拟合来源的结构规则。581 条记录中 70 条为类别或状态条件、31 条为数值条件、18 条为复合条件、462 条结构未知。结构可以跨同一指南的病例复用，患者事实只在病例相同的条件下关联。比较符、测量单位、时间词、逻辑词、缺失指示词作为词面描述单独记录。患者事实定位、跨句推理、例外条件及定义边界需要相应证据，未核实的原因列入待审。程序可核对的标签表示患者文字和规则算术结果一致；该归因不定位模型的内部错误机制。

S/J 的 1,712 条自然路径诊断、PR #87 的首错位置、E1 的 5,136 对自然与干扰路径转移及历史 166 条 R1 线性规划记录均来自存量。按折和 UID 在自然首错上关联到 151 条 R1 边界；可达性只描述原 R1 的固定预算条件。逐例文件保留 R0 margin、J_zero 的修正符号与幅度、实际四向转移、E1 的配对修正和改写转移。干扰项描述同病例的相关变化。[逐例记录](first_errors.csv)

两例新增待审记录按原始病例计。2744:10/G1 的测量值和病例中的比较结论矛盾，1857:4/G3 的测量值和归档分支标签矛盾，各对应四个路径版本。历史案例另含三个事实或标签冲突和一个适用范围待定项。记录保留原标签；新增冲突属于冻结两条规则的范围以外。
