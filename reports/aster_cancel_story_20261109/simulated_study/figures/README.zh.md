# 模拟研究图表

所有图均为参数化场景推演，不是实际调用模型、运行benchmark或实现基线得到的结果。

01_simulated_main_vr_er：模拟场景推演，非真实benchmark。3种模型名称×3种任务名称只是9组参数配置。最终方法、配对写回与LoRA均为共同潜在变量上的预设读出变换，未实际实现相应基线。VR越高表示配对差方差越小；ER的目标是100%，超过100%表示响应放大，并非额外优势。每格为5个模拟seed均值±样本SD。较纯的痕迹、较高证据保留率均来自额外模拟假设，不能替换真实开发集94.64%的证据响应保留率。

02_simulated_ablation：模拟消融，非真实模型训练结果。每个seed内对可用场景等权平均，再计算5个seed均值与样本SD。去掉b保持所有配对差分指标不变，可能改变阈值判断准确率。其余消融体现预设特征、噪声和读出方式的差异。ER接近100%为理想；本图不据模拟准确率声称真实数据上的性能提升。

绘图来源：../main_summary.csv和../ablation_seed_metrics.csv；图内使用的数值另存为同名_data.csv。
