# 五种模型配置的模拟图表

所有图均醒目标注“模拟结果”。数值来自共同潜在变量与预设变换，不是实际模型或基线实验。

01_simulated_main_vr_er：模拟结果，非真实benchmark。模型与任务名称仅对应预设参数配置；未调用模型、使用真实任务样本或实现相应基线。VR越高表示配对差方差越小；ER以100%为目标，超过100%说明响应放大。较纯痕迹与较高ER均来自额外模拟假设，不能替代真实开发集94.64%的ER。主实验为Qwen3-8B、Llama-3.1-8B-Instruct、Gemma-2-9B-IT三组配置，各含MEGA、NLI4CT、三段论三种任务配置。每格为5个模拟seed均值±样本SD。

02_simulated_ablation：模拟结果，仅汇总三种主模型的九个场景。每个seed内等权汇总场景，再计算5个seed均值与样本SD。去掉b不改变分数差分，但可改变阈值判断准确率。消融反映预设特征与噪声变换，不证明真实模型性能。

03_simulated_supplementary_27b_vr_er：模拟结果，非真实benchmark。模型与任务名称仅对应预设参数配置；未调用模型、使用真实任务样本或实现相应基线。VR越高表示配对差方差越小；ER以100%为目标，超过100%说明响应放大。较纯痕迹与较高ER均来自额外模拟假设，不能替代真实开发集94.64%的ER。补充对照为MedGemma-27B与Gemma-3-27B-IT，各含三种任务配置。色标与主实验图完全相同，便于对照；模型名对应独立预设条件，不能据此推断实际医学微调或参数规模的因果效应。
