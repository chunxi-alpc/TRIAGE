## 二、只做两项剩余实验

### 实验 A：同等证据代价下，确认正交痕迹的特征优势（优先，复用缓存）

**目的：** 回答正交痕迹是否比原始干扰方向、证据方向和随机方向更适合选择性修复。

现有 Qwen 缓存已包含正交痕迹、未正交 U、证据子空间 S、随机子空间及多个预算配置。先直接复用这些激活、分数、配对和已有权重；不要重新跑模型前向。

只重新拟合必要的线性修正，并在 dev 上为每种特征选择实际 C/F 修正 RMS 接近的配置（目标约 0.20 logit）。配置冻结后，在既有 test 上做一次描述性比较。由于该 test 已被此前项目分析过，本实验明确标记为**回顾性/探索性分析**，不称全新确认性测试。

比较四类特征：
1. 正交痕迹 N；
2. 未正交干扰子空间 U；
3. 证据子空间 S；
4. 至少 50 个随机 16 维子空间。

统一使用相同 A/P 训练配对、线性修正、正则化选择规则和 C/F 预算定义。报告：
- dev/test 实际 C/F 修正 RMS；
- A/P VR、分数差 RMS、预测 R²/RMSE；
- C/F ER、方向退化和预算超限数；
- 动态路径正确数；
- 随机方向分布及来源簇 bootstrap 区间。

核心结论只看：**在相近实际证据改动下，N 是否稳定取得更高 VR。** 如果无法匹配证据代价，展示完整 Pareto 曲线，不宣称正交痕迹优越。不得根据 test 调预算。

交付目录：meeting/matched_cost_feature_analysis/。只做缓存计算，不占 GPU；若现有缓存不足，说明缺少哪些字段，不重新生成大缓存。

### 实验 B：跨模型核心复现（只做 MEGA，不跑 285 项）

**目的：** 判断 ASTER-CR 是否依赖 Qwen3-8B 的特定内部表示。

Qwen3-8B 已有完整结果，作为参照。只对以下模型做 MEGA-CDP：
- Llama-3.1-8B-Instruct
- Gemma-2-9B-IT
- Gemma-3-27B-IT
- MedGemma-27B-Text-IT

每个模型独立提取激活、选择注意力头、估计 S/N、构造痕迹、拟合修正参数和截距；不得复用 Qwen 的头索引、特征基、标准化参数或权重。

只比较四种方法：
1. 原模型；
2. 仅截距校准；
3. ASTER-CR 线性（同一 A/P + C/F 约束协议）；
4. 同维随机痕迹控制。

使用已有 MEGA fit80/dev20 来源划分，冻结后评价相同受控 A/P、C/F 留出配对及官方 7,458 条路径。每个模型单独报告，不合并不同模型的 logit。优先复用已保存输入文本和配对清单；只对缺失的模型激活/分数做推理。

先做一次简短的模型权重/GPU 可用性检查。可运行的模型直接执行；缺失权重或 provider 的模型记为 blocked，不等待、不用模拟结果填补。资源允许时再增加 MLP，不作为本轮必需项。

主要指标：
- 痕迹 A/P 预测 R²；
- A/P VR 与分数差 RMS；
- C/F ER、修正 RMS、方向退化；
- 自然节点及动态路径正确数；
- 相对原模型的来源簇配对 95% CI。

交付目录：meeting/cross_model_mega/。至少保存每模型的配置、代码 SHA、权重 revision、逐例预测、来源级指标、运行日志和结果汇总。
