# 临床抽样核验材料

数据：repair-v2。材料尚未经过医生审核。

抽取 A 类30对：fit/dev/test各10对；删除、替换为中性文字、交换处置三种改写各10对。另包含全部 P 类32对，共62个不同节点。抽样种子20261109，未使用模型分数或纠错结果。A类样本避开P类节点。

请逐对核验：

1. 根据条件与病历摘录决定真值的关键事实，独立填写两侧真值。
2. 判断配对真值是否应保持不变。存储标签相同只是构造意图，不能替代语义核验。
3. 判断改写处置后，当前条件所需的定义、禁忌证或方案说明是否仍完整。
4. 判断两侧文本能否被临床解释，注明不自然、矛盾或暗含决定性事实变化的位置。
5. 在review_sheet.csv填写空白审核栏。可填是/否/不确定；定义不涉及处置时可填“不适用”。

A类关键事实待医生摘录。P类如有构造时记录的decisive_facts，已原样提供，仍需独立核验。存储标签和医生标签分开保留。条件定义被破坏或真值应改变的配对，不应作为干扰不变性证据。

文件：review_sheet.csv是审核表；review_pairs.jsonl包含两侧完整输入；review_cases.md供阅读；pair_counts.csv为全量配对计数。

主张范围：正文以“后续处置影响当前条件判断”及其修复为主。P类fit仅18对、dev4对、test10对，应作为探索性结果按类型单列。医生核验前，只能称为“按构造标签保持真值的配对”。
