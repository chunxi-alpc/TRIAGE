# ASTER-CR 新旧配对数据对照实验

基础模型为冻结 BF16 Qwen3-8B，保留原提示、分词、最终 token 评分及 FP32 标签投影。新组独立重估 M1 的 51 个头、M2 的 16 维子空间和 M3 的修正参数；E0 全量结果引用既有实验，避免重复训练。

Dataset A 为 2,540 对均衡数据；Dataset B 为 6,345 对全部合格数据。E1/E2 使用类别及来源平衡，E3 使用自然权重；A/P 回归权重和归一为 4,887，lambda=0.01，所有 C/F 拟合对使用同一 0.2923349 logit 硬约束预算。

开发集选择的主方案为 **E1 / Dataset A**。选择依次比较自然完整路径、自然节点正确率、证据方向退化数、超预算比例及干扰方差降低率。

## 统计与指标

按指南来源执行2,000次配对自助重采样；方法差值使用完全相同的来源抽样。差值及95%置信区间见 source_bootstrap.csv，逐来源误差见 source_metrics.csv。零方差或零响应分母时，相应比值记为空值，并保留有效重采样次数。

A/P差RMS为修正后的配对分数差均方根；另保存原始RMS和修正量RMS。VR=1−修正后差值方差/原差值方差。ER为真值方向加权的修正后与原证据响应之比。方向退化统计原真值方向响应为正、修正后不为正的配对。超预算按修正量在两侧的绝对差是否超过固定delta统计。

历史40个测试来源、已有60个评价来源及目标任务均有历史使用记录，本轮结果属于既有数据上的对照评价，不作为全新独立确认。完整路径按修正后分数自主遍历，所到节点缺少缓存记为不可用并判错。

逐输入分数、逐对预测、完整路径、模型参数和来源指标保存在本目录。旧数据和历史报告只读。当前报告只列已计算的结果。
