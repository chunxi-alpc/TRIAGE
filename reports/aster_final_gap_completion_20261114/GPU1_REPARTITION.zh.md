# GPU 1 分担剩余官方评价

E5十三行干扰路径及接续统计全部完成后，GPU 1释放。按用户要求，将两款27B模型各约20%的剩余节点工作分给GPU 1：先执行Gemma3的638条路径，再执行MedGemma的608条路径，共1,246条。单卡顺序加载两个模型，预计显存55–65GB，整体剩余时间约1.5–2.5小时。

| 模型 | 已完成并保留 | GPU 5或6接续 | GPU 0或4接续 | GPU 1分担 |
| --- | ---: | ---: | ---: | ---: |
| Gemma3 | 4,309路径 | GPU 5：1,259路径 | GPU 0：1,252路径 | 638路径 |
| MedGemma | 4,469路径 | GPU 6：1,174路径 | GPU 4：1,207路径 | 608路径 |

分配按剩余金标准节点数计算，各原分片保留中断路径已缓存的节点，GPU 1接手尚未触及的路径。每个模型三个分片的路径ID无交集，与已完成路径合并后均为7,458条。已有模型、冻结参数、评分器、提示及评价口径继续使用；已有逐例预测和节点缓存全部保留。

统一队列负责GPU 0、1、4、5、6。MedGemma的GPU 1任务依赖Gemma3的GPU 1任务完成，每个模型的合并统计依赖其三个分片全部完成。合并时验收三种方法各7,458条唯一路径、418来源及45,627个自然节点，随后自动归档和提交GitHub。
