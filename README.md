# ASTER

ASTER研究模型如何依据完整指南和患者事实判断当前条件，再由程序沿指南树执行路径。方法保留三模块：**M1定位干扰通路，M2估计干扰与信号子空间，M3学习表示编辑。**

**最新方法：P0–P3中的`paired_ns`。** 固定51个查询头和已有子空间，在干扰／信号联合空间中训练映射与门控，使用在线自身参考及配对监督，共78,051个可训练参数。代码已实现，正式训练和评测尚未完成。
