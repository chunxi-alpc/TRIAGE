## 阅读约定

当前接口以 `src/` 下的模块说明和代码为准。实验目录中的协议、报告、指标、预测与校验清单保留各轮运行时的状态。历史报告中的“当前”“下一步”“默认入口”均指对应实验阶段。

不同模型、数据划分、筛选子集和运行阶段的指标不能直接拼成一张整体性能表。新增入口会明确标注这些差异，并链接到原始依据。
