# ASTER：官方注意力强基线复现与适用性条件化改进

日期：2026-10-25。状态：**设计已交付，尚未启动本计划的新实验或子代理**。
继承基线：PR #35 / `cbb4d613a59618a7f98efccea60a9a469037f0ad`。不覆盖 main，不改写 PR #30—#35 的预测、失败记录或预注册。

## 0. Work 的明确目标

在相同 Qwen3-8B 权重、指南信息、工具权限和合理匹配的计算预算下，以官方 SEKA/AdaSEKA 为可复现基础，研究“患者适用性条件化的证据选择与阶段性注意力引导”。先复现官方算法，再验证其相对普通 SEKA、强非注意力基线的独立增益，最后在未参与设计的外部数据上确认。

研究目标是取得最强的真实结果，不是事先指定排名。允许开发集参数优化；不允许挑选最佳测试种子、排除失败病例、使用金标分支/金标路径选择高亮位置或只报告获胜参数。数据集 SOTA、同底座算法最优和临床有效性是三个不同主张。

首轮只使用 Qwen。探索 seed=0；冻结后报告预设种子 0/1/2 的全部结果和均值。不要为了得到新的数字而重复确定性贪心推理：分别记录数据构造、投影校准、头选择、选项顺序及采样种子。种子不是新的独立患者。

## 2. SOTA 的可比性登记

每项记录必须包括：论文/榜单日期、数据版本、原始/派生任务、切分、上下文权限、模型 checkpoint、是否训练、推理/工具预算、评价器、指标及代码 commit。只有设置相同的分数允许直接比较。

- MedGUIDE 原论文 Table 4 的带指南设定：o4-mini 78.31%，Qwen3-8B 66.68%。这是2025原论文可核验的结果，不是已确认的2026持续榜单世界最优，也不能与本仓库四卷平均分比较。原论文提供匿名代码入口 `https://anonymous.4open.science/r/Submission-MedGUIDE-187A`，需检查可获取性。
- 后续2026研究 MaR 使用 MedGUIDE，但训练、提示及数据协议必须重新核对；不能将第三方聚合榜单的49.9与原论文78.31直接排序。MaR官方论文与代码见来源。
- MEGA-CDP（2026-08预印本）原论文中单轮路径成本 PCC 最低和答案准确率最高不是同一模型；先复现其原始评价器，不合并不同指标选一个“SOTA”。
- MedPIC-Bench（2026-08预印本）原论文表2中 Gemini-3.1-Pro 总体80.7%、CF69.9%、配对48.3%；原始问题是可多选、零样本问题作答。给所有方法增加外部规则后属于另一个开卷赛道，不能直接称超过原论文。
- SEKA/AdaSEKA 是 ICLR2026 的可复现注意力强方法；其 CounterFact、BiasBios 等结果不能等同于 MedGUIDE SOTA。SEKA表2的Qwen3-8B CounterFact efficacy为99.08，PASTA为92.70，指标是论文的efficacy，不应改称通用临床准确率。

## 3. 必做对比基线（先实现再优化我们的方法）

|ID|方法|复现策略|比较目的|
|---|---|---|---|
|B0|完整指南、无干预|原输入/同输出预算，保留闭卷仅作参考|任务基本难度|
|B1|处置隐藏后判断，再写出适用规则|文本两阶段，计入全部token/调用成本|排除盲判只是额外推理预算|
|B2|预测规则裁剪Top-1/Top-2/适用规则集合|共用同一适用性信号；多选任务不硬塞单规则|最强简单规则选择|
|B3|条件判断+直接动作映射/规则执行|保留逻辑、例外与未知；开放生成任务使用被选规则的确定性路径或同底座解释器|排除符号执行已足够|
|B4|静态/动态温度校准概率融合|沿用现有代码、同调参预算；只适用于有定义候选动作的任务|现有最强简单基线|
|B5|CAD|官方xhan77/context-aware-decoding，关闭不必要候选过滤；验证候选筛除的历史问题|上下文忠实性解码|
|B6|PASTA|官方QingruZhang/PASTA或SEKA依赖的对应移植；重新做Qwen头分析|正式注意力基线|
|B7|Spotlight|按原论文公式/头层/目标span复现，代码来源未确认时明确是论文复现|动态分数引导|
|B8|SEKA|官方waylonli/SEKA，构建同checkpoint投影、复现标准集|主要方法基础|
|B9|AdaSEKA|官方自适应builder及专家路由；成本单列|最新自适应注意力强基线|
|B10|PR #35原稀疏动态引导|复用已存输出，协议变化时重新运行|研究演变对照|

Oracle规则/路径只用于上限诊断，不能与预测方法混为同预算正式排名。随机span、错位动作、反向偏置和对应零强度是因果/数值负对照。

ProbeRAG、JUICE、Context-DPO、MedGuideX/MaR仅为第二层相关或训练基线：有同底座权重、授权与合理预算时才纳入。不得用缺权重的半流程冒充完整算法。不得为复现而自动购买API或云GPU。

## 4. 从官方 SEKA 改进的最小候选（不是性能结论）

名称暂用 ASTER-SEKA。不叠加新GRPO、复杂证据模型或多个新算子。

### 模块1：处置独立的证据—条件注意力

输入病历和指南条件，隐藏所有候选处置及选项中的处置泄漏，但保留病历中对条件必需的既往治疗事实。自动定位规则条件与病历中的证据span，输出原文位置。SEKA高亮这些span，帮助T/F/U判断。

不得使用gold rule、gold path、gold answer或规则人工真值确定span。所有基线可获得相同的预测span。掩码负责可见性，SEKA键编辑不自动构成严格的信息隔离。第一版允许两个真实提示，不以“一次预填充”作为未经测量的卖点。

### 模块2：适用性与规则结构

输出逐规则T/F/U分数与支持、反驳、未知证据。单互斥分支才可归一化；多规则同时成立采用集合/图逻辑，不将所有任务强制softmax。

已有规则—动作映射与概率融合保留为统一强基线。对规则求和引入的频数偏差保留均匀、去重、max及mean诊断。未知不自动等同违反。共享条件/脚注span只计一次，不因规则重复获得多倍放大。

### 模块3：适用性条件化的执行期高亮

在完整指南中高亮预测支持的条件—动作片段及必要定义、例外；用同一个官方SEKA算子和明确角色/阶段调度执行。首版不设计带符号负投影，不承诺等价裁剪；低可靠性保留原上下文。

单选任务保留直接映射及校准融合作为强对照。多选任务对每个动作/答案集合独立判定并输出集合；路径生成任务保留原生生成，不将其退化为答案字母分类。结果不默认加旧残差，避免把同一动作支持重复计算两次。

### 最小可归因实验

- 条件判断：普通盲判 vs 相同输入、相同span的SEKA盲判，固定下游决策。
- 执行通道：固定完全相同T/F/U与动作支持，比较文本强调、裁剪、直接映射/融合、普通SEKA、阶段条件化SEKA。
- 2×2：判断阶段引导关/开 × 执行阶段引导关/开，其他信息不变。
- 通用SEKA投影 vs 只用训练/校准集构建的条件任务投影；投影预算相同，属于扩展消融，不能同时更改数据与算子而不分析。
- 注意力关闭、错误span、错位规则及matched-zero必须齐全。模型外解析/验证器独立成本要计算。

## 5. 数据集与作用

1. **CounterFact + BiasBios**：第一阶段官方实现校验，严格按SEKA原脚本的数据/提示/指标。先16条smoke，再完整原定评测划分；CounterFact接近天花板，目的不是为论文另造一个最高分。BiasBios授权不允许时标记blocked而不是擅自再分发。
2. **MedGUIDE及既有四卷/CS**：回归与机制诊断，保留所有旧结果；已暴露开发/测试不再声称全新确认。原生MedGUIDE和我们派生的反事实卷独立表格。
3. **MEGA-CDP（主外部任务）**：仓库清单记录2274指南，train_val1834指南/34895病例，test440指南/7458病例。先核对实际文件、授权和历史曝光。只在train_val按来源指南分组开发/校准；冻结后评估原生test。主任务为单轮路径生成，主要指标PCC（越低越好），次要为最终结果准确率。保持原评价器与版本；替换评审模型必须单独报告，不与原论文直接排名。官方数据当前许可TBD，运行/发布前完成来源使用审计，不上传指南全文。多轮放后续扩展，避免首轮范围膨胀。
4. **MedPIC-Bench（主外部迁移）**：全部467题，保留所有问题类型，原论文89个链接对需验证pair映射。多选集合精确匹配为主指标，另报GF、CF、Pair。原生零样本与固定相同外部规则开卷分别报告；不得用gold选择参考规则。整个集合为冻结外部测试，不用其标签定阈值或选头。若已用于方法开发，则必须改标探索集。
5. **MedCalc-Bench v1.2（诊断）**：使用作者当前修订而非默默混用旧版本。原生完整评测与新构造的条件系数/阈值子集分开。计算工具执行器作为单独工具权限对照，不能把算术工具增益计为注意力增益。
6. **FaithEval（泛化备选）**：counterfactual/inconsistent/unanswerable官方原任务；只在主外部任务通过开发门槛后扩展。不能把其上下文片段虚称为临床规则。

优先完成1、2、3、4，不同时展开全部数据集。RuleArena/NLI4CT可作后续规则适用性扩展，不属于首轮必做目标。

## 6. 执行阶段与完成条件

### G0 数据/资源与协议冻结

审查server目录、模型指纹、GPU占用、公开许可、样本重复和来源指南重叠。核查MEGA-CDP与MedGUIDE来源文档重合，保证校准和外部测试隔离。写dataset_manifest、split_ids和hash。授权缺失明确阻塞，不绕过。

### G1 官方基线完整复现

优先SEKA，再PASTA/AdaSEKA。记录官方commit、实际环境、checkpoint、投影、头集合、生成长度和评价器；跑完整指定标准评测。先排除实现错误，再分析与论文差异。预先可把主要原始指标与论文差异不超过2个百分点作为复现检查线，但环境/数据版本不同则必须单列，不能调测试标签硬凑数字。G1未通过不能宣称在官方SOTA上改进。

### G2 Qwen seed=0 方法开发

主模型为服务器现有Qwen3-8B，按实际权重/配置hash锁定。旧800条用于回归诊断；新任务开发只能来自MEGA-CDP train_val且按源文档分组。先完成2×2核心消融与信息匹配强基线；每个方法最多27个已登记配置，记录累计GPU/CPU/token预算。新候选修改最多两轮，失败就提交完整负结果，不无限测试直到找到赢法。

### G3 冻结配置与外部确认

保存config_lock与时间戳后，评估MEGA-CDP原生单轮test和MedPIC冻结全量。源文档重采样；患者的所有反事实版本与数据种子始终同簇。主要比较族事前固定并Holm校正。不同数据集分别统计，不把重复病例当独立样本。首次测试结果出现后，任何新修改须用新独立数据确认。

### G4 稳定性与审计

预设0/1/2全部种子；静态贪心完全相同运行不重复计证据。每个seed保存参数、样本构造及投影随机性来源。解释失败条件、开放式答案的解析失败、多标签错误和未知事实。完成真实人工审核或明确未完成。计算全部前向、投影构建与评审成本。

## 7. 成功目标（是验收门槛，不是承诺）

A. 在同Qwen模型、同输入/检索/工具权限和可比预算下，优于最强已复现基线，而非只优于原模型。
B. 主外部MEGA-CDP单轮PCC降低目标>=2个百分点，配对来源簇95%区间支持方向；最终结果准确率非劣效界值2个百分点。MedPIC原生或明确标注开卷同设定集合精确匹配目标提升>=2个百分点，区间及Pair方向另报，不混同两赛道。所有门槛由dev功效检查后、test启动前冻结，不能看test修改。
C. 去掉注意力、保持相同预测证据、相同外部模块和输出预算后效果下降；否则不能把收益归因于注意力。
D. 主方法不靠选择某一最佳seed获胜；报告全部结果与均值。结果不支持目标时交付诊断和完整负结果，不能写SOTA成立。
E. 无论是否达标，交付实际可复现代码、参数、完整匿名预测、运行日志、来源、统计区间、计时/显存及准确的完成状态。

这里的“答题退化”不是实际临床伤害。实验不给临床部署安全保证。
