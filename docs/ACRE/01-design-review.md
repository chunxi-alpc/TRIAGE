# 01 · ACRE 方法设计评审与研究定位

> 状态：研究方案评审稿；证据与出处尚待逐条核验。引用标记 `[cite:...]` 沿用原始材料，见 [核验清单](05-reference-checklist.md)。

## 1. 总体判断

**研究方向可行，收敛为一个干预算子是合理的；但新颖性、上游答案泄漏与“关系级”干预的真实作用范围，必须在论文主张中说清楚。**

投稿前的三项关键工作：

1. 充分对齐最接近的先行工作，尤其是 **InstABoost** 和 **AutoPASTA**。
2. 回应“外部关系模块已经算出答案，模型内干预是否多余”的质疑。
3. 严格区分 **匹配头上的条件—证据配对偏置** 与 **决策头上的适用性条件化目标选择**。

### 1.1 支持设计动机的现象

- **冲突检测不等于需要干预**。原始评审引用的 MedPIC-Bench 结果涉及 28 个模型：反事实问题的平均准确率由 63.6% 降至 45.1%，尤其容易在患者新信息要求缩小或撤回安全警告时出错。待核：[cite:c1b71a59-1]。
- **信息被读取，不代表决策已更新**。原始评审称，MedPIC-Bench 的部分推理轨迹已提及变化后的患者信息，但最终答案仍沿用旧判断。这为区分“条件匹配”与“决策落实”提供动机。建议放在论文 Introduction 第二段。待核：[cite:c1b71a59-1]。
- **不应预设独立的先验前馈网络**。JuICE 报告注意力头可同时承载上下文信息与参数记忆，呈现叠加现象；因此应实证选头，而非先验指定“先验 FFN”。待核：[cite:4e944e3f-4]。
- **一个主要干预算子**。不另设安全门或训练版本，减少对单篇论文核心因果命题的干扰。

## 2. 近邻工作

| 方法 | 原始材料中的方法概述 | ACRE 需要验证的区别 | 原始引用 |
| --- | --- | --- | --- |
| PASTA（ICLR 2024） | 在选定少量注意力头上将注意力重新分配至指定文本 | 目标由人工指定；ACRE 依据患者适用性自动选定目标 | [cite:4e944e3f-1] |
| AutoPASTA | 自动识别关键上下文，并修改注意力分数使其突出 | 不仅判断“重要”，还区分适用、不适用、例外、未知 | [cite:7728a054-1] |
| InstABoost | 对指令 token 对应的注意力 logit 加常数偏置，覆盖全部层与头 | 由统一增强转为随样本、规则和头分组变化的目标选择 | [cite:7728a054-2] |
| SEKA / AdaSEKA（ICLR 2026） | 利用谱分解编辑 key 向量，报告与 FlashAttention 的兼容性及开销特点 | ACRE 仅在匹配头上具有真正的 token 对干预；效率须独立实测 | [cite:a0831014-1] |
| JuICE（ICML 2025） | 选择可靠头并以两次前向缓解参数知识与上下文叠加 | ACRE 在选头目标中同时惩罚规则误用与无冲突损伤 | [cite:4e944e3f-4] |
| ProbeRAG | 以潜在空间探针分析知识冲突发生时机和原因 | 从检测冲突转向检验冲突是否改变当前患者决策 | [cite:4e944e3f-3] |
| MediEval / CoRFu | 原始评审描述了基于 DPO 的训练式方案 | 作为训练类相关工作，而非注意力引导直接对手 | [cite:19a1620f-1]、[cite:8e6413dc-1] |

**研究定位**：现有通用注意力引导主要回答“强调哪些内容”；ACRE 进一步研究“基于当前患者的规则适用性，应该强调哪部分规则，以及将何种证据与何种条件关联”。

上述描述是基于待核的评审资料整理；正式论文须核对每项先行工作的发表版本、具体算子、理论适用条件和实验设定。

## 3. 四个需要修正的问题

### 3.1 新颖性不能落在“选头 + logit 偏置”本身

InstABoost 已采用注意力 logit 常数偏置；其理论分析还讨论了增强指令注意力的收益与过度增强对任务上下文的抑制风险。AutoPASTA 结合自动片段定位与注意力强化。PASTA 已采用部分头选择策略。因此这些通用操作不应作为 ACRE 的独立方法贡献。

可辩护的差异限定为：

1. **偏置的结构**：匹配头上使用条件 token 与患者证据 token 的配对关系。
2. **偏置的目标**：决策头上依据软适用性切换动作、支持证据、否定证据或例外片段。
3. **头选择的优化目标**：反事实评分同时考虑正确遵循、错误套用及无冲突损伤。

三者必须拆开做消融。

### 3.2 “关系级偏置”只在匹配头上成立

在决策头中，查询位置通常集中于生成位置；对于给定查询位置，形式为 $B_{tj}$ 的偏置事实上等价于对 key 端 token $j$ 的偏置。因此：

- **决策头的创新在于“强调什么”**，而不是 token 对算子的数学形式。
- **匹配头的创新在于“如何连接”**，即证据查询位置到相应规则条件 key 位置的配对。

如果匹配头配对偏置相对于 key-only 偏置没有增益，应将其从核心贡献收缩至附录，不夸大“关系级”覆盖范围。

### 3.3 上游模块可能已经泄漏决策（最高优先级）

规则解析、临床 NLI、数值校验与规则动作组合，可能在模型外部基本推出最终决策。若如此，审稿人可以合理质疑为何不直接由规则引擎输出答案。

必须采用如下反证设计：

- 报告 **外部流水线直接作答**：将它视为信息量参照基线，而非自动等同于严格意义的正确率上限。
- 用 **软适用性概率 $p_i$** 取代硬判断 $a_i$，研究上游不确定性下的鲁棒性。
- 注入 **10%–40% 的关系判断错误**，报告完整退化曲线。
- 纳入 **不使用 $p_i$ 的匹配偏置变体**，检验模型是否能够独立利用条件—证据关联。
- 加入 **结构化关系直接写入提示** 的强基线，确保 ACRE 与提示基线获得相同上游信息。

只有当这些比较支持时，才能声称内部干预带来了独立增益。

### 3.4 引用与奖项表述需要核验

原始评审将 MediEval 标为 ACL 2026 长文，但未找到“杰出论文”的可靠记录。正式版本应核对官方会议页面；在核实之前**不要写“杰出论文”**。同时核查 CoRFu 的 DPO 设定和训练类基线定位。其他文献与数据集统计同样须核对，不能直接使用不透明的 `[cite:...]` 作为正式引用。

## 5. 论文叙事边界

- 不将所有病例的指南冲突等同于需要纠正的冲突。
- 不将注意力重分配本身解释为已经证明的因果机制；需有激活修补和行为指标支撑。
- 不把外部工具的金标准信息与模型推断信息混合汇报。
- “适用 + 冲突”“不适用 + 表面冲突”“无冲突”“信息不足”的划分，需要在实验标注协议中给出可执行定义；特别要避免把不适用规则的候选动作误写成最终指南决策 $d_G$。
- 数据集间头集合与超参数迁移必须在没有测试泄漏的条件下报告。
