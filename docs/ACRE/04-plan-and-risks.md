# 04 · ACRE 风险、决策门槛与 10–12 周实施计划

> 本文档将 [设计评审](01-design-review.md) 的风险判断和 [实验协议](03-experiments.md) 转化为执行顺序。以下是计划，不表示任务已完成。

## 1. 核心风险矩阵

| 风险 | 判断标准 | 处理预案 |
| --- | --- | --- |
| **结构化提示已经与 ACRE 一样好** | ACRE 与强提示基线的主指标差异无法与统计不确定性区分 | 检查关系噪声、长上下文、多轮场景与推理—答案一致性；若仍无优势，重新定位 |
| **RQ1 不成立**：现有引导方法并未增加误用 | 预实验中的 OAR 没有上升 | 不再声称“通用引导导致误用”；改检验适用冲突准确率与反事实成对准确率的联合改进 |
| **匹配头和决策头高度重叠** | 两组头的重叠率超过约 70% | 合并头组，作为实证观察报告，不强行维持双模块解释 |
| **配对偏置没有独立收益** | 相对于仅 key 端偏置，主指标无可靠提升 | 将核心方法收缩为适用性目标选择与反事实选头，配对偏置移入附录 |
| **增益来自外部流水线直接给答案** | 直接作答、结构化提示已解释收益，或注入关系错误后 ACRE 急剧退化 | 强化对 \(p_i\) 不确定性与拒绝强推机制的检验；如无剩余优势，重新评估内部干预价值 |
| **引用、数据许可或统计信息不准确** | 未找到可复现的正式来源／数据访问受限 | 修正论文表述、记录版本，必要时替换不可访问的数据集 |
| **实现不兼容或成本过高** | FlexAttention 或指定模型无法进行目标 head／token pair 编辑，或端到端开销失去实际意义 | 缩小模型组合、单独报告 kernel 与总成本，不能套用 SEKA 的效率结论 |

## 2. 最小可行证据链

正式开展大规模评测前，应依次确认：

1. **失败模式是否存在**：统一引导在“不适用 + 表面冲突”样本上是否表现出可测量的规则误用。
2. **上游信息是否已足够**：结构化提示、外部规则流水线直接作答能达到什么水平。
3. **目标选择是否有效**：在不选头的 ACRE 版本中，适用性条件化目标是否优于整条规则高亮。
4. **配对偏置是否独立有效**：相对于 key-only 是否存在增益。
5. **反事实选头是否必要**：相对于全头或通用头是否改善多指标权衡。
6. **鲁棒性和迁移是否成立**：噪声、跨指南／模型、长上下文和安全测试是否支持外部有效性。

如果前两项不能形成可信的差异，则不宜把大量资源投向后续模型扩大与机制可视化。

## 3. 周计划

| 阶段 | 时间 | 工作内容 | 应形成的可检查产物 |
| --- | --- | --- | --- |
| **阶段 A：关键预实验** | 第 1–2 周 | 复现标准提示、CoT、结构化提示、InstABoost、AutoPASTA、SEKA 等可执行基线；测试规则误用 | RQ1/RQ4 初步结果、基线复现记录、完整样本分层 |
| **阶段 B：最小 ACRE** | 第 3–5 周 | 实现规则解析、MedCPT、NLI／符号校验、软适用性、冲突门控和不选头版注意力编辑 | 可运行的端到端流程；目标选择和门控消融 |
| **阶段 C：反事实选头** | 第 6–7 周 | 生成条件／动作对照，在 MedCalc 可验证样本上粗筛与真实 activation patching，向 MEGA-CDP 迁移 | 校准头集合、头分组重叠率、迁移测试 |
| **阶段 D：消融与机制** | 第 8–9 周 | 完成 key-only 对照、匹配偏置、硬／软适用性、负偏置、0%–40% 噪声、两张机制图 | 主消融表、退化曲线、机制证据 |
| **阶段 E：扩展与写作** | 第 10–12 周 | 跨模型和外部数据集测试，安全压力测试、成本、统计检验、误差分析与论文写作 | 完整主结果、置信区间、附录、论文初稿 |

时间为相对周次；具体资源分配应随阶段 A 的结果调整。

## 4. 各阶段验收清单

### 阶段 A：预实验

- [ ] 文献与数据版本核验完成；至少明确 InstABoost、AutoPASTA 原始实现和可比设置。
- [ ] “适用／不适用／表面冲突／有效冲突”的标注协议冻结。
- [ ] 结构化提示与注意力方法获得一致的患者及规则信息。
- [ ] 完成外部流水线直接作答参照。
- [ ] RQ1 与 RQ4 的主指标、样本量及不确定性已初步报告。
- [ ] 据结果决定论文是否继续采用“误用纠正”叙事。

### 阶段 B：模块与最小干预

- [ ] 保存每条规则的条件、动作、例外及 token spans。
- [ ] NLI 与符号校验保留“蕴含／矛盾／未知”类别和置信度。
- [ ] \(p_i\) 的聚合方法、校准方案与不确定性规则明确。
- [ ] 闭卷冲突计算不访问金标签。
- [ ] FlexAttention \`score_mod\` 在所选模型和推理模式下可复现。
- [ ] 统一高亮、条件化目标、门控消融结果完成。

### 阶段 C：反事实选头

- [ ] 条件对照一次只变更一个影响适用性的变量。
- [ ] 动作对照只变更规则动作且验证标签逻辑。
- [ ] attribution patching 与真实 activation patching 结果已区分。
- [ ] 校准／开发／测试按指南或计算器分离。
- [ ] 头组重叠率以及合并／不合并的规则已记录。

### 阶段 D：机制与稳健性

- [ ] 匹配头 token 对偏置与 key-only 进行配对比较。
- [ ] 完成无 \(p_i\) 版本和 0%、10%、20%、30%、40% 关系噪声实验。
- [ ] 机制图与行为性能结果相互核对，避免仅凭注意力或探针结果推断因果。
- [ ] 明确是否保留“关系级”独立贡献。

### 阶段 E：扩展与论文

- [ ] 完成开放权重跨家族／规模实验，闭源只作提示参考。
- [ ] 完成 MedGUIDE、MedPIC-Bench 和其他可访问数据的外部测试。
- [ ] 完成 MedCounterFact 安全压力测试，明确模型仅用于研究评估。
- [ ] 报告 ACF、OAR、NCA、PairAcc、路径一致性、延迟和显存。
- [ ] 提供 bootstrap 95% 置信区间、McNemar 检验和 Holm 校正。
- [ ] 文献从 \`[cite:...]\` 替换为规范、可点击、可追溯的正式引用。

## 5. 投稿前判断

最终结论应以数据决定，而不是先写定研究叙事：

- **最强且最重要的对照**：InstABoost、AutoPASTA、结构化提示、外部流水线直接作答。
- **最重要的独立性证据**：匹配偏置不依赖 \(p_i\) 的变体与关系噪声退化曲线。
- **最重要的机制边界**：决策头是条件化目标选择，只有匹配头具备 query–key 配对结构。
- **最重要的负结果处理**：如果主要消融或对照无优势，就缩小主张，而不是增加未验证的模块。

## 6. 研究用途说明

本研究针对指南驱动的临床决策**模型行为评估**。即使在基准数据中有增益，也不能直接推导其适用于真实患者的诊断或治疗；临床部署需要额外的安全性、有效性和监管评估。
