## 2. 推荐的核验顺序

1. **新颖性直接相关**：InstABoost、AutoPASTA、PASTA、SEKA／AdaSEKA、JuICE。
2. **动机与失败模式**：MedPIC-Bench、ProbeRAG。
3. **评测可执行性**：MedCalc-Bench Verified、MEGA-CDP、MedGUIDE、MedCounterFact。
4. **训练类和通用冲突对照**：MediEval／CoRFu、ConFiQA、FaithEval。
5. **实现与通用能力基线**：MedCPT、FlexAttention、MMLU。

优先采信**正式会议论文、官方论文页面、作者代码库、数据集版本记录及对应修订稿**；若与预印本不一致，明确引用版本与发布日期。

## 3. 每项文献应补齐的字段

| 字段 | 要求 |
| --- | --- |
| 标题与作者 | 采用正式出版／公开版本 |
| 年份与出处 | 会议名称、论文类型，或预印本状态 |
| URL / DOI | 可公开访问、精确指向论文的永久链接 |
| 代码与数据 | 官方地址、提交或发布版本、访问条件 |
| 方法细节 | 干预对象、头选择、需要的监督与推理开销 |
| 数值证据 | 数据集版本、样本数量、评价指标、统计口径 |
| ACRE 比较方式 | 原论文设置是否能公平迁移到临床规则任务 |

对尚未找到的字段，应写“未验证／未公开”，不要猜测。

## 4. 两个特别容易写错的地方

### 4.1 MediEval 奖项

原始评审称 MediEval 为 ACL 2026 长文，但未找到其“杰出论文”记录。提交前需查官方论文列表及获奖页面；**未核实则删除奖项说法**。当前方法与评审文档均不把“杰出论文”作为事实。

### 4.2 注意力增强与效率比较

InstABoost、AutoPASTA、SEKA 的运算形式、适用头集合、片段定位方式与 kernel 兼容性可能因论文版本而异。ACRE 的 FlexAttention 性能必须在同等模型、硬件、序列长度、batch、解码设置下**实测**，不能直接继承其他论文的加速比例。
