## 1 本次整理的依据与状态

依据用户提供的完整论文草稿和聊天中的六项“主张—实验—证伪条件”。本次编辑形成研究方案与论文工作稿，不等于完成实验、实现或文献核验。原始附件应原样保留以便追溯。源文自称来自试点的数值也没有在本次编辑中获得原始预测、运行配置和锁定测试集的核验，因此未迁入主线结果。

主稿保留原来的现象→机制→方法结构、ASTER 名称、五卷协议、主要算子、同信息基线、消融和表 1–14 的位置。表 9–14 不保留假设性性能数值。摘要、引言、结果标题和结论均不再预设实验成功。

## 2 实质性修订及原因

| 原稿问题 | 主线稿处理 |
|---|---|
| 预填数值与“我们发现／因果干预显示／显著优于”等结论混用 | 改为待验证假设与待填结果；全部经验性结果须由真实运行补齐 |
| “差异不显著”等同于“持平” | 明确等效／非劣效需要预定界值和区间判定 |
| 常数偏置质量比推导被扩展成“至多帮一个患者” | 保留固定注意力计算中的精确关系，删除整体准确率的必然推论 |
| 组内处置份额被误读成全上下文份额 | 明确分母仅含该组处置；不推出全上下文质量或准确率单调 |
| 强门控“等价删除”的参照不明确 | 限定为保留位置、相同计算图的竞争键屏蔽；与物理删文本区分 |
| 删除极限被扩展成完整贪心序列必然一致 | 先比较逐步 logits；序列结论另需非并列等条件 |
| 盲判不变性只要求处置等总长度 | 加入所有非处置内容、位置、角色及掩码一致的条件 |
| 原稿 U2 非零分布差却用于支持精确不变性 | 改为完整分布与张量检查；容差和误差来源需记录 |
| 缓存共享忽略患者相关绑定 | 患者相关绑定只作用于指南前缀之后的查询；指南前缀必须与患者无关 |
| 原位“绑定”公式实际上只对集合加偏置 | 明确它是联合高亮，不能声称已实现一一对应的成对绑定 |
| 预测分支与金标分支共用符号 | 分别使用预测分支和金标符号 |
| 零概率、并列、NONE、多词元编号未定义 | 给出边界行为和验证要求；这些是规格要求，未声称已实现 |
| 先写入盲判编号，再做软否决，可能使编号与门控目标相反 | 规格明确为逐组读出分布、软否决、再写入校正后的编号；同时记录校正前后分布。并列时固定编号选择，但关闭该组门控与强调。此修订待实现验证 |
| 盲判的第一个预测可能直接取自处置位置 | 要求固定非处置起始前缀，并确保所有分支评分的查询位置均为非处置角色 |
| 门控强度和强调强度的参数域未明确 | 规定基础门控强度非负，强调强度位于预定的非负有界区间 |
| 默认 ASTER 不门控选项，但声称消除所有竞争处置 | 限定屏蔽结论范围；将选项诱饵作为 ASTER+O 的比较问题 |
| “文本做不到”“自由文本只能注意力干预”等绝对表述 | 改为同信息、匹配成本、原生性能约束下的经验比较 |
| 生成任务只给 ASTER-full 比较较少的证据员基线 | 增加共享证据员信息的附注、高亮和重排序对照要求 |
| 逐题 McNemar 未处理树内相关性，也不适用于连续指标 | 以聚类配对方法为主；说明 McNemar 的适用条件 |
| 评分缓存仅用“唯一输出” | 缓存键包含病例、参考、评审提示和版本，防止跨上下文误复用 |
| 伤害率微平均与 NCA 宏平均可能混用 | 明确分母，记录何时准确率变化等于纠正率减伤害率 |
| “Decoy-2×2”却有三种处置条件 | 暂称诱饵配对诊断集，等待正式析因设计 |
| 二分支噪声中错误 argmax 概率可低于 0.5 | 要求按分支数、NONE 和真实 argmax 条件定义噪声 |
| 数据已公开、无隐私、标注已付酬等未核实事实 | 改为按真实记录填写的伦理与数据事项 |

## 4 需要真实数据才能完成的事项

1. 锁定按树／指南划分的清单，以及所有配对底稿与变体。
2. 用原始预测和计数重建表 2–5、9–14 及所有分析曲线。
3. 核验预填表的算术，不用人工修正后的占位数值替代实验重算。
4. 从实际标注记录计算有效率、分歧和一致性。
5. 记录成本计时环境、缓存状态及完整端到端开销。
6. 预先固定统计比较族、非劣效界值、解析失败和缺失输出规则。
7. 只用同一份结果数据派生摘要、正文、表格和结果图。

## 5 配图约束

当前允许的方法图、任务示意和五卷实验设计图须标注“方法设计”或“研究方案”。由门控公式生成的曲线须标为“解析示意，非实验结果”。禁止绘制预填准确率、假设性显著性、拟定规模或未验证机制层窗口，并把它们呈现为实验发现。方法图中的错误路径和纠正路径只能作为虚构示例。
