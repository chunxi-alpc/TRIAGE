## 投稿检查清单

- [ ] 正式测试集、树／指南隔离、配对标识和排除规则已锁定并保存哈希。
- [ ] 所有【预填】数值已替换或删除；摘要和结论仅引用可追溯结果。
- [ ] 原稿中的试点与正式测试结果明确分开，不跨分母移植百分比。
- [ ] 由原始计数计算 NCA、CA、H、伤害率、纠正率和诱饵采纳率。
- [ ] 路径指标固定节点集合、无效输出和终止规则，并记录评审版本。
- [ ] 主张比较采用相同可用信息；证据员贡献与执行器贡献有独立对照。
- [ ] 显著性、区间、非劣效或等效的统计对象及聚类结构正确。
- [ ] 理论性质只在列明的假设下表述；删除极限不冒充物理裁剪等价。
- [ ] 缓存、处置信息泄漏、词元对齐、概率并列、NONE 与数值稳定性经过实现核验。
- [ ] 消融、跨模型复现、覆盖与噪声曲线、延迟和成本均有实际产物。
- [ ] 同一结果在摘要、正文、表格、图注与补充材料中数值一致。
- [ ] 引文、数据来源、许可、标注及伦理陈述均已核对。
- [ ] 实测不支持的主张已修改，负结果和失败范围已保留。

这些条目目前均不标记为实验已完成。实际完成后应补充运行或产物链接，再更新状态。
