## 本次收窄的保证与解释

**弃权不构成统计风险认证。** 温度缩放与间隔阈值属于经验校准和选择性干预。当前主方法不使用保形预测或风险认证，因此不宣称有限样本覆盖率、金标被压低概率上界或伤害率保证。新增相应保证需要独立定义假设、估计量与完整验证程序。

**输入隔离不消除参数先验。** 删除可见处置可以隔离本次输入中的处置内容，不能使模型遗忘已有医学知识。提示要求只依据事实和条件，也不能替代行为检验。

**高概率不等于判断正确。** 温度缩放不改变最高类别。同一骨干模型在分类与生成两阶段可能共享错误，模块三可能放大高置信误判。`prediction`、`NONE` 与 `abstain` 必须分别记录，不能把拒绝决策计成正确的 `NONE` 分类。

**组级不编辑不等于整例回退。** 某组增益为零时，其他组仍可能被编辑。只有所有组都不干预并绕过编辑路径，且输入及推理设置与基础运行一致，才检验全病例输出或数值的一致性。即使精确回退成立，也只证明关闭机制有效。

**表征可分不等于控制有效。** 模块二还需验证方向在在线顺序中的可读性、符号和迁移。局部键变化的代数性质不能替代对最终分支、处置、完整路径及退化的测量。处置平衡降低混杂的设计意图也不能直接写成估计方向严格不含处置语义的定理。

## 历史审计如何使用

[原稿审计](audit.zh.md)与[结构化记录](audit.json)检查的是 2026-10-26 原稿的分母、占位算术、表述和公式边界。通过内部算术检查不表示成绩真实。原稿中的数据规模、层号、标注人数、成本或显著性均不能据文字本身视为已完成事实。历史引文占位符不是正式来源。

当前主线不报告预填成绩。旧证据员覆盖率、保形集合大小、对数门控解析曲线等不能作为本版默认方法的评价结果；若将其恢复为单独消融，须清楚记录版本、额外信息和成本。

## 投稿检查清单

- [ ] 树／指南划分、配对关系、互斥组、祖先条件和排除规则已冻结并保存哈希。
- [ ] 所有预填结果已删除或由可追溯的锁定测试结果替换；试点与正式测试分开。
- [ ] 模块一仅接收条件视图；患者既往治疗事实保留；原始问题、选项和处置字段的输入隔离经过核查。
- [ ] 合法标签在实际分词边界经过验证；`prediction`、`NONE`、弃权、并列与数值异常处理符合规格。
- [ ] 单温度、阈值、增益与标签映射只在开发阶段确定；报告校准、覆盖率和高置信错误。
- [ ] 模块二仅用金标开发最小对，未使用模块一伪标签或测试病例；在线可读性已验证。
- [ ] 模块三实际编辑位置、缓存隔离、未选头状态与全病例零干预回退有运行记录。
- [ ] 主方法与映射、附注、裁剪、融合、SEKA／AdaSEKA 共享同一模块一输出；成本口径一致。
- [ ] 由原始计数计算 NCA、CA、H、伤害率、纠正率及诱饵采纳率；所有失败计入冻结分母。
- [ ] 路径关键节点、未到达节点、无效输出和终止规则已固定，并记录评审版本。
- [ ] 显著性、置信区间、非劣效或等效的对象、聚类和比较族正确。
- [ ] 理论性质列明假设；经验阈值没有被表述为保形覆盖或风险认证。
- [ ] 跨模型、条件切片、噪声、延迟和能力保持的结论均有独立产物。
- [ ] 摘要、正文、图注和补充材料使用同一方法版本、分母与数值。
- [ ] 引文、数据来源、许可与标注事实已核对；不支持的主张已修改，负结果已保留。

这些条目均不因文档更新而自动完成。实际验证后应补充对应运行或产物，再更新状态。
