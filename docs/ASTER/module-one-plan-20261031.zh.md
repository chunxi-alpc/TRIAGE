版本：2026-10-31；取代本轮原七种方向组合搜索和LEACE阶段。三模块接口不变。

原方向来自年龄最小对；新病例检验跨条件、跨来源迁移，不预先称为通用临床适用性方向。

## 开发与冻结

1. 为新100例运行零编辑完整生成。诊断位置为首个基线错误；全对病例取末个参考决策，所有病例保留。
2. 候选头集合为原4头、B4子集、1–35层全部280个可用方向头。B4来自旧43例，只提议候选；层0没有已学习方向，排除并记录。若B4子集全在层0，按同一B4候选窗口的因果排名取相同数量的非零层头并明确注明。
3. 在上述诊断位置，使用未编辑查询测量单位均值方向的理论打分位移平方，先按头、再按病例平均。参考增益g0=2/sqrt(mean(delta_s_unit^2))；目标RMS=2固定于本轮选择之前，不查看120例结果。
4. 每集合比较0.5g0、g0、2g0，共9个配置×100例，仅读取决策边际。取平均边际最高的两个配置；并列时取较小增益，再按配置名固定排序。
5. 对两名候选各生成100例，按完整路径正确数、平均边际、较小增益选择最终配置。完整路径计数来自自由生成；边际评分中的金标前缀不进入生成。
6. 同时满足完整路径净改善>0、同一决策位置平均边际改善>0，才进入验证。这是继续实验的开发条件，不是显著性或临床有效性保证。否则进入64单元诊断，不扩大方向搜索。

每个配置使用完整规则位置，包括被排除后代子树；起始词元、患者及任务文字保留。正负增益随已接受分支分配，未确认子树不抑制。此范围与失败诊断中的目标编号／处置位置分开记录。

模块二仍直接读取原始病历与条件，不抽取事实、不拆条件；原18例拟合的NONE校正保持不变。直接判断阈值也从新100例选择并冻结，旧43例结果仅作历史比较。不同执行器共用同一份已保存判断。

## 验证

金标路线：零编辑、均值、谱、反向均值、随机方向13／37／73，120×7=840单元。预测路线：零编辑、均值、同三个随机方向，120×5=600单元。只改变方向，头、位置、单位范数、增益绝对值全部相同；反向均值不能误用反向谱方向。

主指标为完整路径正确率、配对纠正／退化和来源等权差；同时报告终点、无效输出及根决策边际。验证的根边际是辅助指标，不代表深层决策。按来源重采样区间，仅描述当前基准范围；头、词元及随机方向不作为独立病例。已有结果仅在输入、执行与配置一致时允许复用；本轮新配置独立保存。

## 失败诊断

在原4对、2来源上，每对双向切换患者状态，固定目标规则编号和处置，编辑全部280个可用方向头。

- 患者前置：零编辑、真实K替换、真实V替换、真实KV替换、逐位置匹配真实键差分范数的均值平移，共40单元。
- 指南前置：零编辑、离线真实键差分移植、同样范数匹配的均值平移，共24单元。
- 离线键差分先在RoPE前计算，再按在线目标位置旋转；编号与处置词元逐位置对应。不能把指南前置下本就相同的两份患者无关缓存当作真实差分。
- 报告向供体分支移动的边际、供体分支被选比例、原分支正确率和无效输出；两个相反目标不是独立患者。

真实K有效而均值无效指向压缩损失；V/KV有效而K无效指向算子限制；患者前置有效而在线移植无效指向顺序迁移；全部无效只说明当前干预未控制决策。

## 实施和资源

入口在 experiments/aster_bottleneck_20261031/module_one.py，由advanced顺序调用。数据和私有逐例输出留在服务器的 /home/gcx/aster_bottleneck_20261031/module_one；完成后自动生成汇总和报告。
