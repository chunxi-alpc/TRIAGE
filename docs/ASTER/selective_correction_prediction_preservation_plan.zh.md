### 研究目标与优先级

本轮不再把“多搜索一组 16 维 M3 损失权重使旧路径分数更好”作为目标。按顺序回答：

1. **为何原模型走错首次分支？** 区分表面错误类型、确定性规则错误、患者证据定位错误、无关信息影响、读出表示或证据预算不可达。首先诊断，不预设“都是语义错误”。
2. **固定已有候选修正器后，能否减少原本正确→错误的预测转移，同时保留有限的有效纠正？** 用门控和预测保持做保护性机制消融，不把保护机制包装成独立纠错能力。
3. **错误诊断是否支持一个可核验、具备拒判能力的语义条件验证器？** 仅在证据支持、存在足够可标注样本时实施最小验证器；如主要瓶颈是表示/预算，则走预定替代诊断分支。
4. **候选方案在来源不重叠的新指南上是否仍成立？** 如果没有合格新来源，输出“未完成独立确认”，不得用已反复使用的旧测试集替代。

### 1.2 数据隔离与可追溯性

- **拟合**：MEGA E1 / Dataset A 的 80 来源及 2540 对；既有五折每折 64 来源拟合、16 来源折外。20 开发来源仅用于预定验证与选择（必须首先核验其既往使用）；40 受控留出与官方 7458 路径仅能算**历史描述性/回顾性测试**，不能再当“新独立确认”。
- **按指南来源隔离**：病例、节点、配对端点、改写、相同内容及近重复不得跨训练和验证；记录来源和病例族、固定输入哈希与样本数量。对原有五折报告保持原口径；任何新增估计器（门控、保护阈值、语义解析规则）都不能使用当前外折的标签或其模型拟合特征。
- **标签权限**：推理只使用当前输入、冻结原分数、可取得的内部特征及已训练参数；不使用金标准、参考路径、配对另一端、目标叶节点来决定是否改判。标签只用于已授权的训练或离线评价。
- **独立新来源**：先查询许可与来源清单，排除曾用于构造、训练、开发、历史测试、校准与原始模型评估的指南家族。以文献/指南家族、版本和模板近重复核查；不能证实独立性就标“复用来源”，禁止写“独立验证”。医疗语义标签需合格专业核验；模型自动审核不等于临床专家标注。
- 先冻结计划版本、有效分母、主要终点、一次允许的替代方案和可信区间计算方式，再读取候选方法在评价来源上的新表现。保留每一次尝试与失败，不能事后删除不利配置。

## 3. D1：首次错误分支诊断与修正能力评估（优先级 P1）

### 3.1 错误单位与直接证据

- 分别在**自然路径**和**受干扰路径**定位原模型第一次偏离参考决策的节点。实际动态路径与参考路径可能分叉，必须保存可比的节点标识、可达性和首次分叉原因；无法对应时标“不可比较”，不能把任意后续节点当首次错误。
- 对每个可比较首错，保存原判断分数、金标方向、正确分类所需最小跨界幅度、固定 E1/J_zero 候选修正和修正后分数。另记录原模型已答对节点上的不利修正，按幅度分桶；以来源、病例族、具体节点与路径作为相互区别的单位。
- 复核已有 166 个 R1 首错/150 个在固定 b0 线性规划下不可达的证据边界。明确是“该 16 维线性特征 + 固定截距 + 给定证据预算”的可达性，不是语义不可达。补充 R0、J_zero 下的相同分析时必须记录各自起始分数及约束，不直接挪用 R1 的分母或结论。
- 估计可解释的任务空间上限：对于当前固定候选改判，统计能修复的独立错误数、引起的误修数、所涉及的来源数与病例族数。理论上即使完美门控也最多从这些候选中选择，除非新增独立修正能力。

### 3.2 结构化错误归因（不把分数变化直接当作语义因果）

对拟合来源中的代表性、来源分层的首错节点开展**不看方法表现的语义证据审核**。独立记录两列：

- **观察到的规则/证据表面错误类型**：单条件阈值比较、单位或比较符号、时间/时点推断、与或逻辑、否定/排除/例外、患者事实定位/跨句指代、缺失或矛盾信息、其他/无法判断。分类互斥主类 + 可选次类，保留可检验的指南和事实引用位置；未知不强行猜测。
- **当前修正器为何未纠正**：读出幅度低于边界、线性约束不可达、候选改动方向错误、可能干扰敏感、缓存/路径覆盖不足、待定。此列来自量化诊断，可多标签；不和第一列混同。

自动审查可用来初步提取和排序，但不可将自动注释冒充专家语义金标。对决定后续方法路线的样本应进行独立复核并记分歧；如果无临床审核资源，只做**程序可核验的逻辑/数值子集**与未核验探索性分类，明确限制。

### 3.3 D1 决策点

- 若有足够的跨来源、具备可核验依据的**规则解析或事实匹配错误**，进入 D3 的语义验证器最小实现；D2 仍可作为低成本安全消融并行进行。
- 若错误主要表现为“原分数边界过远、当前 16 维受约束读出不可达”，不能直接声称语义错误；执行 D3B 的单次固定容量/约束上界诊断（不是再次搜索 16 维损失）。
- 若没有足够标注或大多数首错不可归因，先交付 D1 的可观测结果和未确定原因，再做 D2 的确定性保护对照；不得据猜测大规模训练语义验证器。

**验收**：首次错误逐例数据、按来源加权的错误类型表、边界/可达性表、代表性审计案例、分母与未知项、明确 D3 或 D3B 分支判据。

## 4. D2：固定修正器的选择性修正与预测保持消融（优先级 P2）

本阶段回答**风险控制能力**，不预设产生新的纠错知识。先用 E1 仅配对修正和 J_zero 两套可核验冻结修正器分别评估；**同一套方法内部禁止混用截距、头集合与训练参数**。E1 含独立截距的历史完整方法仅作单列诊断。禁止以哪种历史测试更好来选择候选。

### 4.1 四组比较与训练条件

同一候选修正器下固定 5 组：原模型、无保护修正、仅门控、仅预测保持、门控+预测保持。最终输出在校准前采用同一二元分数口径；部署阶段既不需要真值，也不使用配对另一端。

**门控候选**：仅当原分数 s 和候选分数 u 的二元预测不同时，决定是否允许改判。训练标签为“候选改判是否正确”，特征预置为 s、u−s、|s|，单一 L2 逻辑回归；主阈值 p>2/3，C=1，训练来源均权。候选样本只从训练来源的**折外修正输出**构造；若对外折评价门控，必须在该外折的训练来源内部再做嵌套交叉拟合，不能用含外折训练信息的“全 80 来源折外池”直接训练后评价该外折。

**样本充足性门槛**（研究可行性，不是显著性保证）：在拟合来源内，正确改判与错误改判各至少 30 次，且各覆盖至少 10 个独立指南来源，才训练监督门控；不满足则标记“门控统计上不可可靠估计”，执行“不允许改判”的保守回退对照并继续预测保持消融，不能把回退称为学会选择性修正。公开实际计数、类比例、来源覆盖和不确定性。若训练类别之一不存在，不拟合分类器。

**预测保持候选**：在训练折外“将发生改判”的样本上，取 |s| 的来源均权第 75 百分位阈值 q；仅对 |s|≥q 的节点保留原预测符号。若上一阶段输出为 v，原 s≠0，在保护区令 v′=sign(s)×max(sign(s)×v, 0.1|s|)；当 s=0 时保留 0。其余位置采用 v。保护阈值在训练期冻结，不由旧测试结果决定。该保证针对**节点预测符号**，不保证原判断正确；尤其要统计高置信原错误被误保护的损失。若训练集中完全没有候选改判，取 q=+∞ 并写明不具备可估计保护区。

**预算兼容**：非线性门控/截断会破坏原线性 C/F 差分的解析保证。按训练 C/F 对实测最终附加修正 d=v′−s 的最大差 M 计算必要的全局缩放 a=min(1,δ/M)，M=0 时 a=1；最终分数 s+a·d。只对该版原有的合法预算使用这个计算；不能以旧 δ 替代修订版新尺度。缩放后重新统计是否仍发生翻转、纠错保留和实际 C/F 训练预算违规；留出预算单独检测，不保证留出零违规。另列“无门控的同幅缩放”对照，分离纯缩幅的贡献。

### 4.2 保护性终点和可证伪条件

- 首要：在**原模型已答对且结构简单**的可标注参考节点上，新增错误比例 H/N_correct；准确给出 H、N_correct 和来源数。结构简单须由指南规则结构定义（例如单一可检查阈值或布尔条件），**不**将原分数绝对值大直接定义为简单。
- 辅助：原错改对 B/N_wrong、总正确率净变化 (B−H)/N_total、无保护原本纠正样本被联合方法保留的比例、实际改判率与保护覆盖率。自然/干扰动态完整路径独立计算。四格计数保存“错→对/对→错/对→对/错→错”。
- 同时报告 A/P 原分数差和最终分数差 RMS/方差降低、C/F 有向响应与方向正确率、修正 RMS、逐对超预算、双端全对及 F0 同侧事实变化。**不能**用总体有向响应接近 100% 推断医学正确率，不能用节点符号保持推断路径天然保持。
- 来源级成簇 2000 次配对自助重采样（种子 11），每次重算各分母并输出有效次数；事件极少时报告原始次数/来源和适当的事件比例区间，不用零宽 bootstrap 当风险上界。
- 主方案预登记研究性效用下限：联合组至少保留无保护组已纠正**完整路径**的 50%，且实际至少纠正一条；若无保护组没有纠正则判“不可估计”，不得宣称成功。正式“误修显著降低”需要同一预设首要子集上联合−无保护的 95% 区间上界 <0；未达到则写“未证实”，不能改阈值重测。

D2 **继续/停止**：若保护减少误修但几乎全部牺牲纠错，标“防御退化到原模型”，不是新方法成功；若候选改判样本极少，停训监督门控但继续 D3 的独立语义候选（只要 D1 支持）。无论 D2 正负，都不把结果倒灌用于挑选 J/J2 权重。

**验收**：五组逐例预测、门控可训练性审计、保护节点零符号翻转单测、预算缩放前后指标、错误转移及历史来源置信区间。真正新来源的验证放到 D4。

## 5. D3：基于首次错误归因的最小语义验证器（优先级 P3）

**仅当 D1 的审核支持可程序检验的条件/事实错误时启动**；不凭“16 维修正失败”直接假定存在此类错误。先做最小、可拒判的验证器，而不是再训练大模型猜答案。

1. **范围冻结**：只选 D1 训练/开发来源中出现频率最高且跨来源可核验的 1–2 类错误，如数值阈值与比较符号、明确的多条件逻辑或有明确时间参照的条件。完整支持不了的例外、定义、单位或时间规则必须输出 abstain，不得猜测。
2. **输入/输出结构**：解析当前指南条件为可执行表达式（变量、比较运算符、阈值、单位、时间条件、组合逻辑、例外）；从患者记录提取所需事实及原文证据定位；只在事实唯一、单位可无歧义转换、所有必要条件覆盖且例外已排除时执行确定性判断。日志保留条件、证据片段位置、失败原因、结果或拒判；推理不得读取金标。
3. **覆盖率作为成本**：输出 coverage、覆盖条件下正确率、全量按拒判回退原模型的准确率；显式记录“错误事实抽取”“条件规则误解析”“拒判过多”。高准确率低覆盖不可单独宣称改善整体任务。
4. **决策**：若验证器拒判，沿用原模型；若验证器与原模型相同，沿用原分数；仅当满足完整证据检查且预测不同，才作为一个候选纠错决策。比较“只做语义验证”“只做 D2 保护”“语义验证 + 保护”与 R0、J_zero、E1_pair_only（各固定口径）。组合时规定先生成语义候选、再做保护；须单列保护阻止的正确纠正与错误纠正，避免强保护直接抹去语义收益。
5. **迭代上限**：第一轮固定规则实现；允许根据拟合来源的可复现失败修正一次明确的解析/数据工程错误。不得根据旧留出或官方测试错误类型不断增加特例。单独保留无法解析的所有输入及原因。

**验收**：结构化规则/证据 JSON、解析和执行单测（阈值同侧、比较符号、等号、单位、时间、组合、否定、缺失/矛盾、例外）、覆盖与纠正转移表、盲审核记录、失败案例。无合格语义金标则将 D3 标 partial/blocked，不生成伪专家标签。

### D3B：若 D1 主要支持表示/预算瓶颈

仅做一次**已冻结候选的修正能力边界分析**，禁止再做 J/J2 的大规模损失/预算搜索。固定相同节点与来源，对 16 维与**一个预先指定的 32 维特征**（如果已有可靠缓存）比较：原错误 margin、训练/留出证据保护代价、可达性上界、A/P 分数预测力；缺失 32 维缓存则先审计 GPU 需求与授权，不擅自重提全量激活。这个分支的目的仅是判断特征容量可能否定当前 16 维的可达性，不根据旧测试选择模型。若已不能支持有效增长，明确停止分数修正性能路线并转回语义/数据诊断。

## 6. D4：真正的新指南来源验证（优先级 P4）

- 在看新增方法表现之前，以版本化配置明确锁定：一个主要候选、一项主要安全终点、一个主要完整路径终点、评价分母、分支回退规则、独立性检查、bootstrap 随机种子及判定标准。以前用过的 80/20/40、官方 MEGA、NLI4CT/MedPIC 均不构成此阶段的“首次独立确认”。
