## 1. 数据与冻结清单

### 1.1 来源与划分

主任务为 MedGUIDE-CF 五卷选择题及 MEGA-CDP 单轮完整路径。MedPIC 原生任务与规则增强适配分报，FaithEval 和 MedCalc 按各自任务另报，不将异构指标平均成总分。来源规模不等于派生集分母；原文、数据卡及版本身份沿用[引用记录](references.zh.md)。

MedGUIDE 按同源指南簇划分为方向拟合／训练、温度校准、验证选择、锁定测试，比例 60/10/10/20。MEGA-CDP 保留官方测试边界，训练侧按 75/12.5/12.5 分配前三种用途。划分种子 20261028。近重复、同源指南版本和同底稿变体不得跨划分；跨数据集同源核查先于任何拟合。测试指南即使无答案标签也不能自动进入继续预训练，转导设定须另列。

MedGUIDE 必须匹配包含兄弟分支的完整树，不能只输入金标路径。主五卷清单固定为五卷全部验收的共同底稿；额外原生集合单列。路径主要集合要求同底稿 NC、SW 均有效，且两卷各有至少一个参考关键分支。其余卷和完整官方原生集合为补充，不按模型成功率筛选。

### 1.2 构造与有效性

五卷定义只以主稿第 2.2 节为准。CS 由独立规则验证器检查条件、单位、阈值边界及祖先路径的金标翻转。处置交换保持规则映射和下游依赖；无法一致更新者排除并记录。熟悉度按模型独立测量，诱饵在观察测试预测之前固定。

MedPIC 按选项集合完全匹配评分，关联对要求两题均正确。其原生题不直接提供完整规则包；适配规则来自独立可追溯来源，对全部方法共享，不能根据测试答案反推。映射允许多对一；多义或不完整映射按统一回退处理，而非删除困难样本。

每例至少记录来源版本、指南簇、底稿、划分、卷、原始与修改片段、规则结构、金标、诱饵、构造核验、排除原因和许可状态。同一冻结清单用于所有方法。质量不合格样本可在运行前按统一规则排除；模型超时、非法答案和解析失败保留在锁定分母中。

## 2. 模型、预算与比较轨道

主骨干为 Qwen3-8B、Llama-3.1-8B-Instruct；MedGemma-27B-Text-IT 为医学扩展，Qwen3-1.7B 用于工程先导。配置入口为 [models.json](../../configs/models.json)、[datasets.json](../../configs/datasets.json)、[baselines.json](../../configs/baselines.json)。下载记录与配置存在不构成运行证据，具体修订、模板、指纹和后端须冻结。

普通最终生成贪心解码，Qwen 主协议关闭思考；思考扩展单列。所有方法共享格式、上下文与单次输出上限。重排另固定候选采样策略、总词元预算和随机种子，最终确定性选择。拟合方向或训练使用 13、37、73 三个种子，确定性无拟合方法不重复计作独立结果。

| 轨道 | 共享信息 | 解释范围 |
|---|---|---|
| 原生方法 | 相同完整任务；各算法按注册适配运行 | 端到端系统与成本 |
| 共享判断 | 同一次模块二输出 $\mathcal S_g$、相同可达性 $e_g$、输入与映射 | 判断固定后的执行增量 |
| 金标诊断 | 独立金标分支或片段 | 去除判断错误后的剩余执行误差 |

共享轨不能分别重跑“同型号分类器”后声称信息完全一致。$\mathcal S_g$ 始终是主稿五元组；最大概率从分布导出，$e_g$ 单独传递。执行器启用条件为 $a_g=0,e_g=1,\hat r_g\ne\mathrm{NONE}$。所有组未启用时采用同一原模型回退；部分组启用时不为其他组补写推测分支。

## 3. 执行器及训练基线

### 3.1 必需比较与适配

| JuICE | 开发集选头，首遍保存头输出，次遍加入缩放输出；不是两次普通生成；附注组合另记 TS-Note+JuICE |

CAD、JuICE、PASTA、SEKA 为主干预基线；AutoPASTA、AdaSEKA 为扩展。提示重复为补充。金标映射／裁剪／干预单列诊断，不进入可部署排名。PASTA、SEKA 与 ASTER 的原生作用范围不同，保留机制差异，并配套 ASTER 仅正向控制。SEKA 的正负投影不等于 ASTER 的正负规则增益；新增有符号版本必须单列。

### 3.2 分布、注意力及输出层控制

CAD 的注册形式为：

```math
p_{\mathrm{CAD}}(y_t)=\mathrm{softmax}\!\left[(1+\alpha)z_\theta(y_t\mid c,x,y_{<t})-\alpha z_\theta(y_t\mid x,y_{<t})\right],\qquad\alpha\ge0.
```

PASTA 对高亮位置 $J^+$ 保留原权重，对其余位置乘 $0<\alpha\le1$ 后归一化。SEKA 沿用其原投影式 $k'_j=k_j+(g^+P_h^+k_j+g^-P_h^-k_j)/2$；此处投影及增益是该基线的局部记号，不与 ASTER 的 $\Delta_h,g_r$ 混同。

直接偏置对启用组的选中规则加 $+\beta^+$，对兄弟规则加 $-\beta^-$，其余零。主控制复用模块一的 $H^*$，将键值头映射到全部共享查询头；查询范围覆盖指南预填充之后的患者、问题与生成，不回改指南编码，保留原因果与填充掩码。共享选头成本也计入。独立选头变体匹配监督和搜索预算，另报。偏置与键位移单位不同，不要求幅度数值相同。

有单组确定映射 $m_g(r)$ 时，TS-Fuse 使用：

```math
q_g(o)=\sum_{r:m_g(r)=o}p_g(r),\qquad
s(o)=\log p_\theta(o\mid G,P,Q,O)+\lambda\log\max(q_g(o),\epsilon).
```

多词元选项须完整评分；NONE 不强行分配给处置；多组相关概率不无依据相乘。无可用映射按统一回退保留全体分母。

重排候选数记为 $K_{\mathrm{cand}}$，避免与模块一头数上限 $K$ 混淆。候选评分沿用长度归一化模型分数、启用组分支对数概率及无效节点罚项：

```math
s(y)=\frac{\log p_\theta(y\mid x)}{|y|}+\lambda\frac1{|\mathcal G_y|}\sum_{g\in\mathcal G_y}\log\max\{p_g(r_g(y)),\epsilon\}-\eta E_{\mathrm{invalid}}(y).
```

解析、空集合、缺失／矛盾节点和罚项在开发阶段冻结，失败不得获得偏高分。并列按候选序号选择。测试金标仅计算候选覆盖上界，不选最终答案；额外评审模型与调用另报。

### 3.3 训练控制

SFT-NC 只使用原规则训练样本；SFT-CF 使用经核验的五卷平衡样本。比较时固定基础底稿及监督词元预算，额外全数据版本另报。SFT-CF+DPO 从同一 SFT-CF 检查点初始化，以其固定副本作参考，偏好对仅来自训练来源，记录负例生成与验证成本。CPT+SFT-CF 先在许可训练文本继续预训练，再接受相同 SFT；CPT-only 另作诊断。

主训练接口为一致的参数高效微调；适配器、学习率、步数、精度、优化器和停止条件须冻结，全参数版本另报。各方法报告底稿数、监督／无标签词元、偏好标签、更新参数量、GPU 小时和调参次数。不把额外偏好或语料称为相同监督。训练执行器加共享 ABAA 时沿用原分类缓存，不能用训练后模型重新判定后仍称同信息。

## 4. 指标与失败政策

### 4.1 答案与配对单位

$D_v$ 为卷 $v$ 的锁定集合，$c_i^m$ 为方法 $m$ 在实例 $i$ 的正确指示，$m=0$ 为原模型。单选完全匹配，多选要求选项集合完全相同。未运行不是零分，缺少金标不是猜测计分；运行失败和非法输出计错。

```math
\mathrm{Acc}_v^m=\frac1{|D_v|}\sum_{i\in D_v}c_i^m,\qquad
\mathrm{HR}^m=\frac{\sum_{i\in D_0}c_i^0(1-c_i^m)}{|D_0|},\qquad
\mathrm{CR}^m=\frac{\sum_{i\in D_0}(1-c_i^0)c_i^m}{|D_0|},\quad D_0=D_{NC}\cup D_{IC}.
```

NCA、CA、H 仅使用主稿公式；缺失整卷时不临时改公式。HR／CR 使用相同无条件分母，微平均变化等于 CR−HR；条件退化率另除以原模型答对数，不混用。SW 诱饵采纳率为选择预先指定且不同于金标的诱饵标签的比例，与正确率及失败率同报。

```math
\mathrm{PairAcc}^m=\frac1{|\mathcal P|}\sum_{(i,j)\in\mathcal P}c_i^m c_j^m,\qquad
\mathrm{All5Acc}^m=\frac1{|\mathcal B_5|}\sum_{b\in\mathcal B_5}\prod_v c_{b,v}^m.
```

配对必须全部答对；All5Acc 只用于冻结时具备五卷的底稿，公开覆盖率。百分比差以百分点展示，计算用未取整计数。种子标准差和测试抽样区间分报。

### 4.2 适用性分类与三种覆盖率

令 $\mathcal U$ 为固定待判断组集合，$N_{\mathrm{grp}}=|\mathcal U|$，$c_g=\mathbb I[\hat r_g=r_g^{\mathrm{gold}}]$。BAcc 为全部组的 $c_g$ 均值，弃权不删组；另报 NONE 精确率、召回率、F1 与病例全组正确率。分类失败单列，不能改成语义 NONE。

```math
\mathrm{NLL}=-\frac1{N_{\mathrm{grp}}}\sum_g\log p_g(r_g^{\mathrm{gold}}),\qquad
\mathrm{Brier}=\frac1{N_{\mathrm{grp}}}\sum_g\sum_r\left(p_g(r)-\mathbb I[r=r_g^{\mathrm{gold}}]\right)^2.
```

Brier 不再除以类别数，范围为 $[0,2]$；按组大小分层。ECE 使用预注册的 15 个等宽置信区间，按箱人数加权准确率与平均置信度的绝对差，空箱贡献为零，边界固定。无合法概率的失败单列，明确实际可评分分母并补报共同可评分集合。

**统一记号：$a_g=1$ 始终表示弃权；$e_g$ 只表示输入与可达性有效。** 令 $s_g^m=1$ 表示执行器实际应用了合法启用信号，$\xi_g^m=1$ 表示日志确认发生有效非零键编辑。它们均不是仅有计划增益。

```math
\mathrm{Cov}_{\mathrm{dec}}=\frac{\sum_g(1-a_g)}{N_{\mathrm{grp}}},\qquad
\mathrm{Risk}_{\mathrm{sel}}=\frac{\sum_g(1-a_g)(1-c_g)}{\sum_g(1-a_g)},
```

```math
\mathrm{Cov}_{\mathrm{sig}}^m=\frac{\sum_gs_g^m}{N_{\mathrm{grp}}},\qquad
\mathrm{Cov}_{\mathrm{edit}}^m=\frac{\sum_g\xi_g^m}{N_{\mathrm{grp}}}.
```

信号和键编辑错误率分别为 $\sum_gs_g^m(1-c_g)/\sum_gs_g^m$ 与 $\sum_g\xi_g^m(1-c_g)/\sum_g\xi_g^m$。零分母时未定义；非键编辑方法的键指标不适用。高置信 NONE 可接受但不应用处置信号。另报病例级至少一次实际编辑覆盖率。固定间隔阈值后扫描概率阈值，测试曲线不重新选部署点。

对必要关键组集合 $\mathcal U_i^{\mathrm{gold}}$，固定所有执行器共享的子集：

```math
\mathcal I_{\mathrm{ok}}=\{i:|\mathcal U_i^{\mathrm{gold}}|>0,\ \forall g\in\mathcal U_i^{\mathrm{gold}},\ a_g=0\ \land\ \hat r_g=r_g^{\mathrm{gold}}\ne\mathrm{NONE}\},\qquad
\mathrm{ExecErr}^m=\frac1{|\mathcal I_{\mathrm{ok}}|}\sum_{i\in\mathcal I_{\mathrm{ok}}}(1-c_i^m).
```

这是必要组均接受且判断正确时仍执行错的比例，失败计错。子集由同一分类缓存确定，不随执行器改变；报告实例数、底稿数和覆盖率。其他病例仍进入全体端到端评价。

### 4.3 完整路径

冻结步骤评分器输出 $C_{ij}\in[0,1]$，令 $D_{ij}=1-C_{ij}$。在标准动态时间规整约束下先优化累计代价，再归一化：

```math
\mathcal P^{\star}=\arg\min_{\mathcal P}\sum_{(i,j)\in\mathcal P}D_{ij},\qquad
\mathrm{PCC}_b=\frac{\sum_{(i,j)\in\mathcal P^{\star}}D_{ij}}{|\mathcal P^{\star}|}.
```

PCC 范围 $[0,1]$，越低越好。并列路径、分步程序、评分提示、评审模型和重复数须冻结。空输出或完全不可解析记 PCC=1，这是本研究的保守失败政策。评分实现不同于官方时标为适配协议，不直接与公开分数排位。

固定参考关键节点集合 $\mathcal V_b$；$u_{bj}=1$ 当且仅当节点分支正确。遗漏、未到达和不可解析记零。只对非空节点集病例 $\mathcal B$ 定义：

```math
\mathrm{BFR}_{\mathrm{micro}}=\frac{\sum_b\sum_{j\in\mathcal V_b}u_{bj}}{\sum_b|\mathcal V_b|},\quad
\mathrm{BFR}_{\mathrm{macro}}=\frac1{|\mathcal B|}\sum_b\frac{\sum_{j\in\mathcal V_b}u_{bj}}{|\mathcal V_b|},\quad
\mathrm{PathAll}=\frac1{|\mathcal B|}\sum_b\prod_{j\in\mathcal V_b}u_{bj}.
```

PathAll 仅表示关键分支全对，不等于全部自由文本正确。无关键节点病例仍评终点。节点 DA 使用预先固定诱饵节点分母，遗漏不算采纳但计 BFR 错误；无诱饵节点时 DA 不适用。Deg 为重复循环或输出触顶病例的并集比例，解析失败另报。评审缓存键包含病例、参考路径、输出、提示和评审器版本，不能只按输出文本复用。

### 4.4 机制与子空间诊断

盲判减明判分支准确率为 $\Delta_{\mathrm{TLBS}}$，正值表示可见性退化；熟悉与中性条件的差为熟悉度交互诊断。敲除／修补报告原始效果，恢复比例在差距过小时未定义，不裁成 100%。

模块一报告三状态标签通过率、对齐率、联合通过率及排除计数；验证与测试响应分表。分半重叠使用 $\|U_A^{\top}U_B\|_F^2/m$，秩不足和失败单列，同秩随机子空间作参考。未见规则平均差分按规则等权计算方向余弦与正向比例，近零均值不硬归类。双状态响应报告均值和正号比例，逐查询头及后续生成位置另报。

谱增量比较固定判断、头集、位移范数和增益下的原始均值差与谱投影均值；重新选头版本匹配开发预算。符号置换保持外积不变，只检验有向均值或定向编辑，不能作为谱特征值零分布。空专家不从统计中消失。

## 5. 统计推断与成本

### 5.1 主要比较与多重控制

主要对照为验证集选定、测试前冻结的最强共享判断执行器。MedGUIDE 比较 ASTER 与该对照的 $\Delta\mathrm{CA}$，原生保持比较 ASTER 与同骨干原模型的 $\Delta\mathrm{NCA}$。路径比较配对 SW 子集的 $\Delta\mathrm{BFR}_{\mathrm{macro}}$。H、PCC 及其他分卷是次要指标。

以同源指南簇进行 10,000 次配对自助重采样，每次保留全部病例、变体与方法，并重算非线性指标。95% 描述区间用 2.5%／97.5% 分位数；少簇情形同时报告逐指南效应和留一指南敏感性。记效应为 $\widehat\theta$、重采样效应为 $\widehat\theta^{*(b)}$，对 $H_0:\theta\le\theta_0$ 沿用注册的中心化近似检验：

```math
p_+(\theta_0)=\frac{1+\sum_{b=1}^{B}\mathbb I[\widehat\theta^{*(b)}-\widehat\theta\ge\widehat\theta-\theta_0]}{B+1},\qquad B=10000.
```

CA 与 SW BFR 的边界为 0，NCA 非劣效边界为 $-0.02$。每骨干的 MedGUIDE 结论使用交并检验 $p_{\mathrm{MG}}=\max(p_{\mathrm{CA}},p_{\mathrm{NI}})$。两个骨干各自的 MG 和 SW-BFR 共四项作 Holm 校正，家族错误率 0.05。保存原始／校正 p 值、重采样种子与索引，不临时重建比较族。

该检验条件于已拟合产物，是近似检验而非少簇精确保证。单侧下界为 $\widehat\theta-q_{0.95}(\widehat\theta^*-\widehat\theta)$，正式结论还须通过四项校正。非劣效界值 0.02 是研究标准，另报 0.01、0.03 敏感性；测试后不得调整。未通过非劣效不等于已证明退化，差异不显著不等于等效。

### 5.2 在线与离线成本

在线分别记录模块二分类、预处理、病例缓存／编辑和最终生成，重排等额外步骤全部计入。分解项不重复计时，并行时以真实墙钟为准。每种方法报告均值及第 95 百分位延迟、峰值显存、前向次数、输入／输出词元。共享判断缓存仅用于控制比较，不意味着部署时没有分类成本。

离线记录方向估计、选头、温度拟合、调参及 SFT／DPO／CPT 的 GPU 小时。部署病例数另记 $N_{\mathrm{deploy}}$，总成本为 $C_{\mathrm{offline}}+N_{\mathrm{deploy}}C_{\mathrm{online}}$，不与问题符号 $Q$ 混用。同后端与优化后端分报，硬件、批量、精度和输出预算一致或明确说明差异。
