## 1. 当前研究范围

当前论文研究ASTER-CR：在保留完整指南和患者输入的条件下，通过四个模块定位、估计并修正干扰对当前条件判断的影响，同时约束对决定性证据响应的改变。

| 模块 | 论文中的职责 | 主要产物 |
|---|---|---|
| M1：注意力头定位 | 定位传导干扰与证据信息的注意力头 | 选中头集合及其修补效应 |
| M2：子空间估计 | 从配对激活差中估计干扰与证据方向 | 标准化参数、证据子空间、干扰子空间及正交基 |
| M3：受约束分数修正 | 利用A/P配对学习输入相关修正，并由C/F配对约束证据改动 | 无全局截距的修正函数、训练中心化统计量及预算记录 |
| M4：任务感知校准与决策 | 固定 M1–M3 后估计概率和任务决策 | MEGA 逻辑再校准、MedPIC 合法集合概率 |

论文的核心证据分为四类：新训练数据是否改善三个模块；干扰抑制是否伴随证据保护；方法是否优于同主干的强基线；方法能否跨模型家族及跨医学任务迁移。

## 2. 状态定义

| 状态 | 含义 |
|---|---|
| 已完成 | 有代码、配置、逐例预测或可复核报告支持 |
| 部分完成/可复用 | 有历史实现或局部实测，但不满足当前论文协议的全部要求 |
| 待执行 | 方案已确定，尚无当前协议下的实测结果 |
| 待核验 | 有实现或候选结果，但尚未证明方法有效加载或满足比较协议 |
| 补充候选 | 有研究价值，但不是当前主线的阻塞任务 |

**规则：** 有代码不等于有实测；历史实测不等于满足新协议；未运行不等于结果为零。不得用文献成绩、模拟分数或其他模型的结果填补缺失单元。

### 五折来源验证

80 个拟合来源分成五折，每折 64 个来源训练、16 个来源验证。每折独立执行：
1. M1：梯度归因、激活修补和注意力头选择。
2. M2：标准化、证据子空间、干扰子空间及正交基估计。
3. M3：A/P 差分拟合、C/F 逐对约束和截距校准。

不得先用全部 80 个来源选择头或估计子空间，再进行五折验证。主评价合并五个未参与对应训练的验证来源集合，覆盖 80 个来源；每次重采样重新计算合并指标，不平均折级 VR 或置信区间。独立截距 b₀ 仅用同一 761 个自然拟合节点，每折限于 64 个训练来源。
