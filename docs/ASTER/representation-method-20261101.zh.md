## 方法

模型读完整指南来回答，同时用同一个冻结模型只读患者和当前条件，得到一份不受候选处置影响的内部表示。我们学习一个小模块，在模型选择当前分支时，把注意力输出的一小部分向这份处置盲表示调整。其余表示和完整指南保留。三模块职责为：学习干预参数、提供处置盲表示、在当前决策处实施干预。

令完整输入在第ℓ层、当前决策位置的注意力输出为o，处置盲输入在同层回答边界的输出为z。编辑位置在注意力输出投影之后、残差相加之前：

```math
\widetilde o=o+\gamma U(Bz-U^\top o),\qquad
U^\top U=I,\quad
\gamma=\sigma(w^\top[U^\top o;Bz]+b).
```

U通过QR分解保持列正交，秩固定4；B为线性映射。强度初始为0.01。只训练U的底层参数、B、w和b，共32,777个参数；Qwen3-8B骨干冻结，骨干用BF16，小模块用FP32。候选单层为18、24、30，层号从0开始，不叠加多个层。

处置盲输入直接使用原始患者记录、当前完整条件和理解指代所需的祖先条件，不拆原子条件、不抽取额外特征。输入不含本组候选处置、原问题、选项或金标路径。病历中已经记录的治疗史保留；祖先条件只说明到达该节点的语境，不当作患者事实。T/F/U标签和概率保留用于诊断，完整方法使用连续表示，不用标签强制确定路径。

只有产生当前Y/N分支选择的查询位置接受编辑。保留一份未编辑的上下文KV；编辑时复制并截断到当前查询之前，临时前向得到分支分数，随后丢弃这次前向的KV。选定分支由未编辑模型重新编码，进入下一次决策。因此，后续路径会受到实际选择影响，但不会额外继承编辑造成的患者或路径缓存变化。

所有主要方法使用相同完整指南树约束：强制路径语法与转移编号，Y/N选择仍由模型打分；达到终点即停止，并根据当前指南填写终点编号及处置描述。处置描述存入结果的action字段。该组件的收益不算内部干预收益。

## 训练

同一病例使用原指南及终点处置描述循环交换两个视图。规则编号、条件、转移关系和终点编号保持不变，不生成新患者标签。

```math
\mathcal L=\tfrac12(\mathrm{CE}_{orig}+\mathrm{CE}_{swap})
+\mathrm{JS}(p_{orig},p_{swap})
+0.1\mathcal L_{keep}+0.001\mathcal L_{edit}.
```

保持损失只施加于训练标签确认原模型正确的视图，使用原分布到编辑分布的KL散度；没有符合条件的视图时为0。编辑幅度为注意力输出改变量的平方范数除以原输出平方范数。每例各节点损失平均，两个视图共同组成一个训练单元。已有年龄最小对的两态标签纳入同一个交叉熵目标，提供条件翻转监督，不另加未经约定的损失。

AdamW，学习率0.001，权重衰减0.01，3轮，单例批次，累计8例更新，梯度裁剪1。开发集每轮评估，按原指南完整路径与终点联合正确数选检查点；并列时依次选交换前后路径更稳定、编辑幅度更小的配置。仍并列时固定选较早轮次、较低层号。

## 对照与执行次序

先独立训练完整方法的18、24、30层。开发集选定层后，在该层训练普通低秩干预和去掉JS损失的干预，各3轮。普通低秩干预把Bz换成Bo，参数量、训练数据及损失一致，完全不读取处置盲表示。

主要比较零干预、原静态均值键编辑、标签概率融合、普通低秩干预、无JS方法和完整方法。标签融合固定使用

```math
w=0.5(1-p_U),\qquad
p_{fused}=(1-w)p_{base}+w\frac{(p_T,p_F)}{p_T+p_F}.
```

不再额外搜索融合系数。它使用与完整方法相同盲判输入，检验收益是否只来自多做一次条件判断。原静态键编辑使用旧已选头、位置、增益及直接三值门控，原结果仅在执行条件一致时复用。

完整方法和两项学习对照的检查点全部冻结后，才运行新确认集。GPU0、1动态分配：哪个空出就启动已具备条件的任务，不等待另一张卡；选层和最终冻结所需的依赖仍保留。成功完成的任务及逐例结果直接跳过；失败记录保留，不自动增加层、秩或其他形式。

规模：5个训练配置×3轮×586个节点＝8,790个双视图节点训练单元；开发3,600个病例视图条件，其中200个复用；最终确认1,200个病例视图条件；条件翻转诊断320个病例视图条件。以上条件数包含相同病例的重复测量，不是独立样本量。

## 指标、解释与必要检查

原指南与处置交换均覆盖全部病例，报告完整路径与终点联合正确、单独路径与终点、无效输出、交换前后路径一致率。完整方法相对各对照报告配对纠正／退化、来源等权差异及来源重采样区间。年龄最小对报告两态同时正确，训练对和已暴露诊断对分开。

只有完整方法优于相同输出设置下的零干预，并较标签融合及普通低秩干预有额外收益，才支持处置盲内部表示的贡献。处置交换稳定还必须保留条件变化后的正确响应；始终选择同一分支不算成功。若未满足，明确报告当前设计未获支持，不把结构化输出的收益归于算法，也不声称已证明处置偏好造成错误的因果机制。

必要检查覆盖零强度前向等价、梯度只进入新增参数、共享KV不被改写、交换处置不改变盲判输入及部署输入去除金标。训练使用独立可求导路径，不改旧推理代码。两例试跑用于测量耗时和显存，试跑权重丢弃；稳定后停止持续监控。

低秩表示干预已有[ReFT](https://arxiv.org/abs/2404.03592)等先例。本轮要检验的是处置盲信息与完整指南信息在内部如何结合，以及处置交换和条件翻转监督是否改善这种结合。缓存复用是实现属性，不预先宣称速度优势。
