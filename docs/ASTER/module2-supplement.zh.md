## A. 差分二阶矩与谱估计

对训练最小对 $i$ 中的规则词元 $j$，令 $w_{i,j}=1/(N|J_i|)$，则 $\sum_{i,j}w_{i,j}=1$。正文使用最小对等权估计：

```math
\bar d_h=\sum_{i,j}w_{i,j}d_{h,i,j},\qquad
\Omega_h=\sum_{i,j}w_{i,j}d_{h,i,j}d_{h,i,j}^{\top}.
```
这里的 $\Omega_h$ 是未中心化二阶矩。定义同权重的经验协方差：

```math
C_h=\sum_{i,j}w_{i,j}(d_{h,i,j}-\bar d_h)
(d_{h,i,j}-\bar d_h)^{\top},
```
则 $\Omega_h=C_h+\bar d_h\bar d_h^{\top}$。不进行中心化使平均差分与围绕均值的变化共同参与子空间估计。

对任意向量 $a$，有 $a^{\top}\Omega_h a=\sum_{i,j}w_{i,j}(a^{\top}d_{h,i,j})^2\ge0$，因此 $\Omega_h$ 为对称半正定矩阵。将特征值按降序排列，前 $m$ 个特征向量构成的正交基 $U_h$ 求解：

```math
\max_{U^{\top}U=I_m}
\mathrm{tr}(U^{\top}\Omega_h U)
=
\max_{U^{\top}U=I_m}
\sum_{i,j}w_{i,j}\|U^{\top}d_{h,i,j}\|_2^2.
```
最优值为前 $m$ 个特征值之和。等价地，该子空间最小化差分的加权投影重构误差。若矩阵 $D_h$ 的每一行为 $\sqrt{w_{i,j}}d_{h,i,j}^{\top}$，则 $\Omega_h=D_h^{\top}D_h$，可通过 $D_h$ 的前 $m$ 个右奇异向量实现同一估计。

最小对等权避免长规则片段获得更大的样本权重，但不自动使规则或指南等权。复现记录同时保存每条规则的最小对数量、片段长度和指南来源；规则均衡抽样作为独立敏感性分析。

## B. 共享位移的最小二乘解释

给定子空间 $\mathcal U_h=\mathrm{span}(U_h)$，拟合一个共享位移：

```math
\min_{v\in\mathcal U_h}
\sum_{i,j}w_{i,j}\|d_{h,i,j}-v\|_2^2.
```
展开目标可得：

```math
\sum_{i,j}w_{i,j}\|d_{h,i,j}-v\|_2^2
=
\sum_{i,j}w_{i,j}\|d_{h,i,j}-\bar d_h\|_2^2
+\|v-\bar d_h\|_2^2.
```
因此，最优位移为 $v_h=U_hU_h^{\top}\bar d_h$。归一化后得到正文使用的 $\Delta_h=v_h/(\|v_h\|_2+\epsilon)$。特征子空间确定保留的差分成分，平均差分确定适用性极性。归一化将幅度控制交给模块三的固定正负增益。

对满足 $\|v_h\|_2>\tau_\Delta$ 的头计算方向，其中 $\tau_\Delta>0$ 在开发阶段固定。低于阈值的头不进入选头；分母中的 $\epsilon$ 仅用于数值稳定。由于加入 $\epsilon$，$\|\Delta_h\|_2\le1$，不是严格恒等于 1。

## C. 对比构造与计算约定

### C.1 对比三元组

正负最小对连同信息缺失对照组成一个三元组。目标规则的完整条件包含祖先条件；正负状态共享分支组可达性。信息缺失状态保留已知祖先事实，并删除区分目标与兄弟分支所需的事实。条件解析器同时核验正、负、未知三个状态，未知不能由字符串“未记录”直接代替语义核验。

同一三元组保持问题、规则文本、处置及其余患者事实一致。处置平衡在不同三元组之间进行，保留规则条件与处置的结构映射。改变下游依赖且无法一致更新的置换不纳入训练。对患者事实替换同时检查关联字段的一致性。

在实际聊天模板下核验规则词元的标识、绝对位置及片段边界。等字符数不代替词元对齐。对齐失败、条件冲突和上下文截断分别记录并按统一规则处理。同一底稿的全部变体进入同一树级数据划分。

### C.2 键与查询坐标

模型使用确定性评估模式。键采集位于键归一化之后、旋转位置编码之前；模型无键归一化时使用恒等映射。在线向已旋转的键缓存加入 $g_rR_j\Delta_h$，不再对编辑结果施加额外键归一化。

分组查询注意力中，$\mathcal A(h)$ 表示共享键值头 $h$ 的查询头集合，平均查询为 $\bar q_{h,t}=|\mathcal A(h)|^{-1}\sum_{a\in\mathcal A(h)}q_{a,t}$。每个 $q_{a,t}$ 均包含查询侧位置编码。均值对应平均直接得分响应；逐查询头的异质性另行报告。

离线差分使用患者前置顺序；读取响应使用未编辑模型的实际在线顺序。两种运行分别保存规则位置集合 $J_i$ 与 $\widetilde J_i$。旋转前采集统一本层的编辑坐标，不消除上游隐藏状态中的顺序与位置影响。

### C.3 数值处理与专家保存

采用预先固定的浮点累积精度和特征值容差；分解前进行数值对称化。数值秩不足 $m$、非有限统计量、近零投影均值的头予以排除。验证集标准差采用最小对级经验总体标准差，即除以 $N_{\mathrm{val}}$；信息缺失惩罚在每对片段平均后取绝对值。需要至少两个验证最小对。

有效头同时满足正的表示分离度和两种状态各自正的平均查询响应。按联合分数降序选取至多 $K$ 个头，并列时按层号、键值头编号排序。有效头不足时不补入零分头；没有有效头时保存空专家并跳过键编辑。

专家产物包含 $H^*$、每头 $U_h$ 与 $\Delta_h$、投影均值范数、谱值、验证评分，以及模型、分词器、模板、数据划分和超参数指纹。在线最小运行集合为 $H^*$ 与 $\{\Delta_h\}_{h\in H^*}$；其余内容用于复现和诊断。

## D. 固定查询下的局部改变量

对查询头 $a\in\mathcal A(h)$，固定当前查询和注意力计算，其直接得分变化为：

```math
\delta s_{a,t,j}
=\frac{g_rq_{a,t}^{\top}R_j\Delta_h}{\sqrt{d_k}}.
```
若 $a_j=\mathrm{softmax}(s)_j$、$a_j'=\mathrm{softmax}(s+\delta s)_j$，则

```math
\mathrm{KL}(a\Vert a')
=\log\!\left(\sum_j a_j e^{\delta s_j}\right)
-\sum_j a_j\delta s_j
\le \max_j\delta s_j-\min_j\delta s_j
\le 2\max_j|\delta s_j|.
```
令 $\mathcal J_{\mathrm{edit}}$ 表示当前查询头实际编辑的规则词元集合。在同一个固定查询头内，未编辑位置令 $\delta s_j=0$，得到

```math
\mathrm{KL}(a\Vert a')
\le
2\max(g^+,g^-)
\max_{j\in\mathcal J_{\mathrm{edit}}}
\frac{|q_{a,t}^{\top}R_j\Delta_h|}{\sqrt{d_k}}.
```
没有编辑位置时右端定义为零。该推导用于描述一次注意力计算的直接变化；完整前向传播的查询和后续表示由实际运行计算。

## E. 三项主要实验备注

### E.1 对比有效性：条件变化还是文本线索

对应正文 4.3.1 后的备注。报告三状态标签核验和位置对齐通过率；比较处置平衡前后、事实等义改写以及非决定性事实扰动。检查得到的方向是否主要随规则适用状态变化，而非随某个词、长度或处置名称变化。

**已完成的构造检查。** 本轮 12 个开发指南包含 96 个目标三元组，每指南同时覆盖两个目标、两种处置映射和两种规则顺序。独立条件核验通过；96/96 三元组的三状态目标词元标识、绝对位置和总长度一致，无截断。患者仅使用源树谓词的显式布尔判断，没有把它们当作已核验临床一致性的自然病例。处置置换用于降低映射依赖，尚未完成“取消平衡”消融、事实等义改写或非决定性事实扰动；这些内容继续保留为待验证项目。[数据审计](../../experiments/module2_mechanism_20261028/results/data_audit.json)和[词元对齐记录](../../experiments/module2_mechanism_20261028/results/offline_audit.json)提供逐例依据。

### E.2 共享方向与谱估计的增量价值

对应正文 4.3.2 后的备注。正文保留未见规则上的有向差分一致性，以及原始均值差、谱投影均值、随机同范数方向的主要比较。分半子空间重叠、逐规则余弦、秩扫描、样本学习曲线和不同种子放在补充结果中。

子空间稳定性用投影矩阵或主夹角比较，不直接比较具有符号不唯一性的特征向量。固定训练方向，在独立规则上计算平均差分与其余弦及正向比例。近零规则均值单列，不将其记为确定的正负方向。

**配对标签交换的检验对象。** 在最小对内交换正负状态，相当于 $d_{h,i,j}\mapsto-d_{h,i,j}$，但外积不变：

```math
(-d_{h,i,j})(-d_{h,i,j})^{\top}
=d_{h,i,j}d_{h,i,j}^{\top}.
```
因此，配对符号置换用于有向均值、方向一致性或定向干预指标的对照，不用于构造差分二阶矩特征值的零分布。同一最小对内的全部词元使用同一符号；同源变体保持聚类关系，随机化单元及交换性假设预先固定。谱结构本身通过独立分半重现和非决定性事实对照检验。

**本轮有向变化结果。** 在拟合／选择／确认指南为 6／3／3 的划分上，冻结头 `(13,4)`、`(23,6)`、`(6,2)`、`(22,7)` 的确认有向差分正向数分别为 21、22、19、16，分母均为 24 个目标三元组。对同一指南配置的相反目标规则计算

```math
d_{h,A}=k_{h,A}(P_A)-k_{h,A}(P_B),\qquad
d_{h,B}=k_{h,B}(P_B)-k_{h,B}(P_A),
```

并分别分析 $(d_{h,A}+d_{h,B})/2$ 与 $(d_{h,A}-d_{h,B})/2$ 沿冻结方向的投影。第一项的正向数依上述头顺序为 12/12、12/12、12/12、11/12。相同患者事实扰动若在两处规则表示上产生相同变化，会在第一项中抵消；规则内容和位置响应不同仍可能留下混杂。此处的 $k$ 是对应编号与处置片段的均值，仅用于相对效应分析，拟合式（6）仍使用逐 token 外积。[全部相对效应](../../experiments/module2_mechanism_20261028/results_analysis/rule_relative_effects.csv)包含所有对照与配置。

原始均值方向在四个冻结头上的确认平均余弦均高于谱投影方向，因此当前证据支持共享的有向变化，尚未建立谱估计的增量优势。[64 个指南组符号配置](../../experiments/module2_mechanism_20261028/results_analysis/group_sign_controls.csv)固定原子空间、保留每个指南内部全部变体并重新计算有向均值，不重选头，也不报告谱显著性。分半子空间重现、秩扫描、学习曲线与跨种子谱稳定性尚未运行。

### E.3 在线迁移与双向读取

对应正文 4.3.3 后的备注。按实际指南前缀缓存协议检验正向增强与负向抑制，分别报告正负状态的平均响应、符号比例和最终决策效果。比较只用表示分离度、平均响应选头、双状态响应筛选及随机等量头；同时比较去除信息缺失惩罚的版本。

正文保留跨顺序迁移和相同模块一输出下的执行增量；逐位置、逐查询头及后续生成位置的响应分布放入补充结果。仅平均查询为正不替代逐样本符号检验。

**本轮在线迁移结果。** 144 次离线前向与 48 次在线前向来自同一固定 `Qwen3-0.6B-Base`。在线指南前缀在患者正负状态间完全一致，保存的目标键变化最大值为 0；实际在线查询则按各患者重新计算。四个冻结头在确认集上，适用状态与不适用状态各有 24/24 个目标平均响应为正；这里的平均包含真实目标位置及全部共享 GQA 查询头。该结果说明离线方向能够被本轮在线查询正向读取，不能替代每词元符号、真实注意力质量或最终决策的测量。[在线审计](../../experiments/module2_mechanism_20261028/results/online_audit.json)、[头级统计](../../experiments/module2_mechanism_20261028/results_analysis/head_direction_metrics.csv)及[完整干预报告](../../experiments/module2_mechanism_20261028/RESULTS.zh.md)分别保留这些证据。

本轮干预使用 oracle 规则符号，未评估模块一预测。平均响应选头、随机等量头及去除缺失惩罚的选头消融仍未运行；最终报告的方向对照不能替代这些选头对照。
