## 方法不可替换

方向必须来自规则编号与处置片段的**键向量差分**。采集坐标为键归一化之后、旋转位置编码之前。按最小对等权计算逐词元差分外积；用前 m 个特征方向投影有向均值，再归一化。在线查询仅用于验证可读性与选头，不替代键差分作为学习对象。

离线使用患者前置输入。选头使用独立来源的指南前置输入，要求表示分离度、正状态读取和负状态读取均为正。允许空专家，不用无效头补齐。

在线复用现有同骨干处置盲组级分类、温度缩放和弃权接口。显式核验祖先可达性。对正确预测的选中规则分配正增益，对同组兄弟规则分配负增益；失败、弃权、NONE 或不可达组不编辑。测试金标不进入可部署路由。

实际编辑是病例独立缓存中的加性位移 `k' = k + g_r Delta`；已旋转缓存写入 `g_r R_j Delta`。不使用当前键的投影 `u u^T k`，不额外归一化，不修改值向量。指南预填充后、完整患者/问题后缀之前执行编辑。
