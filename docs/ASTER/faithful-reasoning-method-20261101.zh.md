# 方法说明：面向指南忠实推理的处置盲表示干预

2026-11-02修订。用户已确定去掉JS不变性损失的版本为主方法；实验键仍为`no_js`，原`full`继续表示含JS版本并保留为消融。内部干预公式、层、秩和已训练检查点均不改变，不新增训练配置。

本次改选依据已有开发集和内部确认结果；后者已参与方法选择，不再作为新主方法的独立确认。官方测试已经启动后才作出这次改选，本次仅核对运行进度和耗时、未查看官方效能汇总，不将该改选写成测试启动前完成。原冻结记录与历史结果保留，详见[主方法修订记录](main-method-amendment-20261102.zh.md)。

## 1. 动机：分支选择应依据患者事实和指南条件

指南推理需要先根据患者事实判断条件，再选择分支，最后读取对应处置。我们研究的忠实性是：模型的分支选择是否忠实于当前输入的患者事实和规则，而不是仅生成合理的处置或合法的路径格式。

本轮将这一要求具体化为三个行为标准：

1. 条件判断正确，生成路径与患者事实及指南条件一致。
2. 固定患者、条件和转移关系，只交换终点处置描述，分支选择保持稳定。
3. 改变决定性患者事实后，模型按改变后的条件选择相应分支。

本轮按显式条件及既定路径标签定义扰动任务，处置重排改变最终填写的文本，条件分支标签沿用原值。如果条件的含义本来依赖被改动的处置语境，标签不变就需要额外核实，不能由条件字符串未变直接推出。上述标准评价决策行为，不等同于已经证明模型所有内部计算或生成解释均忠实。

## 2. 洞见：两种输入产生互补的判断错误

完整指南输入保留了患者、规则语境和候选处置；处置盲输入只保留患者、当前条件及理解指代所需的祖先条件。二者使用同一冻结模型，但可能产生不同错误。

开发100例的历史含JS版本结果表明，11例是处置盲查表错误而完整指南模型正确，9例相反。该版本分别保持了前11例，并解决了后9例中的7例。进一步逐例分析发现，14例相对查表的纠正中，11例是保留完整模型本来就有的正确判断，2例体现不同节点上的互补，1例不能由两侧离散标签择优解释。详见[17例分析](representation-case-analysis-17-20261101.zh.md)。

这些结果支持“判断错误具有互补性”，尚不证明两侧一定拥有不同事实。很多决定性事实同时存在于两侧输入，差异也可能来自语境、提示格式、计算过程或标签读出。

新草稿提出“处置集合可能帮助解释条件、处置分配可能干扰判断”，可作为研究假设。当前没有证明完整模型的收益来自集合；将集合规范排序并去掉分支对应关系也是可行的输入构造，因此不能论证所有上下文方法原则上无法解决。完整核对见[CBS草稿核对](cbs-draft-review-20261102.zh.md)。

直接依据盲判删除其余分支，会把一次不确定或错误的判断固定为后续前提。完整方法保留所有规则，并在当前分支尚未确定时学习结合两侧表示。研究假设是：这种结合能够保留完整模型的正确判断，同时利用处置盲表示修正部分错误；不能预先假定学习到的强度已经能准确识别哪一侧可靠。

## 3. 固定算法

三模块保留原编号，但职责固定为：模块一学习干预参数；模块二提供当前节点的处置盲表示；模块三在完整指南模型的当前分支决策处实施干预。

### 3.1 模块二：形成处置盲参考表示

对于实际到达的节点g，同一冻结骨干接收：患者原始记录、当前完整条件，以及理解该条件所需的祖先条件。候选处置、原问题、选项和金标路径不进入该输入。既有治疗史属于患者事实，保留；祖先条件只作语境，不被当作患者已经满足的事实。

在该输入的回答边界，取第ℓ层注意力输出投影之后、残差相加之前的向量，记作z_g。它是没有读取候选处置文本的参考表示，不保证本身正确。T/F/U标签与概率只用于诊断及对照，不强制决定完整方法的路径。

不增加结构化事实抽取、原子条件拆解或额外临床特征模型。表示按病例和当前节点缓存复用。

### 3.2 模块一：学习子空间、映射与强度

完整指南模型在当前分支查询位置t的同层注意力输出记作o_t。学习三个部分：正交子空间U、处置盲映射B以及强度函数。

```math
U\in\mathbb R^{d\times k},\quad U^\top U=I,\qquad
B\in\mathbb R^{k\times d},\qquad
\gamma_t=\sigma\!\left(w^\top[U^\top o_t;Bz_g]+b\right).
```

U通过对可训练矩阵做QR分解保持正交。B把处置盲表示映射到该子空间。γ根据两侧低维表示学习，不直接使用标签最大概率，不把γ解释成已校准的可信度。

### 3.3 模块三：只调整当前分支决策的表示

在注意力输出投影之后、残差相加之前实施：

```math
\widetilde o_t=o_t+\gamma_tU\left(Bz_g-U^\top o_t\right).
```

由于U列正交，也可以写成：

```math
\widetilde o_t=(I-UU^\top)o_t
+U\left[(1-\gamma_t)U^\top o_t+\gamma_tBz_g\right].
```

因此，在该干预位置，子空间之外的分量保持不变，子空间之内结合两侧表示，后续冻结网络继续完成分支判断。这是算法的操作含义。U是否真正对应有用的条件判断分量，需要行为对照来验证；正交与低秩本身不提供这一保证。

固定盲输入与参数时，处置交换不改变z与Bz；但o、γ以及实际编辑量仍可能变化。因此只能保证参考目标不读取候选处置，不能保证整个干预量或最终输出不受处置影响。正交补保持不变也不证明处置集合信息恰好位于其中。

干预只作用于产生当前Y/N选择的查询位置。患者读取、指南预填充和非决策词元不施加编辑。γ处于0到1之间，但B可学习，因此这不保证实际改变量很小；幅度由损失惩罚并据实报告。

### 3.4 保持后续上下文缓存干净

每次决策保留一份未编辑的上下文KV。临时复制缓存，在当前查询上编辑并读取分支分数；随后丢弃临时前向产生的KV。选定分支词元由未编辑模型重新编码，再进入下一次决策。

干预会通过实际选择影响后续路径，但不把编辑产生的额外缓存变化传下去。它并不消除错误分支选择本身的传播。

## 4. 训练如何对应忠实性要求

骨干冻结，只训练U的底层矩阵、B、w和b。每个普通病例取根、中间、末端三个不同节点，不足三个时全部使用；训练使用金标前缀，推理只使用已经生成的前缀。

同一病例提供原指南与全树终点处置描述循环移位后的两个视图，固定患者、条件、规则编号、转移关系和终点编号。这保留全树处置集合，但不保留各节点的局部集合：40棵训练／开发／内部确认指南中，829个非根节点有819个发生局部文本多重集变化。现有实验不是固定局部集合的分配交换检验。损失为：

```math
\mathcal L=
\tfrac12(\mathrm{CE}_{orig}+\mathrm{CE}_{swap})
+0.1\mathcal L_{keep}
+0.001\mathcal L_{edit}.
```

| 目标 | 实现 | 对应问题 |
|---|---|---|
| 分支正确 | 原指南和交换指南的分支交叉熵 | 避免仅追求分布稳定而选择错误分支 |
| 处置交换后的正确性 | 原指南与交换指南都使用相同正确分支监督 | 要求两边均判断正确，不强制两边概率分布相同 |
| 条件敏感性 | 已核验年龄最小对的两态标签进入同一交叉熵 | 决定性事实变化后应切换分支；没有另设未实现的翻转损失 |
| 保留已有正确判断 | 仅对训练标签确认原模型正确的节点视图，约束原分布到编辑分布的KL | 减少把本来正确的判断改错 |
| 限制改动 | 输出改变量平方范数除以原输出平方范数 | 抑制不必要的大幅修改，不是硬保证 |

保持项在原模型正确的视图上取KL平均，无符合条件的视图时为零；幅度项对两视图平均，每例再对节点平均。同标签两视图不保证分配与标签统计独立。决策正确不要求置信分布相同，是移除JS的目标层面理由；不能以四维子空间证明输出分布无法对齐，也不把观察到的性能差异写成已证明的优化机制。

主方法仍保留全部处置交换训练样本，只去掉额外的JS散度项。含JS版本作为消融，检验强制概率分布相同是否有帮助。年龄最小对仅支持当前覆盖范围内的条件翻转，不提前称为通用临床机制；评价同时检查两种指南均正确和条件改变后两态均正确，恒定选择错误分支不能被计为忠实推理。

## 6. 论文主张与判定依据

论文的方法主张固定为：**通过在当前分支决策处学习结合处置盲表示与完整指南表示，改善模型依据患者事实和给定规则进行分支推理的能力，并减少无关终点处置变化对判断的影响。**

低秩表示干预已有[ReFT](https://arxiv.org/abs/2404.03592)等先例。本方法需要验证的贡献是处置盲参考、当前决策处的条件化结合与反事实监督在本任务中的共同作用，不将低秩形式本身称为创新。

现有对照分别回答：直接盲判后查表能否达到同样效果；标签概率融合是否已经足够；同等数据和参数量的上下文方法是否同样有效；训练一个盲表示分类器能否解释收益；没有盲表示的普通低秩模块与增加JS损失的版本表现如何。原静态键编辑保留为历史方法对照。

| 实际方法 | 盲参考输入 | 最终判断可用信息 |
|---|---|---|
| 无JS主方法、含JS版本 | 患者、当前条件、祖先条件的隐藏表示 | 完整指南、患者、问题，加参考向量 |
| 直接盲判查表、盲表示分类器 | 同一局部提示／隐藏表示 | 盲判或分类器决定分支；程序按树转移 |
| 标签融合 | 同一局部T/F/U概率 | 完整指南分支概率与盲概率 |
| 上下文对照 | 同一局部T/F/U概率的文字提示 | 完整指南、患者、问题与概率提示 |
| 普通低秩、零干预 | 无盲参考 | 完整指南、患者、问题 |

实际盲判并未读取完整条件树；完整树只供程序执行转移与查表。主方法与盲分类器不等信息，完整模型与盲判的差异也不只来自处置文本。主方法与上下文对照共享参考来源，但传递隐藏向量与三个概率，不能将比较推广为内部干预优于所有上下文方法。

现有普通低秩和上下文对照仍含JS，因此与新主方法的损失不完全匹配。无JS版本优于它们，不能单独证明收益来自处置盲表示；支撑这一归因需要后续匹配损失的对照，本次不新增实验。

主指标固定为原指南完整路径正确率，重点比较普通低秩、上下文和盲表示分类器，报告配对纠正、退化及净提升；补充两种指南均正确率、终点、来源等权、路径一致率和年龄条件翻转能力。既有内部确认中的主方法为91/100完整路径正确、82/100两种指南均正确，这是改选依据，不是独立确认。若官方测试不支持收益，就收窄贡献，不用输出整理或选择阶段成绩代替验证。

官方当前队列仅评原指南；已有交换评测作为辅助证据，不改变冻结的主指标。盲判方法的交换路径直接复用，其100%一致率不是学出的机制证据。内部确认已参与主方法选择，两版本同时报告，不能改写为只根据开发集选定。

## 7. 给老师的简明说明

我们研究大模型能否真正依据患者事实和指南条件选择分支。完整指南模型与不看候选处置的条件判断模型会犯不同的错误，因此不能简单把其中一方的标签当成最终答案。我们使用同一个冻结模型形成两种表示，学习在当前决策的一个四维子空间中结合它们，再由模型完成判断。训练要求原指南和交换处置后的指南都选对，决定性事实改变后选择相应分支，但不强制两个输出概率分布相同。我们要检验的是这种内部结合能否比直接查表、上下文补充和训练的分类器更准确、更稳定，并用损失匹配的对照区分盲表示与训练目标的作用。
