# 方法定稿：面向指南忠实推理的处置盲表示干预

2026-11-01。方法结构与主配置已经确定，独立确认结果仍待完成。本文件固定动机、算法与主张范围，不增加实验配置。

## 1. 动机：分支选择应依据患者事实和指南条件

指南推理需要先根据患者事实判断条件，再选择分支，最后读取对应处置。我们研究的忠实性是：模型的分支选择是否忠实于当前输入的患者事实和规则，而不是仅生成合理的处置或合法的路径格式。

本轮将这一要求具体化为三个行为标准：

1. 条件判断正确，生成路径与患者事实及指南条件一致。
2. 固定患者、条件和转移关系，只交换终点处置描述，分支选择保持稳定。
3. 改变决定性患者事实后，模型按改变后的条件选择相应分支。

终点处置描述的变化应影响最终填写的处置，而不应反过来决定条件是否成立。上述标准评价决策行为，不等同于已经证明模型所有内部计算或生成解释均忠实。

## 2. 洞见：两种输入产生互补的判断错误

完整指南输入保留了患者、规则语境和候选处置；处置盲输入只保留患者、当前条件及理解指代所需的祖先条件。二者使用同一冻结模型，但可能产生不同错误。

开发100例的已有结果表明，11例是处置盲查表错误而完整指南模型正确，9例相反。内部方法分别保持了前11例，并解决了后9例中的7例。进一步逐例分析发现，14例相对查表的纠正中，11例是保留完整模型本来就有的正确判断，2例体现不同节点上的互补，1例不能由两侧离散标签择优解释。详见[17例分析](representation-case-analysis-17-20261101.zh.md)。

这些结果支持“判断错误具有互补性”，尚不证明两侧一定拥有不同事实。很多决定性事实同时存在于两侧输入，差异也可能来自语境、提示格式、计算过程或标签读出。

直接依据盲判删除其余分支，会把一次不确定或错误的判断固定为后续前提。完整方法保留所有规则，并在当前分支尚未确定时学习结合两侧表示。研究假设是：这种结合能够保留完整模型的正确判断，同时利用处置盲表示修正部分错误；不能预先假定学习到的强度已经能准确识别哪一侧可靠。

## 3. 固定算法

三模块保留原编号，但职责固定为：模块一学习干预参数；模块二提供当前节点的处置盲表示；模块三在完整指南模型的当前分支决策处实施干预。

### 3.1 模块二：形成处置盲参考表示

对于实际到达的节点g，同一冻结骨干接收：患者原始记录、当前完整条件，以及理解该条件所需的祖先条件。候选处置、原问题、选项和金标路径不进入该输入。既有治疗史属于患者事实，保留；祖先条件只作语境，不被当作患者已经满足的事实。

在该输入的回答边界，取第ℓ层注意力输出投影之后、残差相加之前的向量，记作z_g。它是没有读取候选处置文本的参考表示，不保证本身正确。T/F/U标签与概率只用于诊断及对照，不强制决定完整方法的路径。

不增加结构化事实抽取、原子条件拆解或额外临床特征模型。表示按病例和当前节点缓存复用。

### 3.2 模块一：学习子空间、映射与强度

完整指南模型在当前分支查询位置t的同层注意力输出记作o_t。学习三个部分：正交子空间U、处置盲映射B以及强度函数。

```math
U\in\mathbb R^{d\times k},\quad U^\top U=I,\qquad
B\in\mathbb R^{k\times d},\qquad
\gamma_t=\sigma\!\left(w^\top[U^\top o_t;Bz_g]+b\right).
```

U通过对可训练矩阵做QR分解保持正交。B把处置盲表示映射到该子空间。γ根据两侧低维表示学习，不直接使用标签最大概率，不把γ解释成已校准的可信度。

### 3.3 模块三：只调整当前分支决策的表示

在注意力输出投影之后、残差相加之前实施：

```math
\widetilde o_t=o_t+\gamma_tU\left(Bz_g-U^\top o_t\right).
```

由于U列正交，也可以写成：

```math
\widetilde o_t=(I-UU^\top)o_t
+U\left[(1-\gamma_t)U^\top o_t+\gamma_tBz_g\right].
```

因此，在该干预位置，子空间之外的分量保持不变，子空间之内结合两侧表示，后续冻结网络继续完成分支判断。这是算法的操作含义。U是否真正对应有用的条件判断分量，需要行为对照来验证；正交与低秩本身不提供这一保证。

干预只作用于产生当前Y/N选择的查询位置。患者读取、指南预填充和非决策词元不施加编辑。γ处于0到1之间，但B可学习，因此这不保证实际改变量很小；幅度由损失惩罚并据实报告。

### 3.4 保持后续上下文缓存干净

每次决策保留一份未编辑的上下文KV。临时复制缓存，在当前查询上编辑并读取分支分数；随后丢弃临时前向产生的KV。选定分支词元由未编辑模型重新编码，再进入下一次决策。

干预会通过实际选择影响后续路径，但不把编辑产生的额外缓存变化传下去。它并不消除错误分支选择本身的传播。

## 4. 训练如何对应忠实性要求

骨干冻结，只训练U的底层矩阵、B、w和b。每个普通病例取根、中间、末端三个不同节点，不足三个时全部使用；训练使用金标前缀，推理只使用已经生成的前缀。

同一病例提供原指南与终点处置描述交换后的两个视图，固定患者、条件、规则编号、转移关系和终点编号。损失为：

```math
\mathcal L=
\tfrac12(\mathrm{CE}_{orig}+\mathrm{CE}_{swap})
+\mathrm{JS}(p_{orig},p_{swap})
+0.1\mathcal L_{keep}
+0.001\mathcal L_{edit}.
```

| 目标 | 实现 | 对应问题 |
|---|---|---|
| 分支正确 | 原指南和交换指南的分支交叉熵 | 避免仅追求分布稳定而选择错误分支 |
| 处置不变性 | 两个视图分支分布的JS散度 | 减少终点处置内容对条件判断的影响 |
| 条件敏感性 | 已核验年龄最小对的两态标签进入同一交叉熵 | 决定性事实变化后应切换分支；没有另设未实现的翻转损失 |
| 保留已有正确判断 | 仅对训练标签确认原模型正确的节点视图，约束原分布到编辑分布的KL | 减少把本来正确的判断改错 |
| 限制改动 | 输出改变量平方范数除以原输出平方范数 | 抑制不必要的大幅修改，不是硬保证 |

年龄最小对仅支持当前覆盖范围内的条件翻转，不提前称为通用临床机制。处置不变性和条件敏感性必须结合评价；恒定选择某一分支不能被计为忠实推理。

## 6. 论文主张与判定依据

论文的方法主张固定为：**通过在当前分支决策处学习结合处置盲表示与完整指南表示，改善模型依据患者事实和给定规则进行分支推理的能力，并减少无关终点处置变化对判断的影响。**

低秩表示干预已有[ReFT](https://arxiv.org/abs/2404.03592)等先例。本方法需要验证的贡献是处置盲参考、当前决策处的条件化结合与反事实监督在本任务中的共同作用，不将低秩形式本身称为创新。

现有队列的对照分别回答：直接盲判后查表能否达到同样效果；标签概率融合是否已经足够；相同训练的上下文方法是否同样有效；训练一个盲表示分类器能否解释收益；没有盲表示的普通低秩模块和没有JS损失的模块表现如何。原静态键编辑保留为历史方法对照。

必须在相同输出设置下报告完整路径与终点、配对纠正和退化、来源等权结果、处置交换稳定性及条件翻转能力。若内部方法没有超过相应替代方法，就收窄贡献，不用输出整理收益或开发集选出的成绩代替独立确认。

## 7. 给老师的简明说明

我们研究大模型能否真正依据患者事实和指南条件选择分支。完整指南模型与不看候选处置的条件判断模型会犯不同的错误，因此不能简单把其中一方的标签当成最终答案。我们使用同一个冻结模型形成两种表示，学习在当前决策的一个四维子空间中结合它们，再由模型完成判断。训练同时要求患者条件决定分支、处置描述交换不改变分支、决定性事实改变后分支相应改变。我们要检验的是这种内部结合能否比直接查表、上下文补充和同样训练的分类器更准确、更稳定。
