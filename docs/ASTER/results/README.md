# 单轮结果附件

官方测试的主指标为原指南完整路径正确率。下表按同一病例配对，主方法为历史冻结的处置盲内部干预，不是最新可学习 M3。每个对照均覆盖7,458例，区间按418个来源簇重采样。

| 对照 | 主方法纠正 | 主方法退化 | 配对净提升（百分点） | 95%区间（百分点） |
|---|---:|---:|---:|---:|
| 普通低秩干预 | 497 | 127 | +4.96 | +4.01 至 +5.94 |
| 零干预 | 1,537 | 172 | +18.30 | +16.64 至 +19.85 |
| 标签概率融合 | 883 | 326 | +7.47 | +6.14 至 +8.78 |
| 概率上下文 | 930 | 161 | +10.31 | +8.97 至 +11.56 |
| 盲表示分类器 | 787 | 537 | +3.35 | +1.59 至 +5.18 |

[single-turn.json](single-turn.json) 保存严格路径计数、分语言与来源等权结果、BERTScore 全量结果、处置交换与年龄事实翻转的配对统计，以及18节点实验设计和主终点。篇中 BERTScore 数值为百分数，PathAcc 配对差字段以百分点为单位。历史生成式语义评分的有效分母随方法而异，见[正文表1和表2b](../manuscript-representation.zh.md#51-单轮主结果)。

[pathacc-by-source.csv](pathacc-by-source.csv) 每行对应一个来源簇与一种对照。both_correct 和 both_wrong 分别为两方法均正确、均错误的例数；corrected 为仅主方法正确，regressed 为仅对照正确。

[matched-nodes.csv](matched-nodes.csv) 每行是一个新来源的目标节点。internal 和 soft 分别表示内部干预与匹配软提示，yes/no 表示事实状态，original/sibling_swap 表示原视图或兄弟终点交换。1表示选对分支。将同一方法的四个标记全部为1的行计数，即得到四种输入均正确的节点数。
