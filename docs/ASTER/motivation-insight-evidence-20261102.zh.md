# 动机、核心洞见与现有证据

2026-11-02。依据现有实现和已保存结果重新整理；没有训练或重新生成预测。主方法仍为冻结的第18层、秩4、第3轮无JS版本。

## 动机：让分支判断忠实于患者事实和指南条件

任务要求模型逐步核对条件并选择分支，而不是凭一个处置看起来是否合适，反推通向它的条件成立。完整指南提供判断语境，也可能引入与当前条件无关的线索；处置盲输入隔离了候选处置文本，但仍会漏读、误解或判断错误。

因此，方法面对的问题是：怎样使用一份可能有帮助、也可能出错的条件判断，同时保留完整模型的纠错能力？不能预先把所有错误归因于处置干扰，也不能把处置盲模型视为正确答案来源。

## 核心洞见：辅助信息不必先变成标签，再参与最终决策

“盲判选分支，再删掉其他规则”把辅助判断变成了后续推理的前提。当前方法把同一次盲判前向中的隐藏表示作为参考，在完整模型尚未作出当前分支选择时参与计算。

区别在于辅助信息的使用方式：从读取一个已经压缩的T/F/U结论，变为学习使用形成结论的内部表示。隐藏表示是否包含未被标签读出的有用证据，是需要验证的假设；当前并未识别其中具体编码了哪些条件事实。

完整指南与盲提示已表现出互补的错误；“判断互补”是观察，“互补一定来自处置集合”不是已建立的解释。

## 算法如何实现

同一冻结模型在患者、当前条件和祖先条件上得到参考z，在完整指南的当前决策位置得到o。训练一个秩4子空间U、映射B与强度函数：

$$\widetilde o=o+\gamma U(Bz-U^\top o),\qquad
\gamma=\sigma(w^\top[U^\top o;Bz]+b).$$

参考不硬指定路径。当前决策处的子空间向参考目标调整，正交补保留，后续冻结网络完成判断。编辑的临时KV被丢弃，所选分支通过未编辑模型重新编码。

训练只更新新增参数，用原指南与全树处置描述重排视图的正确分支监督，配合保持正确判断和编辑幅度惩罚。无JS版本去掉额外概率分布一致性项，但继续使用两视图交叉熵和已有年龄最小对。

这一设计保证参考目标不读取候选处置、编辑范围明确；不保证参考正确、门控能判断可靠性，或最终输出完全不受处置影响。

## 为什么内部干预值得研究

| 设计特点 | 相对当前具体对照的可能优势 | 已知边界 |
|---|---|---|
| 使用隐藏参考而非仅T/F/U概率 | 可能利用标签未表达的条件证据 | 未证明具体证据及其独立贡献；更丰富文本提示也可能有效 |
| 在当前分支决策表示中结合 | 可以直接以分支正确性训练参考如何影响决策 | 直接修改不等于必然更准确；上下文方法也能接受监督 |
| 保留完整指南参与判断 | 辅助判错时仍有机会保持完整模型的正确分支 | 不是内部方法独有属性，保留完整指南的上下文方法也具备 |
| 按节点和两侧表示决定编辑 | 可以对不同决策使用不同修改 | 尚未证明门控识别了哪一侧可靠 |
| 限定当前查询并丢弃编辑KV | 避免额外的编辑缓存变化延续 | 实际选错分支仍会影响后续，尚未单独证明该设计带来的性能收益 |

内部方法的优势是可检验的算法假设，不能从“所有上下文方法必然丢失信息”推导。无序处置集合可以规范排序后提供；丰富提示、标签融合或其他模型也可能做到有效结合。

现有“上下文对照”本身训练了普通低秩模块：它将局部盲判概率写入提示，低秩映射使用完整表示自身。因此当前比较更准确地说是“通过隐藏表示提供盲参考”与“通过概率文本提供盲参考”，并非内部编辑与完全没有训练的提示的比较。

## 能写成什么贡献

可提出并检验的算法贡献是：

> 面向指南分支推理，使用同一冻结模型在处置盲输入下得到的表示作为参考，学习在当前决策位置如何将它与完整指南表示结合，从而改善条件判断，同时避免把辅助标签直接当作最终路径。

相对本实验的普通低秩对照，新增的是来自另一次受限输入的参考z，而不是仅从完整表示o自身学习修改。相对直接盲判查表，保留了完整指南参与决策；相对概率提示和概率融合，使用的是内部表示。

低秩、门控、冻结骨干、交换增强和移除JS分别都不单独作为创新。也不宣称这是首次提出表示结合，或已经证明通用的忠实推理机制。

## 已有结果支持到哪一步

### 1. 两种输入的判断错误存在互补

历史含JS版本的开发100例中：
- 盲判错误、完整模型正确的11例，内部方法保持11例正确。
- 盲判正确、完整模型错误的9例，内部方法纠正7例。
- 两侧完整路径都错误的9例，内部方法得到3条正确路径，其中2例存在不同节点上的互补。

这些结果支持保留完整判断并结合辅助参考这一设计动机。它们不证明纠正专由盲表示引起；少量两侧标签都错而编辑正确的节点，也可能由普通监督训练解释。

### 2. 当前具体方法有较好的选择阶段表现

以下100例内部确认结果已参与无JS主方法选择，不再作为该方法独立确认。所有方法共用合法路径生成、终点停止和处置填写。

| 方法 | 原指南完整路径正确 | 两视图完整路径均正确 |
|---|---:|---:|
| 零干预 | 68/100 | 59/100 |
| 标签融合 | 83/100 | 78/100 |
| 普通低秩，含JS | 87/100 | 79/100 |
| 概率提示＋普通低秩，含JS | 73/100 | 64/100 |
| 盲表示分类器 | 79/100 | 79/100 |
| 盲参考内部干预，含JS | 86/100 | 81/100 |
| 主方法：盲参考内部干预，无JS | 91/100 | 82/100 |

主方法相对零干预纠正26例、退化3例；相对普通低秩纠正6例、退化2例。这说明当前方案值得在冻结配置下继续检验，不能用总分差替代因素归因。

最重要的限制是：相同含JS目标下，盲参考版本原指南86/100，普通低秩87/100；新主方法91/100同时改变了参考输入与损失。**盲参考相对普通低秩的独立增益尚未建立。** 即使官方大样本继续领先既有对照，这个损失不匹配仍不会自动消失。

### 3. 官方主方法已经完成，但比较尚未完成

读取已完成的主方法汇总：MEGA-CDP官方划分7,458例中，完整路径正确6,653例，即89.21%，技术失败0。采用冻结的结构化决策树输入设置，不能与原始指南自由文本任务混为同一设置。

本次读取时还没有全部对照完成后的REPORT。因此89.21%说明主方法在该划分上的表现，尚不能说明它超过普通低秩、上下文或盲分类器。当前官方队列只有原指南预测，不提供官方交换稳定性结论。

### 4. 尚未证明的内容

- 全树交换会改变多数非根节点的局部处置集合，不能证明只消除了分配影响。
- 两视图均正确是有用行为指标，但不能识别模型究竟使用了哪类语义信息。
- 年龄翻转中多个学习方法均为满分，样本少且已暴露，不能证明广泛的条件敏感性优势。
- 没有证明门控已判断出哪侧可靠、没有证明某子空间编码处置集合，也没有证明内部方法普遍优于上下文方法。

## 给老师的简明表述

我们研究的是模型能否按患者事实和指南条件逐步选分支。完整指南模型和只看条件的模型会犯不同错误，所以不能简单让其中一方的答案决定整条路径。我们让同一个模型先形成一份不看候选处置的内部参考，再学习怎样把这份参考用于完整模型当前的分支决策。要验证的是，使用内部参考是否比传一个标签、加一段概率提示或单独训练分类器更有效。已有结果支持判断互补和当前系统的改进潜力，但还没有证明盲表示本身相对普通低秩训练的独立优势。
