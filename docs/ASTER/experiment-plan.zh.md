# ASTER 实验计划与指标定义

[主线索引](README.md) · [论文工作稿](manuscript.zh.md) · [六项主张](claims-and-falsification.zh.md)

**版本：2026-10-27。状态：待执行协议。** 主方法由处置盲分支分类、离线适用性子空间学习和在线规则键平移组成。历史实验只支持其原模型、输入与算子，不能自动成为新版方法的结果。样本规模、模型版本、超参预算、非劣效界值及统计分析计划须在正式运行前固定。预填数字不作为目标成绩或停止条件。

## 1. 数据、划分与五卷配对

基本单位是病例底稿、决策树／指南、分支组和适用规则。底稿及其全部改写共用配对标识。划分以树或指南为单位，禁止同源改写跨集合。每个分支组须具有已核验的互斥语义；从根节点继承的条件必须保留。重叠的建议列表不得直接作为互斥类别。无适用规则、关键事实缺失以及输入结构无效分别记录，不能通过静默剔除提高准确率。

开发阶段区分三个用途：模块二最小对拟合、模块一温度拟合、阈值与增益选择。优先使用互不重叠的开发树子集；数据有限时采用按树划分的交叉验证，并冻结折叠与选择过程。测试树始终隔离。模块一只拟合一个全局正温度；阈值和增益由开发数据选择后固定，不逐测试样本重新拟合。离线校准是模块一输出唯一必要的开发用途，不将其伪标签送入模块二。

| 卷 | 构造 | 金标 | 要回答的问题 |
| --- | --- | --- | --- |
| NC | 保留原条件与处置 | 原适用规则的处置 | 原生规则遵循如何？ |
| AC | 仅替换适用分支的处置 | 替换后的处置 | 模型是否覆盖所给指南而采用旧处置？ |
| IC | 仅替换不适用兄弟分支的处置 | 原处置 | 不适用改写本身是否产生干扰？ |
| SW | 交换适用与兄弟分支的处置 | 原兄弟分支的处置 | 熟悉处置落到错误分支时是否诱发误用？ |
| CS | 改变条件阈值，使适用分支翻转 | 新适用分支的处置 | 是否重新读取条件并放弃旧分支？ |

CS 由独立数据验证器核查翻转、单位、边界等号、时间基准和缺失值；该验证器属于离线数据质量控制，不是模块一运行步骤。生成路径任务只纳入参考路径可一致更新的病例，公开所有排除计数及原因。锁定清单记录数据文件哈希、构造程序、模型分词器、配对关系和实际分母。

## 2. 从现象到机制

**H1：处置可见性。** 盲判与明判使用同一病例，均只读出分支类别。控制问题和选项中的处置、顺序、长度与位置。熟悉、陌生、中性代号三种诱饵分开报告。每个模型的闭卷偏好估计方法和分层边界在开发集固定；不在测试集重新筛选诱饵以扩大效应。

**H2：读取机制。** 在独立开发资料上实施注意力敲除、键／值激活修补和探针分析。比较目标窗口、随机窗口、无关片段、修补方向及匹配长度条件。探针准确率只表示信息可解码；需要干预改变输出且排除相应混杂，才能支持读取机制。诊断窗口用于独立验证，不直接冒充模块二的选头结果。

**H3：患者相关目标。** 构造共享指南但金标分支相反的病例对。比较全指南高亮、固定规则高亮、查询自适应目标及模块一目标。同一算子换目标与同一目标换算子分别比较，避免把适用性信息的收益归因于键编辑形式。

## 3. 模块一：处置盲分类与经验校准

### 3.1 冻结运行契约

默认结构化接口包含患者原文、分支组编号、规则编号、自然语言条件和必要祖先条件。原始编号保留在程序边界；模型提示只使用中性代理标签、患者、条件与无处置信息的固定任务指令。指南的处置字段、原始选项和含处置的原始问题不进入分类提示。确需问题限定范围时，只使用单独核验的条件性任务上下文，并记录其构造版本。患者既往用药、既往治疗及规则中的暴露条件属于判定事实，不按处置词表全局删除。

每组使用同一部署骨干模型，独立得到规则和 `NONE` 的候选分数。默认使用已在实际聊天模板和评分边界核验的互异单词元代理标签，再映射回规则编号。不能把任意多词元规则编号的首词元当作完整类别分数。若标签方案不能满足条件，应明确失败或另行注册完整序列评分变体；不得静默改变评分语义。

温度缩放后记录 `probabilities`、`prediction`、最大概率、`margin`、以自然对数计算的 `entropy` 和 `abstain`。`prediction` 始终保留最高类别，弃权不能把它覆写为 `NONE`。最大概率或间隔低于冻结阈值时弃权；最高类别为 `NONE` 时即使不弃权也禁止编辑。并列最高类别须按冻结规则记录并关闭干预。

### 3.2 版本与必要对照

| 版本 | 判定器 | 用途与限制 |
| --- | --- | --- |
| M1-self | 同一骨干模型、处置盲提示、组内受限分类 | 唯一默认主方法；不抽取患者原子，不生成处置 |
| M1-NLI | 在相同可见输入上加入医学自然语言推断辅助 | 可选辅助消融；独立说明模型、训练来源、融合与校准方案，计入额外成本 |
| M1-oracle | 规则分支金标 | 诊断上界；不作为可部署方法，不将测试金标用于模块二的离线估计 |

模块一实验报告各卷分支准确率、`NONE` 的分类表现、负对数似然、布里尔分数、预先固定分箱的期望校准误差，以及弃权后的覆盖率和选择性错误率。温度缩放不改变最高类别，因此不把其后的分支准确率变化当作正常校准收益。按数值、时间、否定、类别、复合条件及缺失信息分层；这些标签用于离线评测切片，不要求模块一在线抽取原子。

按正确／错误与高／低置信作完整交叉统计，另外报告 `NONE` 的各类情况。将模块一错误与最终答案由对变错交叉统计，以测量错误放大。报告标签顺序、代理标签映射、组大小和指南来源对读数的影响；不根据测试结果挑选更有利的标签。

### 3.3 处置盲性的验收

对非处置信息保持不变的 NC／AC／IC／SW 配对，先逐字比较构造后的模块一提示，再比较分词结果与模型读数。只比较最终准确率不能排除泄漏。祖先条件、规则标识及任务上下文也必须纳入检查。CS 改变条件，应允许提示和预测随之改变。

## 4. 模块二与模块三：分离估计和在线选择

模块二仅使用经独立验证的金标最小对。构造中患者置于规则之前，使规则键能够编码患者差异。正负输入只改变决定性事实，保留规则文本并对齐词元位置；中性样本用于诊断患者在场效应。记录最小对的金标验证、位置对齐、处置平衡及开发来源，不使用模块一预测筛选正负样本。

H4 的比较至少包含：原始均值差、配对差分的谱投影、随机同范数方向、通用 SEKA／AdaSEKA 方向；选头比较随机头、编码分离及编码与在线可读性的联合指标。报告学习曲线、子空间分半稳定性、符号稳定性，以及患者在前构造到在线原生顺序的迁移。若方向在线不可读，不将离线可分性解释为可用的干预方向。

模块三的默认策略为：高置信且最高类别为实际规则时，该规则取正增益，组内其余规则取负增益；弃权或 `NONE` 时整组增益为零。正负增益为开发集冻结的常数，连续置信度调节只作为消融。增益作用于选中头的规则编号段和处置段的键平移；证据位置不作为主方法编辑目标。

多层决策树只沿已确认的祖先路径启用下游组。上游不确定时，下游组不作额外编辑；不得将高置信父节点的错误沿整棵未访问子树无条件放大。若另行实现整棵子树抑制，必须作为独立消融并评估父节点错误传播。

H5 比较无弃权、仅概率阈值、仅间隔阈值、联合阈值、未校准与温度缩放。报告覆盖率与错误干预曲线，并在相同覆盖率下比较。温度和阈值只能提供经验性取舍，不报告保形覆盖保证或风险认证结果。H6 比较同一模块一输出上的不同执行方式，特别测量模块一已判断正确但生成仍执行错误的子集。

## 5. 同信息、同预算对照

| 信息层级 | 比较方法 | 必须匹配的输入与解释 |
| --- | --- | --- |
| 无额外判定信号 | Vanilla、Reorder、PromptRep、CoT、CAD、JuICE、PASTA、SEKA、AutoPASTA | 同一病例、指南、选项与答案格式；额外计算计入成本 |
| 相同模块一输出 | ASTER、TS-Note、TS-Prune、TS-Map、TS-Fuse、TS-SEKA／AdaSEKA、TS-Rerank | 复用同一分支分布、最高类别与弃权状态；不以重新运行同型号判定器代替完全共享输出 |
| 仅模块一直接映射 | M1-only／TS-Map | 适用规则到所给指南处置的直接映射；检验注意力编辑是否超过简单查表；弃权时采用冻结的相同回退政策 |
| 金标诊断 | M1-oracle + 各执行方式、Gold-Prune | 金标明确标为上界；区分分支判定错误和执行错误 |

选择题中的 Map／Fuse 需要确定的分支—处置—选项映射。该映射在分类器之外读取完整指南，不改变模块一处置盲、只输出分支的接口。多个规则共享处置、多种处置合并为一个选项或 `NONE` 时，须固定处理规则。自由文本任务使用可实施的文本附注、裁剪、高亮和候选重排；不能把只在选择题上定义的方法直接宣称不适用于所有路径任务。

共享弃权决策的执行基线必须报告相同的无干预回退；也可另设各方法独立调参比较，但应标为不同问题。记录超参配置数、候选数、模型调用和可用标签。成本比较同时报告原生表现及诱饵表现，避免以不同预算点替代公平对照。

离线平移与监督微调、反事实监督微调等训练方法的比较属于次要研究。使用相同可用开发数据与模型规模，披露额外训练数据、更新参数及算力。参数冻结或逐例可关闭是方法属性，不证明它在分布内准确率、指南更新或能力保持上必然更优。

## 6. 指标、分母与评分

设各卷准确率为百分数。主要平衡指标按卷宏平均定义：

$$\mathrm{NCA}=\frac{\mathrm{NC}+\mathrm{IC}}{2},\qquad
\mathrm{CA}=\frac{\mathrm{AC}+\mathrm{SW}+\mathrm{CS}}{3},\qquad
H=\frac{2\,\mathrm{NCA}\,\mathrm{CA}}{\mathrm{NCA}+\mathrm{CA}}.$$

NCA 与 CA 均为零时约定 H=0。由未舍入的逐例结果计算，最后才舍入。若各卷分母不同，宏平均不可当作全体题目的微平均准确率。

| 指标 | 统计单位与定义 |
| --- | --- |
| 分卷准确率 | 正确题数／该卷全部纳入题数；失败按冻结规则计入，不能静默剔除 |
| 伤害率 | NC∪IC 中 Vanilla 正确且方法错误的题数／NC∪IC 全部题数；仅指评测退化 |
| 纠正率 | NC∪IC 中 Vanilla 错误且方法正确的题数／同一总分母 |
| 选择题诱饵采纳率 | SW 中选择预先指定诱饵处置的题数／SW 全部题数 |
| 分支准确率 | 原始 `prediction` 正确数／固定待判定组数；弃权不改变此指标的预测标签 |
| 判定覆盖率 | `abstain=false` 的组数／全部待判定组数；包含高置信 `NONE` |
| 选择性错误率 | 未弃权组中的错误预测数／未弃权组数；零覆盖时记为未定义 |
| 实际干预覆盖率 | 至少一条目标规则具有非零增益且实际执行有效键编辑的组数／全部待判定组数；只计算增益时另称计划非零增益覆盖率，另报至少一组实际干预的病例比例 |
| 负对数似然与布里尔分数 | 含 `NONE` 的完整分布，按组平均；布里尔分数采用各类别平方误差之和并固定该口径 |
| 期望校准误差 | 在冻结分箱下比较最大概率与原始分类正确率；同时公开分箱计数及可靠性图 |
| 路径一致性代价 | 使用核验后的官方评分定义与版本；保留原生与诱饵两个集合 |
| 分支忠实率 | 固定关键节点集合中正确选择的比例；病例宏平均与节点微平均分开 |
| 路径诱饵采纳率 | 固定诱饵节点上采纳诱饵的比例；冻结遗漏或未到达节点的计分方式 |
| 退化率 | 重复循环或输出触顶的病例数／全部病例数；两种事件的交集只计一次 |

在相同集合与权重下，微平均准确率差应等于纠正率减伤害率。诱饵采纳率和分支忠实率通常不互补。熵使用自然对数，跨组大小比较时另外报告除以最大熵的归一化值；不把大组天然较高的熵直接解释为更差校准。

路径评分预先固定关键节点、无效输出与终止规则。评审缓存键包括病例／指南标识、规范化输出、评审模型、提示版本与评分设置。仅在任务上下文和设置相同时复用评分。

## 7. 统计、成本与实施顺序

主要效应使用按树／指南聚类的配对区间或匹配检验。H、连续路径代价和节点聚合量不能直接套用二元配对检验。多重比较族、主要对照、校正方式与最小效应预先固定。没有显著差异不等于等效，非劣效通过不代表改善。

成本记录硬件、精度、批量、完整上下文长度、模块一组数、分类前向次数、最终生成长度、预填充和解码耗时、离线估计与校准成本。复用同一骨干权重不等于没有额外前向成本。缓存共享长度、逐例复制和编辑开销须实测；不继承旧算子的延迟数字。

实施顺序如下：

1. 冻结数据来源、配对标识、树划分、互斥组、祖先条件、排除规则与指标。
2. 核验处置输入不变性、患者事实保留、代理标签分词、概率与弃权契约；覆盖重复标识、非有限分数、超长输入、并列及 `NONE`。
3. 独立构造模块二金标最小对，完成方向、选头和在线可读性验证；核验旋转位置编码前后的编辑位置、缓存隔离和未选头状态。
4. 在开发数据拟合单温度并选择阈值、头数和正负增益；冻结配置，记录所有尝试。
5. 验收组级零增益和全病例零干预。整体回退必须绕过编辑，并使用与基础模型相同的完整提示和推理设置。
6. 运行锁定测试，保存全部失败与负结果；从逐例产物统一生成表格、区间和摘要数字。
7. 逐项回答 H1–H6。若模块一直接映射已解释全部收益，或方向不可读，应收窄主张，不以增加测试集调参弥补。

所需产物至少包括数据清单、构造版本、最小对金标、原始分数、温度和阈值、分支预测与弃权、实际增益、最终输出、评审缓存、模型／模板指纹、统计程序及运行日志。当前文档与参考接口更新不构成这些模型实验的完成记录。
