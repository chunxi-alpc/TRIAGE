# ASTER 实验计划与指标定义

[主线索引](README.md) · [论文工作稿](manuscript.zh.md) · [六项主张](claims-and-falsification.zh.md)

**状态：待执行协议。** 本文按新主张组织实验，不继承旧支线的结论。样本规模、模型版本、超参预算、非劣效界值及统计分析计划须在正式运行前固定。原稿中的预填数字不作为目标成绩或停止条件。

## 1. 数据与五卷配对

基本单位是病例底稿、决策树／指南、分支组和适用规则。原始底稿及所有派生卷使用同一配对标识。开发集与测试集按树或指南隔离；任何同源改写不得跨集合。锁定清单记录文件哈希、构造程序版本、排除理由及实际分母。

| 卷 | 构造 | 金标 | 要回答的问题 |
| --- | --- | --- | --- |
| NC | 保留原条件与处置 | 原适用规则的处置 | 原生规则遵循如何？ |
| AC | 仅替换适用分支的处置 | 替换后的处置 | 模型是否被旧处置先验覆盖？ |
| IC | 仅替换不适用兄弟分支的处置 | 原处置 | 不适用改写本身是否产生干扰？ |
| SW | 交换适用与兄弟分支的处置 | 原兄弟分支的处置 | 熟悉处置落到错误分支时是否诱发误用？ |
| CS | 改变阈值，使适用分支翻转 | 新适用分支的处置 | 是否重新读取条件并放弃旧分支？ |

CS 由程序验证翻转，并核查单位、边界等号、时间基准和缺失值。生成路径任务只纳入参考路径可一致更新的病例，所有排除计数公开。合成反事实是评测输入，不能当作真实诊疗规则。

## 2. 从现象到机制

**H1：处置可见性。** 盲判与明判使用同一病例并仅输出分支编号；控制选项、问题中的处置名称、长度、顺序和非处置位置。熟悉、陌生、中性代号三种诱饵分开报告。闭卷先验置信度的估计方法和分层边界在开发集固定；测试集不重选分位或诱饵以追求更大效应。

**H2：读取机制。** 在开发集开展注意力敲除、键／值激活修补和探针分析。比较目标窗口、随机窗口、无关文本片段、修补方向及匹配长度条件。探针准确率仅表示信息可解码；只有干预改变输出并排除相关混杂，才可支持读取机制。层窗口按模型分别确定，不将原稿预填层号作为已知事实。

**H3：目标是否依赖患者。** 构造使用同一指南、但适用分支相反的病例对。分别比较整指南高亮、固定规则高亮、查询自适应高亮和患者适用性目标。同一算子换目标、同一目标换算子须分开，防止把目标信息的收益归因于注意力编辑形式。

## 3. 同信息、同预算对照

| 信息层级 | 比较方法 | 必须匹配的输入 |
| --- | --- | --- |
| 无额外判断信号 | Vanilla、Reorder、PromptRep、CoT、CAD、JuICE、PASTA、SEKA、AutoPASTA | 同一病例、指南、选项与答案格式；各方法自己的额外计算计入成本 |
| 相同盲判信息 | ASTER-self、TS-Note、TS-Prune、TS-SEKA、TS-Map、TS-Fuse、TS-Rerank | 尽可能复用同一盲判分布和编号，而不只使用同型号模型重新判定 |
| 相同盲判及证据信息 | ASTER-full、Clerk-Note、Clerk-Prune、Clerk-Map、Clerk-Fuse | 相同原子状态、置信度、证据位置及软否决规则 |
| 金标诊断 | Gold-Prune、Gold-ASTER | 金标分支明确标为诊断上界，不混入可部署主结果 |

Map／Fuse 的本文定义需要分支—选项映射，仅用于相应选择题。自由文本路径采用文本附注、裁剪、高亮、候选重排等可实施基线；如加入路径级融合，应另行定义，不能先验排除。

超参配置数、候选数、模型调用和调参数据须披露。生成任务同时比较匹配成本与原生表现，避免仅用不同成本点宣称优势。证据员只能读取条件和病历，但其状态本身可能足以推断分支；Clerk 基线用于辨别这一贡献。

## 4. 不确定性与组件实验

H4 分别操纵分支翻转率、错误置信度和概率校准。至少覆盖自信错误、犹豫错误、正确但犹豫和未知状态；比较不同噪声机制。门控解析图只说明公式，不替代这些实验。

H5 的阶段消融包含：盲判改为明判、文本隐藏、去掉跨处置隔离、重新明判编码、取消门控、取消强调、固定门控强度、扩大强调层范围及相同算子使用患者无关目标。

H6 的证据员实验包含：self／full、去掉绑定、去掉软否决、文本状态附注、覆盖率扫描、数值／时间／否定／类别分层，以及抽取错误和自然语言推断错误的分离统计。任何模块失败须计入覆盖与总体结果。

## 5. 指标、分母与评分

设各卷准确率为百分数。主要平衡指标按卷宏平均定义：

$$\mathrm{NCA}=\frac{\mathrm{NC}+\mathrm{IC}}{2},\qquad
\mathrm{CA}=\frac{\mathrm{AC}+\mathrm{SW}+\mathrm{CS}}{3},\qquad
H=\frac{2\,\mathrm{NCA}\,\mathrm{CA}}{\mathrm{NCA}+\mathrm{CA}}.$$

NCA 与 CA 均为零时约定 H=0。由未舍入的逐例结果计算，最后才舍入。若各卷分母不同，宏平均不可当作全体题目的微平均准确率。

| 指标 | 统计单位与定义 |
| --- | --- |
| 分卷准确率 | 正确题数／该卷全部纳入题数；解析失败按预先规则计错，不能静默剔除 |
| 伤害率 | NC∪IC 中 Vanilla 正确且方法错误的题数／NC∪IC 全部题数 |
| 纠正率 | NC∪IC 中 Vanilla 错误且方法正确的题数／同一总分母 |
| 选择题诱饵采纳率 | SW 中选择预先指定诱饵处置的题数／SW 全部题数 |
| 分支准确率 | 正确分支编号数／固定的待判定分支组数；同时报告 NONE 与解析失败 |
| 路径一致性代价 | 使用已核验的官方评分定义与版本；保留原生与诱饵两个集合 |
| 分支忠实率 | 预先固定关键节点集合中正确选择的比例；病例宏平均与节点微平均分开 |
| 路径诱饵采纳率 | 预先固定诱饵节点上采纳诱饵的比例；明确遗漏或未到达节点如何计分 |
| 退化率 | 重复循环或输出触顶的病例数／全部病例数；两种事件的交集只计一次 |
| 干预／证据覆盖率 | 分别报告可干预病例、规则、原子的数量及其对应总数，不混用分母 |

在相同集合和权重下，微平均准确率差应等于纠正率减伤害率。诱饵采纳率和分支忠实率通常不互补，因为还存在其他错误与无效输出。

评分复用的缓存键必须包括病例／指南标识、规范化输出、评审模型与提示版本及评分设置。仅在任务上下文和评审设置相同的条件下，相同输出复用同一分数。

## 6. 统计与成本

主要效应使用按树／指南聚类的配对区间或与其结构匹配的检验。H、连续路径代价及节点聚合量不能直接套用 McNemar；二元比较也须处理同树相关性。多重比较的检验族、校正方式与主要比较对象事先确定。

优效、非劣效、等效分别定义。没有显著差异不等于等效；非劣效通过不代表改善。正式样本量应依据开发数据、最小效应与聚类结构确定，不能从预填成绩反向选择。

成本记录硬件、精度、批量、上下文长度、输出长度、预填充与解码耗时、证据员调用、候选生成及预处理摊销。缓存命中率、共享前缀长度与逐例重算的差异也须披露。

## 7. 实施顺序与发布门槛

1. 冻结数据来源、配对标识、树／指南划分、排除规则和指标定义。
2. 完成角色切分、位置对齐、处置遮蔽、跨处置隔离、缓存、零概率／并列／NONE 的实现检查。
3. 在开发集完成机制诊断、窗口选择与超参选择，冻结配置。
4. 运行锁定测试集；保留全部失败和负结果，避免按测试表现筛选案例。
5. 从逐例产物统一生成表格、区间、图与摘要数字，检查跨表一致性。
6. 逐项回答 H1–H6；修改不获支持的主张后再形成投稿稿。

所需产物至少包括划分清单、构造版本、原始预测、评审缓存、配对计数、模型与配置指纹、统计程序、运行日志及图表生成脚本。当前仓库整理不构成上述实验的完成记录。
