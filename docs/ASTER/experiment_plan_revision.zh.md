**版本：2026-10-31。** 本计划取代此前以规则键平移为中心的执行器搜索。实验按瓶颈顺序推进：先证明模块三存在有效算子，再修复模块二的路径判断，最后在已验证的算子与头上研究模块一。新实验均为待运行；43 例仅作为开发诊断。

## 1. 实验治理

1. 已从 PR #42 溯源 43 例确认批次：MEGA-CDP revision `8f058c88ce1ed43693785b435ad0ff99907a2890` 的 `train_val` 内部确认集，指南 `665` 的 18 例和 `1310` 的 25 例，合计 43 例、2 来源簇。生成程序 `experiments/aster_manuscript_clinical_20261030/cases.py` 保留原始 `vignette_cases.jsonl` 患者文本，将 `decision_trees.jsonl` 转换成规则表示，以 `case_paths.jsonl` 中的原始参考路径提供评分金标。43 例不是官方 `test` 子集，也不是人工年龄反事实三元组；训练用 34 三元组属于另一数据用途。原始病例文字和逐例预测未在公开分支发布。运行代码及公开聚合已核对，但尚未独立下载官方原始 JSONL 进行单例逐字对照。后续必须在数据可访问环境里导出至少一条 `mega:train_val:665:<path_id>` 的源记录、构造记录及文本/路径差分以完成逐例复核。
2. 将数据扩展到十余个独立来源簇；同源指南、近重复病例和反事实变体不得跨开发、校准、验证和测试划分。
3. 预注册主终点为预测路径下完整路径正确率；共同风险约束为错误接受率。次要终点包括终点正确率、关键分支全对率、决策点 logit 边际、覆盖率、延迟和显存。
4. 同一病例不同执行器采用配对比较，以指南来源簇为重采样单位；报告簇数、逐簇效应和留一簇敏感性。
5. 固定偏置网格、路径阈值、层头选择、等效界和停止规则。失败计入分母并单列，未运行不记为零。

## 2. 阶段一：模块三算子阶梯（金标路径）

固定金标完整路径、同一批 43 例、同一骨干与解码设置。

| 条件 | 操作 | 识别因素 |
|---|---|---|
| B0 | 零编辑（19/43） | 原始基线 |
| B1 | 金标文本裁剪并重新预填充（43/43） | 理想上界 |
| B1′ | 非路径规则替换为等长中性文本 | 内容干扰与序列长度 |
| B2 | 共享缓存内硬屏蔽全部非路径规则及后代子树 | 缓存复用下的上下文不可见性 |
| B2-s | 仅屏蔽路径组兄弟规则，不屏蔽子树 | 子树抑制增量 |
| B2′ | B2 加少量指南词元选择性重算 | 预填充污染能否修复 |
| B3 | 软偏置：非路径 −β、路径 +β，β∈{1,2,4,8} | 剂量—反应及过度聚焦 |
| B4 | 将 B2/B3 限制到层窗口和头子集 | 最小覆盖范围 |
| B5 | 在 B4 头上以键平移复现 B3 的打分位移 | 键平移是否为瓶颈 |

连续指标：第一个分支决策词元处的金标规则与最强兄弟 logit 差；逐层路径／非路径注意力质量；打分位移符号一致率；患者事实注意力变化；预填充、缓存、掩码、重算和生成分项延迟。

预注册判定：B2 在预设等效界内达到 B1，支持缓存内硬门控；B2 低于 B1 而 B2′ 恢复，则纳入选择性重算；只有全层全头或大 β 有效，则放弃稀疏头门控主张；B5 不能复现 B3，则停止调键方向。保留注意力汇聚词元，不屏蔽起始 token。

## 3. 阶段二：模块二失败分型与路径级判断

已确认 43 例批次来源；对其 12/43 完整路径正确所对应的其余 31 条错误路径逐例分型：A 决定性事实存在但漏读；B 需要时间窗、分期或阈值推导；C 条件回指祖先处置；D 金标依赖病历缺失的默认事实；E 规则结构穷尽但仍设置 NONE；F 代理标签或规则顺序造成先验偏置。这里的 31 是该批次中的错误路径数，不是另一份数据集的样本量；需先确认 43 个分析单位是独立病例还是含同源／反事实重复。保存证据句、原子条件、祖先历史、类别分数和错误传播深度，并检验 NONE 停止次数与合取项数的关系。

### 3.1 原子条件三值判定

将完整条件拆为原子条件，每个病例的每个原子只判定一次，输出 T（证据支持满足）、F（证据支持不满足）或 U（未知／证据不足）。按强 Kleene 三值逻辑组合：唯一一条规则为 T 时接受该规则；所有候选规则均为 F 时输出 NONE；其余情况（含 U、多个 T 或冲突）输出 ABSTAIN。结构穷尽且含“其他”分支的规则组不机械设置 NONE。接口失败和无效输入单独编码。

每个原子保存证据句、抽取值、单位、时间区间和计算步骤。阈值、时间窗及算术组合交由确定性计算器，避免重复判定同一条件。

### 3.2 类别偏置与校准

温度缩放不改变 argmax，不能修复 NONE 先验。先做代理标签置换和规则顺序置换，再在独立校准集拟合“类别（尤其 NONE）×深度”的可加偏置，使校正允许改变类别排序。无内容输入校准只作诊断。UNKNOWN 不得并入 NONE。

### 3.3 路径级推断

以约束路径搜索替代逐层贪心：只保留结构合法路径，按累计校准对数概率保留 top-k。并行比较层级选择性分类（只接受最深高置信祖先，后代交给骨干）和多路径边缘化。已接受祖先处置历史可作为独立对照输入；当前组候选处置仍屏蔽，且必须重新通过处置盲不变性测试。

弃权阈值优先控制错误接受率。报告风险—覆盖率曲线、错误接受率、NONE 误判率和完整路径正确率。来源簇不足时，不宣称保形风险保证。

## 4. 阶段三：预测路径、执行器与错误注入

交叉比较金标路径、预测路径、最深高置信祖先路径和 top-k 边缘化；执行器比较文本裁剪、缓存硬屏蔽、软偏置和零编辑。以 ε∈{0,0.05,0.1,0.2,0.3} 将门控替换为错误兄弟或提前停止，比较软门控与硬裁剪完整路径正确率的退化曲线。只有软门控退化显著更慢，才主张其对路径错误更稳健。

## 5. 阶段四：模块一方向与因果选头

仅在阶段一找到有效执行器后启动。默认方向为配对差分均值；谱投影、中心化协方差和 SEA 作为候选或诊断。报告谱／均值方向余弦、跨来源簇方向一致性、分半子空间重叠和在线打分符号一致率。若余弦接近 1 且行为效应无增量，谱步骤仅保留为一致性诊断。

方向目标从拟合差分改为最大化金标分支相对兄弟分支的决策边际，并约束非决策词元分布变化。充分性检验：在不适用规则键上加方向，观察是否转向目标分支。必要性检验：用 LEACE 擦除候选子空间，观察原生判断是否下降。选头流程为候选池建立、attribution patching 排序、实际编辑确认、留出集任务效应定夺。不得仅凭注意力热图或探针选择最终头。

## 6. 数据扩充、统计与退出条件

按路径构造最小对，覆盖分期、数值阈值、时间窗、否定、既往治疗、缺失信息和祖先回指；规则引擎核验结构与金标，人工复核自然语言语义。合成样本与真实病历结果分表报告。

二元配对结果报告不一致病例数及精确 McNemar 检验；连续决策边际报告配对差及来源簇自助区间；多条件比较预先指定主对照并进行 Holm 校正。43 例若只有极少不一致病例或来源簇不足，结论写为证据不足，不作等效判断。

| 阶段 | 核心运行 | 进入下一阶段条件 |
|---|---|---|
| 0 | 数据审计、失败分型、运行指纹复现 | 数据与标签可追溯 |
| 1 | 金标路径 B0–B5 | 找到接近裁剪的缓存内算子，或明确否定该路线 |
| 2 | 三值条件、偏置校准、路径级推断 | 完整路径改善且错误接受率不恶化 |
| 3 | 预测路径 × 执行器 × 错误注入 | 软门控稳健性有配对证据，或收窄主张 |
| 4 | 均值／谱／行为方向与因果选头 | 充分性与必要性检验支持行为方向 |

若所有缓存内算子均明显低于文本裁剪，优先考虑文本裁剪作为主方法，将缓存内门控作为负结果或效率探索；不得继续扩大方向搜索来掩盖执行器失败。
