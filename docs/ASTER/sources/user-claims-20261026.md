来源：2026-10-26 本次任务消息。表格仅规范 Markdown 排版，保留原意。

| 核心主张 | 支撑实验 | 证伪条件 |
| --- | --- | --- |
| 处置可见性会带偏分支判断 | 盲判/明判对照；熟悉、陌生和中性代号对照；闭卷置信度分层 | 中性代号下差距仍与熟悉诱饵相当，或跨模型、跨顺序无法复现 |

| 证据员带来额外收益而非替模型答题 | ASTER-self/full；Clerk-Note/Prune/Map/Fuse；覆盖率与噪声曲线 | ASTER-full 的增益全部来自规则执行器，或证据员错误率使其整体退化 |
