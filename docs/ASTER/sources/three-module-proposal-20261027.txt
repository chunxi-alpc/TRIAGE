我同意原 ASTER 偏复杂。复杂度主要来自把盲判、证据绑定、软否决和两种笔都塞进同一套注意力掩码。下面按你的思路拆成三个职责单一的模块（一判、一学、一调），先回答你点名的问题，再给完整框架和闭环。

原稿 §3 的数字都是预填，所以下面每个设计决定都绑定一个待检验的前提，并事先写好前提不成立时的预案。

## 0 先回答四个问题

**1. 模块一的输出放在哪里？放在模块三，不进模块二的子空间估计。**
- 模块二只用代码验证过的金标最小对。
- 模块一只以"在校准集上的输出分布"进入离线阶段，用来标定保形阈值和增益。
- 一句话分工：子空间学"怎么调、一个单位多大"；模块一决定"调谁、往哪边调、调不调"；LTT（Learn-then-Test，风险认证）决定"调几个单位"。理由见 §5。

**2. 匹配用什么模型？没有现成的"指南条件 ↔ 病历"蕴含模型，所以按原子类型分派核查器。**
- 数值和时间原子：抽取后用代码比较。
- 类别和否定原子：用 NLI 交叉编码器，或用骨干 LLM 逐条判定。
- 详见 §2.3。

**3. 怎么模仿 AdaSEKA？保留它的离线管线，换掉样本和在线算子。**
- 保留：对比三元组 → 谱分解 → 选头 → 专家。
- 换样本：改成"同一规则、只改患者决定性事实"的最小对。
- 换算子：从"放大投影"改成"沿子空间平移"。乘性放大在需要改判的病例上可能把注意力往反方向推（命题 B）；平移是均值匹配意义下的最小二乘最优编辑（命题 C）。

**4. 离线调整是否优于训练调整？论断要收窄。**
- 不主张分布内准确率必然更高。
- 主张四项按构造成立、训练按构造做不到的性质：可回退、伤害可认证、局部有界、估计量低维。
- 另有两项可检验的预测：不制造新先验、保留通用能力。见 §6。

方法名保留 ASTER，展开改为 *Action-blind Selection, Then Eigen-subspace Re-routing*（处置盲判 + 适用性子空间重路由）。

## 1 框架总览

**记号。** 沿用原稿的 $G,P,Q,O$、分支组 $g$、规则 $r=(I_r,C_r,A_r)$。另外约定：
- $k_j\in\mathbb R^d$：KV 头 $h$ 上 token $j$ 在 RoPE 之前的键（Qwen3 取 k_norm 之后）。
- Dec：决策位置。选择题是答案字母位置，路径任务是全部生成 token。
- $\bar q_{ij}$：并入相对 RoPE 旋转后的查询，使 $s_{ij}=\bar q_{ij}^\top k_j/\sqrt d$。

| 阶段 | 模块 | 输入 | 输出 | 依赖患者？ |
|---|---|---|---|---|
| 离线，每个模型一次 | 模块二（学） | 开发树上的最小对三元组 | 头集 $H^*$；每头每角色的平移向量 $\Delta_h^\rho$ | 否 |

## 2 模块一：处置盲判的适用性判定

### 2.1 遮蔽
- 用文本遮蔽，不再用注意力掩码：处置段替换为统一占位符，并删去问题和选项里的处置名称，单独做一次前向。
- NC/AC/IC/SW 四卷只差处置文本，所以模块一在这四卷上的输出按构造完全相同。这就是"处置盲"可检验的定义，可以写成单元测试。

### 2.2 条件编译（每份指南离线一次）
- 每个条件拆成带类型的原子：{变量, 运算符, 阈值, 单位, 时间锚点, 极性}。
- 类型分四种：NUM（数值阈值）、TIME（时间）、NEG（否定或"既往未用"）、CAT（类别、分期）。保留"且/或/否则"的逻辑结构。
- 两个数据源都有显式树结构，编译主要是规范化节点条件：MedGUIDE 来自 55 棵 NCCN 决策树 [cite:beeaee6a-2]；MEGA-CDP 经"指南→病例"流水线构造，并带参考路径 [cite:70171030-1]。

### 2.3 用什么模型匹配
先排除一类：SciFact、HealthVer 这类"医学事实核查"模型核查的是"声明 vs 文献"，不是"条件 vs 病历"，任务不对口。剩下的候选按原子类型分派：

| 原子类型 | 默认核查器 | 理由 | 备选 / 消融 |
|---|---|---|---|
| NUM、TIME | 骨干 LLM 在遮处置状态下做受限 JSON 抽取（取值、单位、日期、证据句号），再由代码比较 | 数值推理是 NLI 的弱项：NLI4CT 需要数值推理，蕴含任务上多数系统没有显著超过多数类基线 [cite:286507c4-1]；NLI4CT-P 又加入了干预和因果扰动 [cite:beeaee6a-1] | 让 LLM 直接判大小 |
| CAT、NEG（英文） | 证据句检索 + NLI 交叉编码器：通用 NLI 预训练的 DeBERTa-v3-large，再在 MedNLI 和 NLI4CT 上微调。MedNLI 发布在 PhysioNet [cite:a0bca124-3]，需按受限数据流程申请 | 临床 NLI 是最接近"条件是否被病历蕴含"的现成任务。否定、既往、家族史可先用 ConText 类规则做前置标注 | MiniCheck：770M 参数的 MiniCheck-FT5 达到 GPT-4 水平，成本约低 400 倍 [cite:c3f4bcc3-1]；但它不是医学领域训练的 |
| 中文原子、复合原子 | 骨干 LLM 逐条判定，采用 TrialGPT 的输出格式：解释、相关句位置、资格标签。TrialGPT 在 1,015 个患者-标准对上准确率 87.3%，接近专家 [cite:ac1adf61-1] | 缺少可靠的中文临床 NLI | — |

由此得到三个版本：
- **M1-self（默认）**：NUM/TIME 用代码，其余都由骨干 LLM 判定，不引入外部训练模型。用来回答"是不是外部模块替模型把题做完了"。
- **M1-ext**：英文 CAT/NEG 原子改用 MedNLI 微调的交叉编码器。
- **M1-oracle**：金标原子，作为上界。

全部原子在一次结构化调用里批量输出。

### 2.4 聚合与校准
$$\pi_a=\sigma\!\big(z_a/T_{\mathrm{type}(a)}\big)\tag{1}$$
$$m_r=\textstyle\prod_{a\in C_r}\pi_a\ (\text{且}),\quad m_{\text{否则}}=\prod_{r'\ne\text{否则}}(1-m_{r'}),\quad m_{\textsc{none}}=\prod_{r\in g}(1-m_r)\tag{2}$$
$$p(r\mid g)=\operatorname{softmax}_{r\in g\cup\{\textsc{none}\}}\big(w_1\log m_r+w_2\log p_{\text{blind}}(r\mid g)\big)\tag{3}$$
$$\Gamma_g=\{r:\ p(r\mid g)\ge 1-\hat q_\alpha\}\tag{4}$$

- 式 (2) 里"或"条件用 noisy-OR：$1-\prod_a(1-\pi_a)$。
- $p_{\text{blind}}$ 是遮蔽提示中"[G_g: R?]"的受限解码分布，即模型的整体判断。$w_1,w_2$ 和各类温度只是几个标量，在开发集上拟合。
- 保形集在可交换性下满足 $P(y\in\Gamma_g)\ge1-\alpha$，这是分布无关、有限样本的保证 [cite:e2396198-1]。已有研究专门考察过 LLM 选择题在跨学科场景下可交换性是否成立 [cite:e2396198-2]。因此校准集和测试集按树划分，保证在"树可交换"的意义下成立。

### 2.5 输出

| 层级 | 字段 | 去向 |
|---|---|---|
| 原子 | 状态（满足/违反/未知）、$\pi_a$、证据位置、核查器类型 | 审计、错误归因 |
| 规则 | 匹配度 $m_r$；证据覆盖率 $\kappa_r$；决定性原子 $D_r$ | $m_r$ 进入式 (3)；其余用于审计和"缺失信息清单" |
| 组 | $p(\cdot\mid g)$（含 NONE）、间隔 $\delta_g$、**保形集 $\Gamma_g$** | **$\Gamma_g$ 进入模块三**；$\delta_g$ 只用于连续增益变体 |
| 路径 | 路径后验、被排除的子树 | 模块三据此压低整棵子树 |

**为什么没有"每条规则的置信度"。** 兄弟规则互斥，置信度本质上是组级概念，应该用 $\Gamma_g$ 表达，而不是给每条规则一个置信分。另外，若 $\sum_r m_r$ 明显偏离 1（两条都像，或都不像），说明指南重叠或信息缺失，这一组直接弃权。

## 3 模块二：离线构建适用性子空间（重点）

### 3.1 SEKA 原本怎么做，哪些能搬
SEKA 对对比提示得到的键做谱分解，学出"相关性子空间"，推理时按 $k'=k+gPk$ 编辑被高亮 token 的键 [cite:383b242f-1]。它的三元组有三种：
- 中性：只有上下文；
- 正：上下文配一个相关问题；
- 负：上下文配一个无关问题。

比较的是同一 token 片段在正、负提示下的键 [cite:383b242f-1]。AdaSEKA 学一组任务专家，推理时用免训练路由按提示语义把它们混合 [cite:383b242f-1]。

再看原文细节（§3.1、§3.3–3.4、附录 A–C）：
- 投影来自"中性 × 正/负"的未中心化互协方差做 SVD；
- 选头标准是正负键的平均 ℓ2 距离超过阈值；
- AdaSEKA 用最后一个 token 的查询与各专家奇异向量的对齐度做路由，每个专家约 200 例；
- 合成数据中，问题放在上下文之前。

管线可以直接搬，但下面三处必须改。

### 3.2 改动一：正、负、中性样本改为规则适用性最小对

| | SEKA | 本文 |
|---|---|---|
| 比较的 token | 答案片段 | 规则 $r$ 的处置段 $A_r$ 和编号段 $I_r$ |
| 正样本 | 相关问题 + 上下文 | 患者 $P^+$（决定性事实使 $r$ 适用）+ 问题 + 指南 |
| 负样本 | 无关问题 + 上下文 | 患者 $P^-$：只改决定性事实，使同组兄弟规则适用（兄弟硬负例） |
| 中性样本 | 只有上下文 | 患者 $P^0$：决定性事实换成等长的"未记录" |
| 顺序 | 问题在前 | 患者在前 |

**为什么必须患者在前。** 因果注意力下，键只依赖它前面的 token。按基准原有顺序（指南在前），规则键与患者无关，$k_j(P^+)\equiv k_j(P^-)$，对比恒为零。SEKA 把问题放在前面也是这个原因。它推理时（例如 CounterFact）用的却是"上下文在前、问题在后"，所以"患者在前构造、原生顺序推理"有直接先例。

**构造规则：**
- **R1 等长最小编辑。** 三份输入只在决定性槽位不同，分词后长度相同。差分因此不受位置和 RoPE 影响。
- **R2 代码验证标签。** 用与模块一共享的条件编译器，确认 $r$ 的适用性确实翻转，且组内恰有一条兄弟规则适用。
- **R3 兄弟硬负例。** 负样本不能是"无关患者"。要学的是兄弟规则之间的竞争，而不是"相关与否"。
- **R4 处置平衡。** 通过树内处置置换，让每条规则在正负两侧都出现，熟悉和陌生的处置各占一半。这一条是命题 F 的前提。
- **R5 按树隔离。** 只用开发树（MedGUIDE 10 棵、MEGA-CDP 40 份）。MedPIC-Bench 的配对反事实（受控改变患者信息，从而改变规则是否适用）[cite:beeaee6a-3] 与这里的最小对同构，正因如此只能作外测。

**能不能用已有数据？**
- 原料可以用：已有基准的树结构。
- 样本必须按上面的规则重新构造。原题不是最小对，内容、长度、位置混在一起，标签也是最终答案而不是规则是否适用。
- SEKA/AdaSEKA 的通用数据编码的是"与问题相关"，不是"兄弟规则谁适用"，只作基线。

**规模。** SEKA 每个专家约 200 例；ITI 也只用几百个样例就能定位方向 [cite:c3f4bcc3-2]。计划每个角色 1,000 组，并报告 $N\in\{100,\dots,1600\}$ 的学习曲线。

### 3.3 改动二：用配对差分做谱估计
$$d_j=k_j(x^+)-k_j(x^-),\quad \Omega_h^\rho=\tfrac1N\textstyle\sum_j d_jd_j^\top,\quad U_h^\rho=\text{top-}r\ \text{eigvecs}(\Omega_h^\rho)\tag{5}$$
$$\tau^c=U^\top\mathbb E[k_j\mid c],\ c\in\{+,-,0\};\qquad \Delta_h^\rho=U(\tau^+-\tau^-)\tag{6}$$

- **为什么不用未中心化互协方差。** 它的主方向被正、中性两侧共有的能量主导，例如键的均值方向。兄弟规则共用同一模板，这类方向会对任何规则同等放大，区分不了兄弟。配对差分则在对内消去了内容、处置文本和位置。
- **秩 r。** 取分半主角余弦均值 ≥0.9 的最大 r，预期在 1–4 之间。对默认的平移算子，U 只用于给 Δ 去噪和做诊断。
- **中性样本的用途。**
  - 把"患者在场效应" $\tfrac12(\tau^++\tau^-)-\tau^0$ 与"适用性效应" $\tau^+-\tau^-$ 分开，在场效应主导的头剔除。
  - 检查编码是否双向，即 $\tau^+-\tau^0$ 与 $\tau^--\tau^0$ 是否大致反向。

### 3.4 选哪些层、哪些头
SEKA 按原始 ℓ2 距离选头，有两个问题：受各头键范数影响；只看"键里有没有编码"，不看"决策位置读不读"。这里用两个量：

$$d'_h=\big\|\Sigma_w^{-1/2}(\tau^+-\tau^-)\big\|,\quad \rho_h=\frac{\mathbb E_{i\in\text{Dec},\,j\in T}[\bar q_{ij}^\top\Delta_h]}{\sqrt d\,\sigma_h},\quad S_h=d'_h\cdot\max(\rho_h,0)\tag{7}$$

- $d'_h$ 衡量**编码**：标准化后的正负分离。
- $\rho_h$ 衡量**可读性**：在推理所用的顺序下，单位编辑让决策 logit 移动多少个标准差。GQA 下对共享该 KV 头的查询头取平均。
- 按 $S_h$ 取前 $K$ 个头，$K\in\{16,32,64\}$ 交给 LTT 认证。

§3 的敲除窗口**不参与选头**，只用来检验两套独立方法选出的头是否重合；不重合时改用中介效应排序（预注册）。需要报告：Qwen3-8B 上 36 层 × 8 个 KV 头的 $S_h$ 热图，以及 $H^*$ 与敲除窗口的重合率。

### 3.5 几个专家
**判定规则。** 候选划分有四种：角色（ACT/ID/COND）、语言、原子类型、来源。对每种划分算重合度 $O(a,b)=\|U_a^\top U_b\|_F^2/r$：
- $O\ge0.8$ 且合并后留出集上的可读性不下降，就合并；
- 否则拆开。

这实质上是偏差—方差权衡：合并降低估计方差，但引入与子空间错位成正比的偏差。

**预期结果（待检验）：** 1–2 个专家。ACT 和 ID 可能需要分开；原子类型由模块一处理，不必编码进规则键，大概率可以合并。

**路由：用可观测变量，不学路由器。** AdaSEKA 要学路由，是因为它不知道当前是哪类任务。这里角色和语言都已知，路由误差按构造为零。而且平移的效应 $g\,\bar q^\top\Delta$ 本身就逐个位置地选择查询，查询自适应已内含其中。

**附加检验：熟悉度是否在冒充适用性。** 在 Decoy-2×2 上，比较"熟悉处置"和"陌生处置"在处置段结尾 token（两种条件下是同一个 token）上的键，计算以适用性单位计的位移：
$$\varphi=\frac{u^\top(k_{\text{fam}}-k_{\text{unfam}})}{u^\top(\mu^+-\mu^-)}$$
- $\varphi>0$ 且显著：TLBS 在键层面有直接证据，沿 $-\Delta$ 压低正好抵消它，单专家就够。
- 否则：测量 $g^-$ 饱和时诱饵注意力质量的残余比例，残余超过 20% 才增设"去熟悉化"专家。

### 3.6 调多少：以"一次负→正位移"为单位
在线算子是 $k'=k+g\Delta_h$。
- **$g=1$ 的含义：** 在构造坐标系里，它恰好把"不适用"类键的期望坐标移到"适用"类的均值。Representation Surgery 证明，在两类均值相等的约束下，最小二乘最优的仿射引导就是按类均值差平移 [cite:a0bca124-1]（其命题 4.1）。所以 Δ 是估计出来的量，不是超参数。在原生顺序下，$g=1$ 读作"叠加一个适用性单位"。
- **单位跨头可比。** 各头的 $\|\Delta_h\|$ 不同，但单位一致，所以全局一个 $g$ 就有意义。SEKA 的 $g$ 乘的是尺度各异的 $Pk$，没有这一性质。
- **带符号增益：**
  - $g^+\in\{0.5,1,1.5\}$，控制在 1 附近，防止过冲导致退化；
  - $g^-\in\{1,2,4\}$，大于 1 表示越过"不适用"原型、逼近删除。
- **设定点变体（作消融）：** $k'=k+gU(\tau^+-U^\top k)$。模型自己已判为适用时，编辑自动为零。但它要求患者在前推理。

## 4 模块三：在线按适用性重路由

### 4.1 增益规则

| $\Gamma_g$ 的情形 | 增益 $g_r$ |
|---|---|
| $\Gamma_g=\{r^*\}$，且 $r^*\ne$ NONE | $r^*$ 取 $+g^+$，其余取 $-g^-$ |
| $2\le\lvert\Gamma_g\rvert<\lvert g\rvert$ | 集合外取 $-g^-$；集合内取 0（犹豫时不放大任何规则） |
| $\Gamma_g\supseteq g$，或 NONE $\in\Gamma_g$ | 全为 0，这一组精确回退到原模型 |
| 上游分支被排除 | 整棵子树取 $-g^-$ |

### 4.2 编辑
$$k_j\leftarrow k_j+g_r\,\Delta_h^{\rho(j)},\qquad h\in H^*,\ j\in A_r\cup I_r\tag{8}$$

- 编辑在 RoPE 之前施加。
- 保持基准原有顺序：编辑加在已缓存的指南键上，后续的病历、问题和作答位置都读到编辑后的键，指南 KV 仍可在患者之间共享。
- 选择题可选扩展：与 $A_r$ 字符串匹配的选项 token 一并编辑。
- 只改键，所以与 FlashAttention 兼容；SEKA 报告每例只增加约 0.03 s [cite:383b242f-1]。可以直接在 SEKA 开源的 key hook 上替换算子。

### 4.3 认证
- 对象：$\lambda=(\alpha,g^+,g^-,K)$，共 ≤24 组。
- 方法：在校准树上检验 $H_0:\text{harm}(\lambda)>\varepsilon$，用 Bonferroni 或预先固定顺序的检验；可同时控制退化率 Deg ≤3%。
- 选择：在通过认证的配置里，取冲突指标最高的一个。
- 保证：LTT 把风险控制转化为多重检验，给出有限样本保证 [cite:a0bca124-2]，即 $P(\text{harm}(\hat\lambda)\le\varepsilon)\ge1-\delta$。
- 为什么必须标定：ITI 也报告过，干预强度在两个目标之间存在权衡 [cite:c3f4bcc3-2]。
- 可行性：$\lambda=0$ 时方法就是原模型，伤害按定义恒为 0，不用检验也能入选，所以可行集永不为空。

### 4.4 算法

> **算法 1**
>
> 离线：
> ① 按 R1–R5 生成患者在前的三元组；
> ② 收集 pre-RoPE 键，按式 (5)(6) 得到 $U$、$\tau$、$\Delta$；
> ③ 按式 (7) 选头，判定专家数，计算 $\varphi$；
> ④ 在校准树上运行模块一，拟合温度、$w$、$\hat q_\alpha$；
> ⑤ 用 LTT 认证 $\lambda$。
>
> 在线：
> ⑥ 模块一给出 $\Gamma_g$；
> ⑦ 查表得 $g_r$，按式 (8) 编辑键；
> ⑧ 正常解码。

## 5 模块一的输出为什么进模块三

1. **对象不同。** 模块二是模型的属性，估计时还没有任何测试患者；模块一的输出是病例的属性。把后者放进前者，只有两条路，都不成立：
   - 每例重新估计子空间，那就不再是离线；
   - 跨患者汇总，那么对患者的依赖被平均掉，正好落入原稿性质 1 的跷跷板。
2. **误差会叠加。** 如果用模块一的伪标签构造正负样本，模块一的错误会同时决定"往哪调"和"调谁"，两处错误相关并相互放大。金标最小对估计的是模型自己如何编码适用性。
3. **可辨识、可模块化。** 两者分开后，可以区分"判错"和"没调动"两类失败；升级模块一也不必重估子空间。
4. **接口匹配。** $\Gamma_g$ 的保证是"金标规则被压低的概率不超过 α"，这正是模块三需要知道的；子空间只回答"怎样压低"。

唯一的离线耦合是校准，而且只用模块一的输出分布。

这一选择本身可以证伪，设三组消融：
- D1：用模块一的伪标签构造子空间；
- D2：按置信度分层构造子空间；
- D3：本文做法。

预测：D1 的 $d'$ 更低，且在模块一判错的病例上伤害显著更高；D2 没有收益。

## 6 理论：在本任务的部署约束下，离线调整为什么优于训练

**论断范围。** 引导向量的效果因输入而异，有些概念在分布外会失效 [cite:e2396198-3]。MedGUIDE 也比较过"上下文给指南"和"继续预训练"两条路线 [cite:beeaee6a-2]，按我的阅读，其结论部分认为两者改进都有限。所以下面只论证结构性性质，不预设准确率高低。

**命题 A（患者无关目标导致跷跷板）。** 即原稿性质 1。它说明目标必须在线确定、且依赖患者。

**命题 B（符号安全）。** 设 $u$ 为单位适用性方向，$\bar q_{ij}^\top u>0$ 的查询称为"适用性读取型"。
- (i) 平移：$\Delta s_{ij}=g\|\Delta\|\bar q_{ij}^\top u/\sqrt d$，与 $k_j$ 无关。因此对这类查询，被放大规则的注意力质量随 $g^+$ 单调不减，被压低规则的随 $g^-$ 单调不增；$g^-\to\infty$ 时后者趋于 0。与 $u$ 正交的查询不受影响。
- (ii) SEKA 式乘性编辑：$\Delta s_{ij}=g(\bar q^\top u)(u^\top k_j)/\sqrt d$。若模型把规则 $r$ 编码为不适用（$u^\top k_j<0$），则对任意 $g>0$ 都有 $\Delta s<0$：放大反而压低了模块一要救的规则。
- 需要改判的病例正是干预最有价值的地方，所以乘性形式不适合本任务。

**命题 C（最小编辑）。**
- (a) $\arg\min_\Delta\{\|\Delta\|:U^\top(k+\Delta)=\tau\}=U(\tau-U^\top k)$，这就是设定点变体。
- (b) 在均值匹配约束下，最优仿射编辑是按类均值差平移 [cite:a0bca124-1]；限制在 $\mathrm{span}(U)$ 内即得 $\Delta=U(\tau^+-\tau^-)$。

**命题 D（局部、有界、可回退、可行）。**
$$\mathrm{KL}(a_i\|a'_i)\le\operatorname{osc}_j\Delta s_{ij}\le(g^++g^-)\max_j|\bar q_{ij}^\top\Delta_h|/\sqrt d$$
- 证明：$\log(a_{ij}/a'_{ij})=-\Delta s_{ij}+\log\sum_k a_{ik}e^{\Delta s_{ik}}\in[-\operatorname{osc},\operatorname{osc}]$。
- 不在目标集合里的 token、不在 $H^*$ 里的头，计算完全不变。
- $g\equiv0$ 即原模型，所以任意 ε 都可达到。
- 训练得到的是单个模型，没有逐例的"关闭开关"。

**命题 E（低维、可检验的估计量）。**
- 平移只需要一阶矩：$\sin\angle(\hat\Delta,\Delta)\le\|\hat\Delta-\Delta\|/\|\Delta\|=O_p\big(\sqrt{\operatorname{tr}\Sigma_d/(N\|\Delta\|^2)}\big)$。
- 子空间误差由 Davis–Kahan 控制：$\|\sin\Theta\|\lesssim\|\hat\Omega-\Omega\|/\delta_r$。
- 两者都只依赖头维度 $d=128$ 和信噪比，与模型规模无关，并可用分半稳定性直接检验。

**命题 F（处置置换不变）。** 在 R4 的平衡构造下，Δ 对兄弟规则间的处置置换不变，因此不携带任何"条件→处置"关联。
- 反过来，在真实指南数据上做 SFT/DPO，目标函数不具这种不变性：模型可以靠记忆关联降低损失，等于写入新的先验；指南一更新，这些先验就成了新的诱饵。
- 这与"微调引入新知识会线性提高幻觉倾向"的发现方向一致 [cite:c3f4bcc3-3]。
- 处置平衡的反事实 SFT（CF-SFT）能消除这一劣势，所以把它列为最强训练基线。

| 性质 | 离线算子 | SFT / DPO / 继续预训练 |
|---|---|---|
| 逐例回退（D） | 有 | 无 |
| 伤害认证必然可行（D + LTT） | 有 | 只能事后检验单一模型 |
| 局部有界（D） | 只动 $H^*\times T$ | 全局改动 |
| 估计量维数（E） | 每头每角色一个 d 维向量 | 百万级参数 |
| 处置置换不变（F） | 按构造成立 | 普通 SFT 不成立，CF-SFT 近似成立 |
| 分布内准确率 | 不预设 | 不预设，可能更高 |

## 7 动机—方法—实验闭环

**动机三句话：**
1. 熟悉的处置会替模型选分支（TLBS）。
2. 决策位置在中层读取处置段，覆盖了原本正确的分支读数。
3. 与患者无关的干预必然出现跷跷板。

由此推出三条：判断要盲（模块一）；目标要依赖患者（模块一 → 模块三）；算子要是"让规则在模型眼里变得适用或不适用"的最小编辑（模块二）。

| 前提 | 设计决定 | 可证伪预测 | 不成立时的预案 |
|---|---|---|---|
| P1 盲判优于明判 | 文本遮蔽 | 模块一在四卷上输出相同；SW/CS 上不低于明判 | NC/IC 上明判更好的情形，由保形集吸收 |
| P2 患者在前时，键编码适用性 | 用最小对估计 Δ | 存在 $d'$ 显著高于置换零分布的头 | 改用查询侧方向 $\mathbb E[\bar q_i\mid i\in\text{Dec}]$；仍不行就退为 logit 偏置 |
| P3 原生顺序下决策位置可读 | 原生顺序推理、共享缓存 | 被选头的 $\rho>0$ | 改为患者在前推理，并启用设定点变体 |
| P4 熟悉度冒充适用性 | 专家数 | $\varphi>0$ 时单专家足够 | 压低后残余 >20% 才增设专家 |
| P5 跷跷板（命题 A） | 模块一输出在线使用 | D3 优于 D1、D2 | — |
| P6 值通道携带"合理性" | 只编辑键 | 诱饵采纳率随诱饵注意力质量下降 | $g^-$ 饱和后仍比 Gold-Prune 高 5 分以上，就对值向量做同法平移 |
| 命题 B–D | 平移 + LTT | 改判子集上平移优于乘性；实测 KL 不超过上界；认证覆盖率 ≥1−δ | 改用分层校准 |
| 命题 F | "离线优于训练"的论断 | 更新划分和能力保持上占优 | 若 CF-SFT 也不输，论断收缩到命题 B–E |

### 实验
- **RQ1 现象。** 沿用原稿 §3，新增键层面的 $d'$、$\rho$、$\varphi$；诊断的产物直接被模块二使用。
- **RQ2 模块一。** 各卷分支准确率、按原子类型的准确率、ECE、保形覆盖率与平均集合大小；比较 self、ext、oracle 三版。
- **RQ3 模块二。**
  - 学习曲线；
  - 通用 SEKA 专家 vs 任务专家；
  - 未中心化互协方差 vs 配对差分；
  - 选头：ℓ2、$d'$、$d'\times\rho$、随机；
  - 专家划分的重合检验。
- **RQ4 主结果。** 三个基准沿用原稿指标，并单列 MedPIC 中"收窄或撤销警示"子集，这是该基准报告的最难情形 [cite:beeaee6a-3]。关键对照都用模块一给出的目标、只换算子：
  - SEKA / AdaSEKA；
  - logit 偏置；
  - 两阶段附注 / 裁剪；
  - 选择题上的输出层融合 / 映射。

  这样可以把"算子"的贡献和"目标"的贡献分开。
- **RQ5 离线 vs 训练。** 训练基线用同一批开发数据：普通 SFT、CF-SFT、DPO、继续预训练、LoFiT 式头级微调。评测三方面：
  - 分布内；
  - 指南更新划分：用"训练时见过的旧处置"的采纳率衡量新先验；
  - 通用能力保持。

  另报数据效率曲线。对训练模型也用 WiSE-FT 插值 + LTT 做伤害认证，这是对它最公平的比较。
- **RQ6 理论预测。** 改判子集上的符号安全、KL 上界、认证覆盖率、精确回退的单元测试，以及消融 D。
