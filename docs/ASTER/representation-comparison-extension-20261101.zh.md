# 忠实推理假设与必要对照补充

2026-11-01。本补充在部分开发结果可见、新确认集尚未运行时固定；沿用现有数据清单、骨干、三个候选层及秩4，不新增来源或病例，不重新训练已完成配置。

## 要检验的算法假设

提前把适用性判断变成唯一分支，会丢失不确定性并限制后续纠错。完整指南表示与处置盲表示可能存在互补：前者保留更多语境，后者减少候选终点处置的干扰。当前内部干预在分支查询的一个低秩子空间中结合两者，尝试提高条件判断准确率，同时保留处置不变性和条件敏感性。

不能从“保留更多信息”直接推出内部干预优于上下文方法，也不能把额外监督的收益归于编辑位置。直接盲判后查表本身具有终点处置交换下的分支不变性；完整方法必须在保持该性质的同时提高判断正确率。

模块和核心损失不变。补充以下三个对照，用同一开发集选择新增学习配置，在新确认结果可见前全部冻结。

## 对照

| 名称 | 如何使用处置盲信息 | 训练 | 用途 |
|---|---|---|---|
| blind_lookup | 每个节点比较T/F概率，沿选定分支走到终点，再查当前指南处置 | 无 | 直接判断后只保留适用分支的强基线 |
| context | 把当前节点的T/F/U概率写入问题；只通过上下文文字传入 | 与普通低秩对照相同的模块、数据、损失、轮数 | 检验内部传入连续表示是否比上下文传入判断有额外收益 |
| blind_readout | 从同一层处置盲表示学习修正T/F分数，再沿分支查表 | 32,777参数，使用相同训练节点与优化设置 | 排除“只是多训练了一个分类器”的解释 |

blind_lookup和blind_readout都在Y/N之间作出选择，U保留诊断，不用拒答来人为降低基线成绩。原有含U停止门控的预测裁剪结果保持原协议，已有开发原指南76/100不重跑；不把两个协议混称为同一个条件。

context使用完整指南，只在当前决策时向问题追加“该节点T/F/U概率，判断可能出错，应结合病历与指南作决定”。只使用实际到达节点，不读取金标路径。此前已经生成的路径作为决策前缀。普通低秩模块只读取完整输入表示，不直接接收处置盲隐藏向量。临时上下文及编辑KV不写回持久缓存，选中的分支由干净原模型继续编码。处置交换不会改变追加的判断文字。

context与完整方法使用相同数量的训练参数及相同损失形式。它具有普通低秩模块提供的相同训练能力，因此不是拿训练后的内部方法与未经训练的提示进行比较。该比较中，文字只传递T/F/U判断，不能声称覆盖了所有可能的上下文证据表达方法。

blind_readout结构为4096→8的无偏置线性映射、tanh、8→1线性输出，共32,777参数。输出修正量δ以(+δ,−δ)加到原盲判T/F logits，初始化为零修正。训练使用同样200例和原年龄最小对、相同节点、AdamW学习率0.001、3轮、累计8例、梯度裁剪1；交叉熵加0.1倍正确盲判节点的保持KL和0.001倍归一化分数修正幅度。处置交换下输入完全相同，JS项恒为0。分类器幅度项约束logit修正，不能与内部表示幅度直接比较。

新增两个训练配置只使用完整方法在开发集选定的层，不新增层搜索。各自按原指南路径与终点联合正确、交换一致率、较小修改幅度选择检查点。所有配置冻结后才运行新确认100例。

## 如何解释结果

最终增加“盲判查表正确／错误×完整上下文零干预正确／错误”的病例交叉表，报告完整方法在四组中的正确数，并保留配对纠正／退化和来源等权统计。交叉表按完整路径计数；两条路径都错时，也可能存在各节点上的互补，不能直接称为产生了新的推理能力。

超过blind_lookup支持保留纠错机会的价值；超过context支持当前内部结合方式相对当前文字表达方式的增量；超过blind_readout说明收益不只来自监督训练一个更好的盲判分类器。三个比较分别回答不同问题，不能相互替代。

截止补充制定时，开发原指南／交换指南联合正确数为：零干预82／79，概率融合85／83，第18层完整方法91／94，第24层88／84。它们属于开发结果，第30层和独立确认尚未完成，不据此宣称内部干预已获验证。
