# ASTER 方法变体

[主页](../../README.md) · [模块与训练目标](method-clarifications.zh.md) · [实验索引](experiments.zh.md) · [中文主稿](manuscript.zh.md)

ASTER 有两条方法路线：**表示编辑**修改选中注意力头的输出，**分数读出**从冻结表示中计算判断分数的修正量。P0–P3 是实验安排，`repair-v2` 是 ASTER-CR 使用的数据修复版本。

本页保留方法动机、公式和实现差别。前七节阶段数字对应11月8日及之前记录；11月9—10日后续方法见第8节，最新完成状态统一见[实验总表](experiments.zh.md)。

## 表示编辑

### 1 起始闭式版本

**为什么这样设计。** 在完整输入中定位能传导处置／背景变化的头，再估计干扰与信号方向，尝试在这些头上擦除干扰。后续表示编辑版本沿用M1定位、M2估计子空间、M3执行编辑的分工。

**模块与公式。** M1用归因预筛和双向精确修补选择头集合；M2估计$`M_h^q=\mathbb E[\delta_h^q(\delta_h^q)^\top]`$，形成干扰基$`U`$与信号基$`S`$。省略头下标，M3令：

```math
(I-SS^\top)U=Q\Sigma R^\top,\quad
K=\{i:\sigma_i\ge\sin\theta_{\min}\},\quad \bar U=UR_K,
```
```math
D_{\rm hard}=\bar U\Sigma_K^{-1}Q_K^\top,\quad
E=I-D_{\rm hard},\quad z'=z-D_{\rm hard}(z-\mu).
```

保留集合为空时$`D=0`$。非空时，$`E\bar U=0`$、$`ES=S`$、$`E^2=E`$。信号保持针对纯信号方向；混合输入的信号坐标及最终预测由实际编辑结果决定。完整推导在[闭式快照](manuscript-closed-form.zh.md)。

**实现和实验。** [operators.py](../../experiments/aster_closed_form/operators.py)以`N`、`B`存储低秩因子，在线执行`z-NB(z-mu)`。本阶段经历已有构造数据整理，后续比较沿用[现成数据版](../../experiments/aster_closed_form/EXISTING_DATA.zh.md)：1,290输入、1,053配对，拟合／开发／测试输入561/119/610。

能量目标0.90/0.95、每类秩上限4/8/16和夹角15°/30°/45°共18配置；开发主指标及原输入准确率并列，按既定规则选0.95、4、45°，51头、筛选后总秩120。其未筛选基总秩244。

**结果与继承。** 主测试四类配对宏平均97.08%，与单路校准同判；全部610输入603正确。432自主路径401正确，完整阅读404。头定位修补87.71%/84.11%，未筛选干扰分量63.08%/69.34%，筛选后正交分量11.88%/11.85%。下一版保留头、基、参考均值及判定位置，修改方向筛选方式。

### 2 连续衰减版本

**为什么修改。** 硬阈值会直接舍弃接近信号空间的方向，机制分析显示筛选后效应明显下降。因此用连续权重替代删除，保留同一组基。

**模块与公式。** 只改变M3。设$`\tau=\sin45^\circ`$，沿用上节SVD：

```math
D_{\rm soft}=UR\,\operatorname{diag}\left(
\frac{\sigma_i}{\max(\sigma_i^2,\tau^2)}
\right)Q^\top,\qquad z'=z-D_{\rm soft}(z-\mu).
```

高夹角方向与旧算子相同，小夹角方向部分衰减，零夹角编辑为零。仍有$`D_{\rm soft}S=0`$，但一般不再完全擦除全部干扰方向，也不再幂等。244方向均保留，按自身擦除比例求和为166.834；[实现](../../experiments/aster_closed_form/soft_angle.py)

**实验和结果。** 使用同一1,290输入、1,053配对，补569历史输入、开发／测试A/P联合修补及432自主路径。主测试宏平均与硬筛选同为97.08%，逐输入602/610，比硬筛选少1例。路径399/432，相对完整阅读纠正4、新增错误9。A/P修补为9.98%/20.67%，改动效果因类型不同。[完整结果](../../results/aster_soft_angle_20261106/REPORT.zh.md)

**下一版继承。** 继续复用同一M1/M2，保留硬／软方向分析作为对照，转而检查未筛选方向和参考中心的影响。

### 3 未筛选方向与参考对照

**为什么修改。** 未筛选正交分量保留较多修补效应，但以全局均值为中心可能改变病例共同分数。因此固定投影，单独比较参考。

**模块与公式。** M3使用全部干扰基，$`D=UU^\top`$：

```math
z'_{\rm mean}=z-UU^\top(z-\mu),\qquad
z'_{\rm ref}=z-UU^\top(z-r(x)).
```

参考$`r(x)`$来自无干预模型读取同事实参考提示。此投影的信号变化取决于干扰与信号空间的重叠。参考等于当前表示时固定算子编辑为零。

同事实参考由已有`boundary_guideline`和标注的附加背景删除规则构成。C/F各侧保留自己的条件、定义和事实；不同提示的参考激活计算一次后冻结。它与后续“原病历＋当前及祖先条件”的辅助参考是不同提示。[实现](../../experiments/aster_closed_form/reference_anchor.py)

**实验和结果。** 同一1,290主输入、1,053对及569历史输入；没有自主路径评测。610测试输入中，全局均值宏平均77.56%，同事实编辑96.95%，直接参考96.95%；新增错误92/6/6。仅看实际改参考的406输入，全局均值与同事实新增错误为51/6。同事实编辑与直接参考在610输入上同判，379个输入分数不同。[完整结果](../../results/aster_reference_anchor_20261106/REPORT.zh.md)

**下一版继承。** 保留全部244方向及输入相关参考思路，引入映射、门控和任务监督。直接参考继续作为对照。

### 4 可学习M3：辅助参考与自身参考

**为什么修改。** 固定算子的局部几何性质不能保证任务判断改善。同事实参考也未带来超过直接参考的分类收益。因此固定M1/M2，让M3学习最终标签需要的编辑。

**模块与公式。** 固定$`U_h`$，定义：

```math
c_h=U_h^\top z_h,\quad t_h=W_hr_h,\quad
g_h=\sigma(a_h^\top[c_h;t_h]+b_h),\quad
z'_h=z_h+g_hU_h(t_h-c_h).
```

辅助参考来自原病历、原当前条件、原祖先条件，不提供祖先分支答案；自身参考取完整输入的无干预头激活。两者参考均冻结，完整输入按层在线编辑。$`W_h`$初始化为$`U_h^\top`$，门控0.01，共31,771参数。单节点损失为CE、0.1倍原模型正确指示下的KL、0.001倍相对编辑量；不含JS。KL与其他项一起按节点／病例平均。[映射与门控](../../experiments/aster_learnable_m3/m3.py)、[训练与评分](../../experiments/aster_learnable_m3/run.py)

**实验。** 原版MEGA-CDP 200训练、100开发、7,458测试。两种编辑器各3轮，均选择第1轮，开发路径准确率90%。共五种方法、37,290条完整路径预测，均已完成。

| 方法 | 正确／7,458 | 准确率 | 相对完整阅读纠正／新增错误 |
|---|---:|---:|---:|
| 完整阅读 | 7,068 | 94.77% | 0/0 |
| 原固定硬筛选M3 | 7,045 | 94.46% | 22/45 |
| 辅助参考M3 | 7,072 | 94.82% | 6/2 |
| 自身参考M3 | 7,068 | 94.77% | 3/3 |
| 直接参考 | 6,445 | 86.42% | 137/760 |

辅助参考相对旧闭式净增27例，相对完整阅读净增4例；后者P0来源重采样95%差值区间为[-0.0138,+0.1300]个百分点。结果来自[已完成全量记录](../../results/aster_learnable_m3_20261106/comparison.json)及[P0复算](../../results/aster_m3_followup_20261107/p0/paired.json)。

**下一版继承。** 直接加载已有两种检查点和五方法预测，继续复用51头与基；追加节点、迁移、选头及配对训练对照。信号基用于记录编辑引起的坐标变化。

### 5 N/S/NS 配对编辑

**动机。** 辅助参考 M3 在 7,458 条测试路径上净增 4 例正确，需要检验编辑空间与配对监督的作用。

**方法。** 主配置复用既有 51 头及 M2 基，将上一节的编辑空间换为：

```math
V_h=U_h,\quad S_h,\quad\operatorname{orth}([U_h,S_h]),\qquad
r_h=\operatorname{stopgrad}(z_h).
```

参考使用本次前向当前头的编辑前输出，后层表示可以受到前层编辑影响，推理只需一次末位置评分。`paired_n`、`paired_s`、`paired_ns` 分别有 31,771、46,331、78,051 个参数；`online_n` 使用相同在线参考和干扰空间，仅保留原病例监督。

配对两侧保留完整单节点损失。A/P/F_same 另加 JS 保持，C/F 另加两侧标签定向间隔损失，间隔为 1；各类型等权。具体损失见[模块说明](method-clarifications.zh.md)和[训练实现](../../experiments/aster_m3_followup/training.py)。

**结果状态。** P0–P3 的9个新配置均已完成三轮训练。预设主方法 `paired_ns` 的开发准确率为90%、90%、89%，按开发准确率、编辑量和轮次选择第1轮；参数量78,051。MedGUIDE 200题迁移试测中，`paired_ns` 为103/200（51.5%），Full为104/200（52.0%），bias为107/200（53.5%）；相对Full纠正0题、新增错误1题，差值−0.5个百分点，95%来源区间为[−1.575,0]，尚未显示收益。7,458条主测试路径和522对诊断尚无 `paired_ns` 正式结果；旧运行记录停留在评价阶段，目前未运行此实验。节点补评和迁移详情见[阶段报告](../../results/aster_m3_followup_20261107/REPORT.zh.md)。

## 分数读出

### 6 ASTER-CR：repair-v2 数据上的读出

**动机。** 在修复后的条件、事实和背景变体上重新定位注意力头，检验干扰／信号特征能否改善条件判断。

**特征。** 在 fit 上按归因和双向精确修补重新选头。将所选头的末位置输出拼接为 h，按 fit 的 full 视图估计均值 μ 和标准差 s。标准化配对差的 SVD 给出 C/F 信号基 S 和 A/P 初始干扰基 U，再将 U 投影到 S 的正交补并正交化，得到 N。

**读出。**

```math
N=\operatorname{orth}((I-SS^\top)U),\qquad
x=V^\top((h-\mu)\oslash s),\qquad
\ell'=\ell+w^\top x+b.
```

ℓ 为基础模型判断分数差，ℓ′>0 判为条件成立。基础模型与支持空间固定，只训练 w、b。H2 检查干扰坐标的分数变化预测能力及信号扰动，H3 检查错误节点上的信息可读性，据此启用 N、S 或二者拼接。开发选参已冻结为 `cr_r16_l0.01`，使用16维 N，共17参数。

训练采用分类损失、权重正则、A/P/F0 两端分数一致性、C/F 标签定向配对间隔损失和原模型正确输入上的 KL。CR 的间隔约束作用于配对分数差；P3 的间隔约束作用于两端各自的分类分数。实现与参数见[模块说明](method-clarifications.zh.md#aster-cr支持空间与分数读出)、[支持空间](../../experiments/aster_cr/mechanisms.py)和[读出代码](../../experiments/aster_cr/readout.py)。

**对照。** 实验内普通读出使用同一组头的标准化表示做普通 PCA，用分类损失与权重正则训练；CR 使用配对差估计支持空间，并加入配对约束。

**开发结果。** 使用 repair-v2 的 2,782 个候选节点、11,512 个输入和8,730对变体；原始 fit/dev/test 路径为1,712/420/806。选参先要求开发路径下降不超过0.5个百分点，再比较A/P/C/F配对宏平均。

| 方法 | 参数量 | 开发配对宏平均 | 正确路径／420 |
|---|---:|---:|---:|
| Full | 0 | 78.26% | 384 |
| CR 冻结配置 | 17 | 79.09% | 383 |
| 普通读出 ordinary_r8 | 9 | 79.86% | 382 |
| 参数匹配 ordinary_matched | 17 | 78.98% | 381 |
| LoFiT，lr0.001 | 128 | 79.17% | 386 |
| LoReFT，lr0.01 | 8,193 | 78.26% | 384 |
| LoRA，lr0.001 | 8,192 | 76.65% | 385 |
| 最后一层残差偏移，lr0.0001 | 4,096 | 78.26% | 384 |

CR 宏平均高于 Full，低于 ordinary_r8 和 LoFiT，正确路径比 Full 少1例。12组训练对照与4个开发对照分片均已完成；各训练方法按同一路径门槛和配对宏平均选学习率，LoReFT三学习率并列，保存选择为0.01。LoRA的0.0001虽然宏平均更高，但路径380/420未通过门槛；最终选0.001。普通读出冻结为 `ordinary_r8`，提示模板仍为 `full`。

开发对照中，直接参考为78.59%、393/420，参考融合为78.53%、392/420，闭式为78.26%、385/420，LEACE为78.36%、385/420，SEA为76.69%、385/420；CAD和ITI分别为75.22%、311/420与12.49%、22/420。它们在配对宏平均和完整路径上呈现不同变化，不能仅按路径数推断配对鲁棒性。

以上均为原阶段开发集结果。随后测试、五模型和外部任务已有新记录，最新状态见[实验总表](experiments.zh.md)。原开发P/C/F只有4/16/9个独立节点、2/10/5个来源，类别区间、H2/H3和消融见[原阶段分析](../../reports/aster_cr_repair_v2_20261108/ANALYSIS.zh.md)。

### 7 独立普通读出

### 8 后续分数修正与证据保护

11月9—10日继续冻结基础模型，修正条件判断分数。实现和结果收入[近期研究归档](../../results/aster_cr_research_20261109.zip)及[迁移研究归档](../../results/aster_cr_transfer_20261110.zip)。

| 方法 | 相对基础CR的变化 | 实验安排 |
|---|---|---|
| 配对线性拟合与证据保护 | 拟合保持关系的分数变化，约束标签改变关系上的修正 | 比较保护强度、支持空间、秩和混合痕迹 |
| 非线性、分数条件修正与集成 | 用低维特征、原分数或其组合学习修正量，比较多个种子 | 分开记录开发、完整测试及原错误子集 |
| 五模型独立拟合 | 各模型、各旧任务独立定位头并拟合 | MEGA节点、NLI和生成三段论15组，与285项新协议不同 |
| 跨任务A/B/C | 比较源任务冻结配置、目标校准及任务内适配 | NLI和MedPIC保留原划分 |
| G0/G1/G2 | G0重选增益和截距；G1增加标签改变对监督；G2删除相应保护项及训练后幅度缩放 | 同时报告准确率、干扰变化及证据响应 |

降低干扰响应不自动提高准确率。MedPIC的188题适配与467题冻结迁移、MEGA节点与动态路径分别计分。

新痕迹修复无最终结论，[代码与启动快照](../../experiments/aster_cr/trace_repair_20261110.zip)单独保存。每项实现与结果的对应关系见[实验总表](experiments.zh.md)。

## 算子与参考对照

| 方法 | 主要性质／参考 |
|---|---|
| 硬筛选闭式 | 保持纯信号方向；算子幂等 |
| 连续衰减 | 保持纯信号方向；按夹角部分衰减 |
| 全部干扰方向正交投影 | 更新位于干扰空间，信号变化取决于两空间重叠 |
| 可学习 M3 | 更新位于选定空间；记录实际信号变化 |
| learned_self | 参考为无干预完整输入的激活，同前缀两次末位置评分 |
| paired_n/s/ns、online_n | 参考为本次前向当前头输出，推理一次末位置评分 |
| ASTER-CR | 从冻结头表示提取支持空间坐标，修正输出分数 |
| 独立普通读出 | 从冻结末层残差提取 PCA 坐标，修正输出分数 |
