# 模块三：选中头与直接偏置对照实验结果

日期：2026年10月31日。只汇总本次实验，不改完整审查报告。

## 结论

当前证据没有把问题定位为方向、强度或键平移公式的单一错误。更直接的问题是：在现有四个头上改变规则注意力，尚未稳定改善最终决策。

直接偏置与键平移在相同名义强度下，43例的生成规则路径逐例相同。强度4都只纠正同一例；关闭当前头也纠正这一例，没有使原本正确的终点变错。这不能作为所学方向具有独特临床作用的证据。

换到固定对照头施加相同偏置，没有增加终点正确数。关闭对照头时变化更大，并不意味着在这些头上引导正确规则就更有效。当前结果仍不能把主因单独归给选头。

## 这次排除了什么，还没有查清什么

1. 单纯换成直接分数偏置，没有带来比键平移更多的正确路径；暂时没有理由把失败主要解释为键平移的形式不对。
2. 当前头被关闭后，终点成绩没有下降。现有选头指标还缺少“这些头对正确决策关键”的证据；这也不能证明这些头在整个模型中无用，因为本轮只关闭患者输入与回答阶段的输出，指南预填充保持原样。
3. 当前头和对照头关闭时，首个患者后缀末位置移除的输出平方和均值分别为2092.47和1767.80。当前头输出并非更小，却较少改变完整答案，说明只看向量大小或首步分数变化不足以判断决策作用。
4. 原样本中多种不同扰动纠正同一例，可能只是让该例越过了决策边界，不能据此说明所学临床语义方向正确。确认主要原因还需要把规则读取变化与实际错误分支对应起来。

下一步应优先检查“哪些头实际读取分支条件、读入的信息是否传到最终路径”，再据此修改模块三。继续只调强度或把模块一的谱分解做得更复杂，当前证据都不充分。
