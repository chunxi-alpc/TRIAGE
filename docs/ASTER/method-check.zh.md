## 结论

用户提供的“完整读取＋处置盲参考＋共享低秩子空间＋逐节点门控”与当前主方法一致。按本轮相同结构化输入、相同官方7,458例测试集的完整路径正确率，最好结果是 **no_js，第18层、秩4、第3轮，6,653/7,458（89.21%）**。含 JS 版本为6,573/7,458（88.13%），普通低秩为6,283/7,458（84.25%）。这里的“最好”指这些已完成配置的完整路径指标，不代表所有评分指标都最好。

服务器选定检查点为 `/home/gcx/aster_representation_20261101/no_js_layer18/epoch3.pt`。读取其元数据确认：`variant=no_js`、`layer=18`、`rank=4`、`epoch=3`。参数为 `basis[4096,4]`、`mapping.weight[4,4096]`、`gate.weight[1,8]`、`gate.bias[1]`，合计32,777个，对应 $`U,B,w,b`$。

## 需要与原描述区分的地方

| 原描述 | 取得该结果的实际做法 |
|---|---|
| 门控使用 $`[h_g;r_g;\lvert r_g-h_g\rvert]`$ | 只使用 $`[h_g;r_g]`$；绝对差项尚未验证 |
| 参考包含必要定义、脚注和祖先条件 | 提示直接使用患者、当前条件、祖先条件，没有另行提取定义和脚注 |
| 通过验证集选择 $`k`$ | 本轮固定秩4；比较过第18、24、30层，没有秩的对照实验 |
| 交换仅用于条件含义不变的节点，并排除处置依赖条件 | 全树终点文字循环重排，沿用原标签；未实现这项语义排除 |
| 每个训练实例是一处节点判断 | 普通病例选金标路径根、中、末节点，病例内平均；测试覆盖实际走到的每个分叉 |
| 门控学习“答错时纠正、答对时保持” | 通过整体分支损失、正确视图上的 KL 保持项和编辑幅度项间接训练，没有可靠性标签 |

这些差异不改变方法的核心思路，但不能把拟议的绝对差门控、定义提取或语义筛选写成取得89.21%时已经执行的步骤。

## 主要步骤

1. 同一冻结 Qwen3-8B 读取完整规则树；在实际分支决策位置取得第18层注意力输出 $`o_g`$。
2. 另读患者、当前条件和祖先条件，排除候选终点处置，取得同层参考表示 $`z_g`$。参考答案不直接指定路径。
3. 学习正交基 $`U`$ 和映射 $`B`$，得到 $`h_g=U^\top o_g`$、$`r_g=Bz_g`$。
4. 计算 $`\gamma_g=\sigma(w^\top[h_g;r_g]+b)`$，执行 $`\widetilde o_g=o_g+\gamma_gU(r_g-h_g)`$，再由冻结后续层选择合法 Y/N。
5. 用200个普通病例及16个年龄最小对状态训练，共586个选定节点。原指南、全树终点文字重排视图共同接受分支监督；加入权重0.1的正确判断保持项和0.001的相对编辑幅度项，不加 JS。
6. 训练3轮，使用第3轮检查点；推断沿实际选择逐节点执行，终点处置从当前指南查表。干预使用临时缓存，后续持久缓存由未编辑骨干写入。

主方法选择使用过开发集和内部确认集，后者不能再称独立测试。当前结果支持整套配置有效；它不证明三个模块分别学到了预想的语义功能。尤其门控在确认集分歧节点上识别“盲读是否正确”的 AUROC 仅0.549，不能把它当作已经验证的可靠性评分。
