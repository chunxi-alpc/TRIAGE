## 1 引言

大型语言模型正在被用于解读临床指南和患者记录，并判断患者是否满足具体决策条件。此类任务不仅要求模型识别决定性证据，还要求模型判断哪些上下文变化与当前条件无关。对同一指南节点而言，患者的关键指标可能决定判断结果，而后续处置措辞或无关病史虽然属于完整输入，却不应无故改变当前判断。信息的作用取决于当前判断节点：同一项患者属性在一个节点上可能是背景信息，在另一个节点上则可能成为决定性证据。

因此，可靠的指南条件判断需要同时满足两项要求。第一，当决定性证据保持不变、仅非决定性上下文发生变化时，判断应尽量稳定。第二，当条件定义或患者决定性事实发生变化时，判断应保留对该变化的有效响应。前者对应反事实不变性，后者对应证据敏感性（Jacovi & Goldberg, 2020; Veitch et al., 2021）。单纯提高预测一致性并不足够，因为模型也可能通过压低所有输入变化的影响来获得表面稳定性，却同时损害对关键事实的响应。

现有方法从不同层面控制模型行为。输入控制通过提示、遮挡或证据抽取改变模型接收的信息；输出校准与对比解码调整最终分数或输出分布；概念擦除降低某类信息在表示中的可预测性；表示引导直接干预隐藏状态；参数高效微调则通过权重更新改变模型行为。这些路线分别解决了输入选择、输出偏置、表示信息控制和模型适配问题。它们并非原则上不能扩展到反事实配对任务，但其标准优化目标通常不直接对应本文所关心的两个量：非决定性变化引起的判断分数偏移，以及决定性证据变化引起的原始分数响应。

本文研究的是**选择性分数修正**：不删除完整上下文，也不改写冻结模型的参数，而是从模型内部提取与当前判断相关的信号，估计非决定性变化引起的分数偏移，并在训练中同时考虑决定性证据响应。为明确这两个目标，我们构造两类反事实配对。A/P 配对保持当前判断的决定性证据和标签不变，只改变处置文字或无关背景；C/F 配对改变条件定义或决定性患者事实，使当前判断的真值发生变化。A/P 配对提供应当减少的分数变化，C/F 配对提供应当尽量保留的分数响应。

基于这一任务定义，我们提出 ASTER-CR。M1 先定位与当前判断分数相关的注意力头；M2 在这些头的激活中估计证据变化和非决定性变化的主要方向，并提取与主要证据方向正交的低维痕迹；M3 根据痕迹学习分数修正，同时优化 A/P 干扰消减和 C/F 响应保持；M4 在前述模块冻结后进行任务校准。修正函数在训练后具有固定参数，其修正量随输入的内部痕迹变化。因此，本文不以“修正方向逐输入动态改变”作为与表示擦除或表示引导方法的区别；关键区别在于监督目标直接定义在当前判断的反事实分数变化上。

本文的研究贡献体现在三个方面。第一，将指南条件判断中的非决定性变化与决定性证据变化分别操作化为 A/P 和 C/F 配对，使稳定性与证据敏感性可以在同一分数空间中评价。第二，提出由机制引导的注意力头定位、头内反事实方向分解和分数层修正组成的冻结模型框架。第三，分析混合痕迹下精确对消与证据响应保持的可行条件，并通过注意力头四象限诊断研究两类信息在头级激活和判断分数敏感性上的关系。本文不预设两类信息由两组互不重叠的注意力头承载。

## 2 相关工作

### 2.1 反事实不变性与行为忠实性

解释忠实性研究关注模型解释是否反映实际决策过程（Jacovi & Goldberg, 2020）。相关工作表明，模型的显式解释未必忠实于其实际决策依据（Turpin et al., 2023），推理任务表现也可能受到内容变化影响（Lampinen et al., 2024）。反事实不变性研究进一步考察当虚假相关因素变化时，模型预测是否保持稳定（Veitch et al., 2021）。

本文沿用反事实干预的基本思想，但将其落实到指南条件判断的两类配对分数响应。A/P 配对检验在决定性证据不变时分数是否受到无关上下文影响；C/F 配对检验模型是否保留对条件和患者事实变化的响应。两类配对不仅评价最终标签，也评价连续判断分数的变化幅度。需要强调，配对是否成立取决于医学语义：仅有标签相同并不足以证明决定性证据完全相同，处置改写若同时改变条件定义，也不能作为合格的 A/P 配对。

### 2.2 输出校准与对比解码

输出校准通过改变分数尺度或偏置改善概率估计。温度缩放调整模型置信度（Guo et al., 2017）；上下文校准利用无内容参考输入估计标签偏置（Zhao et al., 2021）；批量校准利用无标签输入的平均输出估计偏置（Zhou et al., 2024）。这些方法适合调整整体尺度或系统偏置，但其标准目标并不区分当前任务中的 A/P 与 C/F 变化。

对比解码则利用不同上下文条件下的输出差异调整预测。上下文感知解码比较有无上下文时的模型输出（Shi et al., 2024），DExperts 组合基础模型、专家和反专家的输出以控制生成属性（Liu et al., 2021）。这些方法说明输出层可以实施对比式调整。ASTER-CR 与它们的区别不在于“输出相减”这一形式本身，而在于修正量由所选注意力头的内部痕迹预测，并以 A/P 和 C/F 配对共同监督。

### 2.3 概念擦除与表示信息控制

概念擦除通过投影或优化减少某类属性在表示中的可预测性。INLP 迭代移除线性分类方向（Ravfogel et al., 2020）；R-LACE 采用对抗式线性擦除（Ravfogel et al., 2022a）；LEACE 给出闭式线性概念擦除（Belrose et al., 2023）；SAL 根据表示与属性的交叉协方差移除相关方向（Shao et al., 2023）。后续研究将概念擦除扩展到核空间、率失真目标和非线性分布匹配（Ravfogel et al., 2022b; Chowdhury et al., 2023; Saillenfest & Lemberger, 2025; Akbari et al., 2025）。

概念可预测性与指定判断分数对某类反事实变化的敏感性并非同一目标。某个概念即使难以从表示中被线性预测，也不意味着它不再影响当前判断；反过来，模型也可能保留对某种概念的理解，却不应让它影响某个特定节点的判断。ASTER-CR 不要求从完整表示中擦除非决定性信息，而是学习其对当前判断分数的修正量，并单独评价决定性证据响应。

### 2.4 激活引导与表示微调

表示引导通过内部激活方向改变模型行为。ITI 沿注意力头方向调整激活（Li et al., 2023）；CAA 从成对示例的残差激活差估计干预向量（Rimsky et al., 2024）；CAST 根据输入激活选择性触发行为向量（Lee et al., 2025）。LoFiT 学习局部表示调整（Yin et al., 2024），LoReFT 学习低秩表示干预（Wu et al., 2024）。RePS 通过双向偏好优化学习表示引导，PSR 从提示行为中估计位置相关的引导系数（Wu et al., 2025b; Heyman & Vandeputte, 2026）。

这些工作表明，成对激活、条件化引导和局部表示干预均已有研究基础。因此，本文不将“使用成对激活差”“使用固定线性方向”或“输入相关修正量”单独作为创新点。本文的具体问题是：如何利用机制定位的内部特征，直接拟合 A/P 配对的最终分数偏移，同时在 C/F 配对上评价并优化对原始证据响应的保持。与直接修改隐藏状态的表示干预不同，ASTER-CR 将修正加在最终判断分数上，不改变冻结主干网络的内部前向计算。

### 2.5 参数高效微调

LoRA 通过低秩矩阵参数化权重更新（Hu et al., 2022）；DoRA 将权重幅值和方向分开处理（Liu et al., 2024）；FourierFT 使用频域参数化权重增量（Gao et al., 2024）。这些方法解决的是如何以较低参数成本适配模型。若在训练目标中加入反事实配对，它们也可以学习选择性行为。因此，本文不主张参数微调无法解决该问题，而是研究一种不同的实现路线：冻结主干模型，通过内部特征读取和最终分数修正实现行为调整，并将两类反事实响应直接纳入修正目标。

### 2.6 研究定位

综上，已有研究分别提供了反事实不变性、输出校准、概念擦除、激活引导和参数适配的理论与方法基础。本文的研究定位不是提出全新的正交投影或激活修补技术，而是将这些工具组织为一个面向指南条件判断的分数修正框架：M1 选择与当前判断有关的读取位置；M2 利用反事实差分构造证据感知的内部痕迹；M3 直接联合优化 A/P 分数差消减与 C/F 原始响应保持；M4 将修正后的分数映射到任务决策。本文的比较重点是不同方法在干扰消减、证据响应和任务效用三个维度上的实际表现，而不是假设某一类方法在所有维度上都占优。

## 3 方法

### 3.1 任务定义与反事实配对

输入包括指南决策树、患者病例和当前判断节点。模型判断当前条件是否成立。令 (z_+(x)) 和 (z_-(x)) 分别为冻结模型对“是”和“否”的输出 logit，定义原模型判断分数：

```math
\ell_0(x)=z_+(x)-z_-(x),\qquad
\hat y_0(x)=\mathbf 1[\ell_0(x)>0].
```

正分数表示模型预测当前条件成立。本文构造两类反事实配对：

- **A/P 配对（非决定性变化）**：改变后续处置文字或与当前节点无关的背景信息，保持当前条件的决定性证据和标签不变。理想情况下，配对两端的判断分数应尽量接近。
- **C/F 配对（决定性变化）**：改变条件定义或患者决定性事实，使当前判断的真值发生变化。模型应保留对该证据变化的有效分数响应。

例如，当前节点判断 eGFR 是否不低于30，患者数值为34。仅改写后续处置而保持数值和条件不变，属于 A/P；将决定性数值从34改为26，或将阈值从30改为45，属于 F 或 C。信息是否决定当前判断取决于当前节点，不能仅依据文本类别预先判断。

记训练配对集合为 `\mathcal J_{AP}^{train}` 和 `\mathcal J_{CF}^{train}`。配对权重按类别和来源平衡，使 A 与 P、C 与 F 在各自目标中具有预先规定的贡献。语义审核、来源划分和配对构造均在模型拟合前冻结；同一来源的配对变体不跨训练与留出划分。

### 3.2 M1：机制引导的注意力头定位

M1 回答“从模型内部哪些位置读取信息”。令 (h_h(x)) 表示输入 (x) 在答案位置的第 (h) 个注意力头输出。对每个训练配对 (j) 和候选头 (h)，计算左端输入上的局部梯度归因：

```math
g_{j,h}^{L}=\nabla_{h_h}\ell_0(x_j^L),\qquad
a_{j,h}=\left|
\left\langle h_h(x_j^R)-h_h(x_j^L),g_{j,h}^{L}\right\rangle
\right|.
```

分别在 A、P、C、F 四类配对内汇总加权归因分数，并对每类候选头排序。梯度归因计算成本较低，适合筛选候选，但它只是局部一阶近似，不能单独证明某个头在完整网络中的实际作用。

因此，M1 对候选头进一步执行双向激活修补：在左端输入的前向计算中，将该头激活替换为右端输入对应激活；再反向交换一次，记录最终判断分数变化。双向修补用于验证候选头的干预敏感性，并降低单向替换可能带来的偶然性。修补效应仍是特定配对和干预方式下的局部机制证据，不等同于该头独立承担完整因果路径。

A/P 的排名聚合为干扰侧排序，C/F 的排名聚合为证据侧排序。最终交替合并两侧排名、去重，并按预设头集合规模截取，形成共同的注意力头集合 `\mathcal H_m`。本文不在 M1 阶段强制将注意力头划分为互不重叠的“证据头”和“干扰头”：同一个头可能同时参与两类信息处理，因而需要在 M2 中进一步分析头内激活方向。

### 3.3 M2：证据感知的低维干扰痕迹

M2 回答“所选注意力头内部，哪些变化方向适合用于修正”。将 M1 选中头在答案位置的输出拼接为：

```math
h_m(x)\in\mathbb R^{d_m}.
```

利用训练配对端点的加权均值和逐维标准差进行标准化：

```math
\tilde h_m(x)=
(h_m(x)-\mu_m)\oslash\sigma_m.
```

其中，标准化权重在配对端点间分配，并按配对类别、来源和病例结构平衡。对配对 (j)，定义：

```math
\Delta\tilde h_{m,j}
=\tilde h_m(x_j^R)-\tilde h_m(x_j^L).
```

分别利用 C/F 和 A/P 配对差分估计证据子空间与干扰子空间：

```math
S_m=\mathrm{basis}_{k_m}
\left(\{\Delta\tilde h_{m,j}:j\in\mathcal J_{CF}^{train}\}\right),
\qquad
U_m=\mathrm{basis}_{k_m}
\left(\{\Delta\tilde h_{m,j}:j\in\mathcal J_{AP}^{train}\}\right).
```

`basis` 表示对按配对权重加权的差分矩阵进行截断奇异值分解，并保留预先确定的有效右奇异向量。将干扰子空间中与证据子空间重叠的部分投影出去，再正交化：

```math
N_m=\mathrm{orth}\bigl((I-S_mS_m^\top)U_m\bigr),
\qquad
t_m(x)=N_m^\top\tilde h_m(x).
```

因此，(t_m(x)) 是当前输入在“主要干扰变化方向中、与估计的主要证据变化方向正交的部分”上的坐标。正交投影具有明确的几何性质：若标准化激活变化完全位于 `span(S_m)`，则该变化不会改变 (t_m(x))。但 (S_m) 由有限训练配对和有限秩 SVD 估计，不能保证覆盖所有真实证据变化；正交性是相对于估计子空间成立，而不是对所有可能证据变化的无条件保证。

低维痕迹也具有统计上的作用：它限制 M3 可以利用的方向，降低在有限来源配对上拟合偶然相关性的风险。全维正交补实验表明，扩大特征空间可能提高训练目标上的干扰消减点估计，却同时恶化留出来源上的证据响应；因此，低维限制不仅是信息压缩，也是一种结构性归纳偏置。该经验现象尚不能证明当前秩 (k_m) 最优，秩和正则强度仍需在开发来源上选择。

### 3.4 M3：双目标分数修正

M3 回答“如何利用内部痕迹修正最终判断分数”。定义原模型分数差与痕迹差：

```math
\Delta\ell_{0,j}
=\ell_0(x_j^R)-\ell_0(x_j^L),\qquad
\Delta t_{m,j}=t_m(x_j^R)-t_m(x_j^L).
```

令线性修正函数为 (c_{w_m}(t)=w_m^\top t)。A/P 配对的目标是使修正后的分数差尽量接近零：

```math
L_{AP}(w_m)=
\sum_{j\in\mathcal J_{AP}^{train}}
\omega_j
\left(\Delta\ell_{0,j}
+w_m^\top\Delta t_{m,j}\right)^2.
```

C/F 配对的目标是尽量不改变原模型对决定性证据变化的分数响应：

```math
L_{CF}(w_m)=
\sum_{j\in\mathcal J_{CF}^{train}}
\nu_j
\left(w_m^\top\Delta t_{m,j}\right)^2.
```

联合目标为：

```math
\boxed{
\hat w_m=\arg\min_{w_m}
\left[
L_{AP}(w_m)+\eta_m L_{CF}(w_m)
+\lambda_m\|w_m\|_2^2
\right].
}
```

其中，`\omega_j` 和 `\nu_j` 分别按 A/P 与 C/F 类别及来源平衡；`\eta_m` 控制干扰消减与证据响应保持的相对权重；`\lambda_m>0` 为岭正则强度，用于控制有限样本下的系数规模。两类损失均在训练来源上计算，`\eta_m` 与 `\lambda_m` 只根据开发来源选择。本文不设置逐对硬预算，也不把某个预先指定的修正上限作为方法成立条件；模型优劣由留出来源上的 A/P 消减、C/F 响应变化和任务效用共同评价。

该目标是凸二次函数。令 (X_{AP}) 和 (X_{CF}) 分别为两类配对的痕迹差矩阵，(W_{AP}) 和 (W_{CF}) 为对角权重矩阵，则其 Hessian 为：

```math
2\left(
X_{AP}^\top W_{AP}X_{AP}
+\eta_m X_{CF}^\top W_{CF}X_{CF}
+\lambda_m I
\right).
```

当权重非负、`\eta_m\geq0` 且 `\lambda_m>0` 时，Hessian 正定，故存在唯一全局最优解。这里的 C/F 项是总体加权效果目标，不提供逐配对的硬保证；因此，留出来源上每一类证据配对的修正分布、方向变化和双端判断正确性都必须单独报告。

为将输入相关修正与全局阈值调整分开，计算训练端点上的修正均值：

```math
\mu_{c,m}
=\sum_{v\in\mathcal V_{train}}\rho_v
\hat w_m^\top t_m(v),\qquad
c_m(x)=\hat w_m^\top t_m(x)-\mu_{c,m}.
```

M3 输出分数为：

```math
s_m(x)=\ell_0(x)+c_m(x).
```

中心化不改变任何配对分数差，因为同一个常数在两端相减时抵消。它使输入相关修正与全局阈值偏移在定义上分开；全局截距和概率映射由 M4 独立处理。

### 3.5 M4：任务校准

M1–M3 冻结后，M4 使用训练来源的自然任务样本估计任务校准参数。对二元判断，采用逻辑再校准：

```math
p(y=1\mid x)=\mathrm{sigmoid}
\left(\alpha_m+\beta_m s_m(x)\right),
\qquad \beta_m>0.
```

其中，`\alpha_m` 调整整体阈值，`\beta_m` 调整分数尺度且保持单调性。校准参数只使用训练来源的自然标签估计；开发集用于预先规定的配置选择，测试标签仅用于最终评价。对集合预测任务，则按任务原生协议将修正后的选项分数映射为合法答案集合的能量，并在合法集合上归一化。M4 不重新估计注意力头、子空间或修正方向。

### 3.6 理论依据与适用条件

**正交投影性质。** 由 (N_m\subseteq\mathrm{span}(S_m)^\perp)，可得 (S_m^\top N_m=0)。因此，对任意向量 (a)，若标准化激活增加一个位于证据估计子空间内的变化 (S_ma)，则：

```math
t_m(\tilde h_m+S_ma)
=N_m^\top(\tilde h_m+S_ma)
=N_m^\top\tilde h_m.
```

这说明 M2 构造的痕迹对估计证据子空间内的变化不敏感。该结论是关于估计子空间的代数性质，不意味着 (S_m) 已完整覆盖真实证据变化。

**局部精确对消的可行条件。** 考虑局部加性模型：

```math
\ell_0(e,\nu)=f(e)+\boldsymbol\gamma^\top\nu,
\qquad
t(e,\nu)=D\nu+He,
```

其中 (e) 表示决定性证据坐标，`\nu` 表示非决定性变化坐标。对痕迹施加线性修正 (w^\top t) 后，精确消除干扰且保持原证据响应要求：

```math
D^\top w=-\boldsymbol\gamma,
\qquad
H^\top w=0.
```

令 (Z) 的列构成 `\ker(H^\top)` 的正交基，则两个条件同时可行，当且仅当：

```math
\boldsymbol\gamma\in\mathrm{range}(D^\top Z).
```

该条件说明：痕迹中必须存在既能表达所需干扰修正、又不改变证据响应的读出方向。若条件不成立，增加修正函数容量不能弥补特征中缺失的信息；实际方法只能在两类效果之间进行近似权衡。

**表示纠缠的局部几何代价。** 对同一表示点处的单位证据切向和单位干扰切向，若二者夹角为 `\theta`，任何在该点严格保留证据切向并消除干扰切向的可微表示编辑，其编辑雅可比的谱范数下界随 `\csc\theta` 增长。该结论解释了严格表示分离在高度纠缠时可能代价很高，但它适用于表示编辑的局部精确要求，不直接证明 ASTER-CR 优于所有表示编辑方法。

**优化性质。** M3 的双目标损失是带岭正则的凸二次函数，因而可稳定求得唯一的训练最优解。其实际泛化效果取决于配对覆盖、痕迹质量、正则选择和来源分布；训练目标下降本身不保证留出来源上的证据响应保持或任务准确率提升。

### 3.7 整体推理过程

给定冻结模型、当前指南节点和患者输入，ASTER-CR 按以下步骤工作：

1. 冻结主干模型，读取原始判断分数和 M1 选中的答案位置注意力头激活。
2. 使用训练阶段冻结的标准化参数和投影基，计算内部痕迹 (t_m(x))。
3. 使用训练阶段学习的固定系数计算修正量 (c_m(x))，得到修正分数 (s_m(x))。
4. 使用冻结的 M4 校准器得到最终判断或合法答案集合。

推理时不需要配对另一条输入，也不重新选择注意力头或估计子空间。修正系数 (w_m) 在训练后固定，输入相关性来自每个新输入自身的内部痕迹。

## 4 机制诊断：注意力头的响应选择性

PR #73 的 E1 五折缓存诊断为 M1 与 M2 的分工提供了补充证据。该分析复用已有的全部注意力头激活、梯度归因和精确修补记录，没有重新运行模型前向、梯度计算或 M1。

在标准化激活移动视图中，A/P 与 C/F 两轴的 Spearman 相关为 −0.630。按预先确定的第75百分位阈值，1,152个注意力头中有288个属于 A/P 高、C/F 低，288个属于 A/P 低、C/F 高，576个属于两轴均低，未观察到两轴均高的头；92.10%的头在五折中与共识象限一致。这说明不同注意力头的激活移动模式呈现稳定差异，但四象限数量受分位阈值定义影响，不应被解释为模型天然形成了固定数量的功能模块。

梯度归因视图呈现不同关系：A/P 与 C/F 归因的 Spearman 相关为 +0.780；179个头位于两轴均高的混合象限。M1 每折选中的51个头共有255次折内入选记录，其中246次（96.47%）落在梯度混合象限。该结果提示，真正与最终判断分数敏感性相关的头，往往同时响应 A/P 与 C/F 两类变化。因此，当前方法在 M1 中合并两侧排名，而不是把注意力头强制划分为互不重叠的两组；随后在 M2 中分析同一头集合内部的变化方向。

已有双向精确修补在32个具有 A/P、P、C/F 四类完整记录的共同覆盖头上，梯度归因与修补效应的 Spearman 相关分别为 A/P 0.880、C/F 0.920。但该修补集合来自每类梯度排名靠前的候选头，存在候选筛选偏差；而且 A/P 激活选择性候选与完整修补集合的共同覆盖为0。因此，现有修补结果支持候选范围内的梯度—干预效应对应关系，尤其是 C/F 方向，但尚不能验证 A/P 激活选择性头是否具有更大的 A/P 因果效应，也不能证明存在两组因果独立的注意力头。该诊断支持“头级定位、头内方向分解”的当前设计，但不构成双分支架构已经成立的证据。

## 5 结果整合前必须完成的验证

本稿将 M3 从逐对硬约束改为 A/P 与 C/F 双目标效果优化。现有 E1 主结果、预算敏感性结果及 PR #71 全维实验均来自旧版逐对硬约束 M3，不能直接作为本稿 M3 的验证。正式整合结果时，应在不重新运行 M1、不重新提取激活的前提下，复用现有来源五折特征缓存，按本稿目标重新拟合 M3，并在独立来源上同时报告：

- A/P 修正后分数差 RMS、方差降低率和双端判断结果；
- C/F 修正量 RMS、原始有向响应变化、逐对变化分布和双端判断结果；
- 自然节点、自然路径及干扰路径任务表现；
- 不同 `\eta_m` 和 `\lambda_m` 的开发集选择过程，以及来源级留出区间。

不应将 C/F 平均响应保持等同于每一对证据均被保持，也不应将 A/P 方差降低等同于任务准确率提升。只有新 M3 在留出来源上同时改善两类反事实效果，才可将其作为最终方法的实证结论。
