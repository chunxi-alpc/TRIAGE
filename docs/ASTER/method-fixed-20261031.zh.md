# ASTER：论文方法定稿说明

版本：2026-10-31。本文件固定本轮主方法、数据使用和主张；具体头集合、编辑强度、弃权阈值由开发集选定后填入，验证结果不反馈选参。

建议论文标题：**基于处置盲适用性判断的指南缓存键编辑**。ASTER作为方法名称保留，不把谱分解列为必要组成，也不预设处置偏好是已证明的失败机制。

## 可直接写入论文的方法概述

我们提出ASTER，将指南适用性判断与下游处置生成分为三个模块。首先，使用独立患者最小对提取规则键表示的正负差分，以归一化均值差作为可复用的编辑方向。其次，冻结的大语言模型仅根据原始患者记录、当前节点条件及必要祖先条件语境，直接判断该条件为真、假或信息不足；患者病历中已有的治疗史保留，当前候选处置、原问题和选项不参与适用性判断。最后，将已接受的规则路径转换为有符号键平移，在复用指南预填充缓存的基础上调整后续生成。模型权重保持不变。

本轮使用二叉指南树：真与假分别对应“是”和“否”分支；信息不足或置信度低于阈值时停止进一步门控，保留已接受祖先，下面未确认的子树由生成模型判断。停止不是把缺失事实判为否，也不等于删除整个剩余指南。

## 三个模块的固定定义

### 模块一：均值方向

离线采用“患者→指南”的顺序。在独立最小对中，只改变决定规则适用性的患者事实，从目标规则编号和处置词元提取k_norm后、RoPE前的键。先在每对的目标词元内平均差分，再在最小对间等权平均并归一化：

```math
\bar d_h=\frac{1}{N}\sum_{i=1}^N\frac{1}{|J_i|}
\sum_{j\in J_i}(k^+_{h,i,j}-k^-_{h,i,j}),\qquad
\Delta_h=\bar d_h/\|\bar d_h\|_2.
```

使用原16对、8来源拟合，不使用模块二伪标签，不在本轮更新模型权重或训练额外方向组合。未知状态不作为负例。

### 模块二：大模型直接判断适用性

对当前完整条件直接输出T、F、U，分别表示病历支持、病历反驳、信息不足／不确定／冲突。祖先条件仅用于理解指代，不作为新增患者证据，也不重复要求模型核验全部祖先合取项。直接读取三个代理标签的概率，使用前两名之差作为置信度分数。沿合法树路径逐步接受分支，遇到U或间隔小于阈值τ时停止。

这些标签概率作为开发选择用的置信度分数，不称为已经校准的风险保证。τ从新100例上选择，冻结后使用；本轮候选为0、0.1、0.2。原分类器与NONE偏置校正是对照，不属于主方法新增模块。

### 模块三：规则键编辑

在线采用“指南→患者→问题→回答”的顺序。指南缓存可以在同一指南的病例之间复用；每个病例复制缓存后编辑，不回写共享原件。

将已接受规则对应位置记为正增益，被排除兄弟及其全部后代位置记为负增益，其余位置增益为零。不对被排除后代重复累加惩罚；已接受分支下未确认的子树保留。部署编辑范围固定为完整规则片段，包含条件、编号、处置，以及被排除后代组的标题和祖先说明；起始汇聚词元、患者和问题文字不编辑。此范围大于离线方向提取的编号／处置范围，属于需要验证的迁移，不将二者混称同一位置。

```math
\widetilde K_{h,j}
=K_{h,j}+a_j\,g\,R_j\Delta_h,\qquad
a_j\in\{-1,0,+1\},\quad h\in\mathcal H.
```

其中K为已旋转的缓存键，R_j使用在线位置，g为冻结强度，H为冻结头集合。其他头不编辑，值缓存不编辑。真实K／V／KV替换仅是失败诊断，不是部署方法。键平移不保证每个查询都产生同号打分变化，也不等同于硬裁剪。

## 主方法与对照分开

**主方法只有：均值方向＋直接三值判断＋规则键平移。**

- 谱、反向均值、三个随机方向：检验学习方向及谱步骤是否有增量。
- 裁剪、硬屏蔽、打分偏置：检验读取范围及键平移形式的限制。
- 金标门控：隔离模块二误差的诊断，不能列作部署成绩。
- 真实K／V／KV替换与跨顺序移植：键编辑没有正向开发信号时才进行的失败定位。
- 七种方向组合搜索和LEACE：不在本轮主方法或自动实验队列中。
- 多路径概率集成：额外执行对照，不改变主方法的单条接受路径定义。
