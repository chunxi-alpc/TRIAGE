# 两模型最终结论：冻结 M1 机制诊断与原文试测

本轮已完成。两模型分别完成64对头修补、64对重点层内外修补、12对残差扫描，以及MedGUIDE和MEGA-CDP各200例原文试测。CPU分析、来源重采样区间和最终总报告均已生成。无超长或其他无法评分记录。没有重新选头或进行纠错训练。

## 对方法的判断

结果支持M1识别出能够解释较大部分分数变化的头集合。当前证据仍不足以确认完整方法能够提高原题回答准确率；本轮测量的是机制恢复和基础模型错误数，没有测量纠错前后收益。

保留冻结M1。后续值得对两模型统一研究逐层候选筛选和联合选择，理由是候选外贡献与组合不可加已经出现；本轮不执行升级，不把80%作为成功线，也不追加变体凑错误数量。

## 机制诊断说明什么

1. 候选外仍有作用。Qwen开发A三个重点层的候选外加权贡献为14.96%、11.86%、4.91%，区间均高于零；MedGemma开发A的层索引58候选外贡献为9.94%，区间4.02%–28.19%。它们是分别干预的结果，不能相加，也不是加入冻结集合后的边际收益。两模型都有扩大候选覆盖方式的研究理由，但不是所有层、所有类型都得到正贡献。

2. 组合贡献不能按单头效应直接相加。MedGemma开发A正向，组合效应均值为0.1383，单头效应和均值为2.2175；固定注意力输出RMS缩放后为0.1021和2.3571。这个例子说明固定缩放没有使效应自动变得可加，不能把所有差异归因于该归一化。各配对的方向与分母不同，解释时同时使用逐对差值和双方向结果。

3. 归一化影响部分组合，证据最明确的是MedGemma开发P的合并集合。原口径由92.34%变为70.97%，配对差值-21.37个百分点，95%区间[-35.19,-0.65]；加权口径由96.88%变为87.65%，差值-9.24个百分点，区间[-29.15,-1.48]。类型专用A/P集合的对应差值区间均跨零。该结果来自8对、4来源，原口径中5对有效，支持继续研究组合相互作用，不能认定归一化是普遍原因。

4. 精确排名的高重叠需要与随机基线比较。MedGemma A在128候选中取125头，重采样Jaccard为0.962，随机基线已经为0.954，不能把0.962当作很强的稳定性证据。Qwen候选内排名重叠也有波动。此处只验证固定候选内排名，不验证完整选头流程，更没有检验重新选择后的组合恢复率。

5. 样本与分数口径会显著影响恢复率。Qwen开发A的原口径44.99%、加权81.14%、回归96.39%；同样8对在旧缓存的原口径为47.39%，因此不能用旧完整开发集81.89%与44.99%的差异判断实现退化。MedGemma拟合A出现超过100%的恢复，表示修补效应超过原分数差，不能解释为超过100%的准确率。

6. 数值检查应分开解释。两模型各64对的缓存内重复、自己修补自己及全头donor恢复误差均为零；MedGemma固定缩放无干预也为零。一次性完整前向与缓存末位置前向的最大分数差为Qwen 0.6771、MedGemma 0.1012。小效应对这一差异敏感，当前不能把微小分数变化全部解释为机制信号。完整前向差异没有在本轮进一步归因。

## 原文基础模型结果

|数据/指标|Qwen3正确/错误|Qwen3准确率|MedGemma正确/错误|MedGemma准确率|
|---|---|---|---|---|
|MedGUIDE题目200道|103/97|51.50%|111/89|55.50%|
|MEGA-CDP自主路径200例|193/7|96.50%|196/4|98.00%|

MedGUIDE覆盖53个来源，MEGA覆盖200个来源。MedGUIDE两模型共同错71题（37来源），仅Qwen错26题，仅MedGemma错18题；MEGA共同错1例，仅Qwen错6例，仅MedGemma错3例。所有数量均相对于数据集原标注，不是对标注本身临床正确性的重新裁定。

这些数字说明MedGUIDE存在较多跨模型共同自然错误，MEGA本次样本中的错误较少。MedGemma的样本准确率略高，不据此宣称完整数据集上的稳定优势。这是来源均衡的探索样本结果，不能与完整7458例成绩混同；未来方法升级应保留新的确认来源。

## 可以写入论文的结论

少量注意力头能够恢复较大部分配对分数变化，支持M1作为机制定位步骤的价值。恢复程度随效应规模和样本组成变化，候选外贡献及组合相互作用表明当前集合尚非完整、稳定的机制描述。原文基础评估进一步显示，不同任务的自然错误规模差异很大。上述结果为后续候选筛选、联合选择和纠错评估提供依据，尚不构成纠错准确率提升的证据。
