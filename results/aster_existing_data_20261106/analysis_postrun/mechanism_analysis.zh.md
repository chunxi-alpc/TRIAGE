# ASTER 机制与消融问题分析

本分析只使用本轮已保存的分数、激活修补结果与算子诊断，未运行新模型、改标签或调整选参。结论是：M1 找到的头确实承载了较多干扰效应，但低秩表示和夹角筛选之后，最终算子只覆盖很小一部分可测干扰。主测试集的两处纠正可以被简单的输出校准完全复现。

## 1. 主要损失发生在夹角筛选

在同一批测试 A/P 配对上，四种双向联合修补的平均恢复率如下。每种方法使用相同的 51 个头。

| 修补分量 | A | P |
| --- | ---: | ---: |
| 完整头差分 | 87.71% | 84.11% |
| 低秩干扰空间正交分量，未经夹角筛选 | 63.08% | 69.34% |
| 夹角筛选后的正交分量 | 11.88% | 11.85% |
| 最终斜投影分量 | 15.26% | 14.42% |

A 共 200 对、P 共 98 对全部保留；上述归一化均值分别使用原始分数差绝对值至少 0.1 的 185/92 对。恢复率衡量修补解释的分数变化，不等同于准确率改善或严格可加的因果贡献。

为避免小分母主导结论，另用全部配对计算过原点的效应回归比例：令 t 为原始分数差，e 为双向修补效应的对称平均，报告 sum(t*e)/sum(t*t)。四阶段 A 为 95.53%、72.69%、9.65%、7.75%；P 为 95.02%、82.32%、3.22%、2.83%。在分数差绝对值至少 0.5、1、2 的诊断中，筛选后的效应也一直较小。这些补充统计不参与选参、不改变主评价分母。

这说明低秩截断已有损失，而最明显的损失发生在夹角筛选。斜投影没有把被筛掉的方向补回来；其相对正交分量的改善只出现在逐对归一化均值中，不能据此宣称它全面优于正交修补。

## 2. 能量目标与实际覆盖有明显差距

最终配置为能量目标 0.95、单类秩上限 4、夹角 45 度。按相应干扰类型使用的头汇总拟合差分能量：

能量分母是原方案效应过滤后全部拟合干扰差分的未中心化二阶能量：A 141 对、P 107 对。A 只在 M1 指定承载 A 的 22 个头上汇总，P 只在 M1 指定承载 P 的 39 个头上汇总；两组允许重叠，各自计算比例，不相加成一个总百分比。这是拟合端覆盖描述，不用于按测试表现筛选样本。

| 阶段 | A 能量覆盖 | P 能量覆盖 |
| --- | ---: | ---: |
| 合并低秩干扰空间 | 55.27% | 75.84% |
| 夹角筛选后保留方向 | 18.57% | 10.59% |

这些是各头能量先相加再取比值，不是按头平均，也不是准确率。A 的 22 个对应头没有一个以秩 4 达到 95% 目标，P 的 39 个对应头仅 1 个达到；达到目标所需秩的中位数分别为 46 和 36。能量目标 0.95 因而不能解读为实际保留了 95% 干扰能量。

夹角筛选把总干扰秩从 244 降到 120，3 个头最终编辑秩为 0。它又丢弃低秩空间内 A 能量的 66.40%、P 能量的 86.03%。筛选规则去除与保护空间夹角小于 45 度的方向，结合修补效应骤降，支持如下解释：当前重要干扰方向与被保护的 C/F 差分空间有较大重叠，几何分离要求舍弃了大量有作用的方向。这里的“保护空间”是经验估计的差分空间；不能直接把它等同于纯粹的事实或条件语义。

## 3. M1 有定位作用，但尚未转化为独特的分类收益

H1 中，所选头联合修补的 A/P 恢复率是 87.71%/84.11%；三个随机头集合分别只有 A 7.82%—19.14%、P 7.56%—20.98%。因此不宜把本轮负结果归结为“完全没找到相关头”。

但最终分类改善非常集中：ASTER 只改变了同一个节点 expanded-confirmation-2303-G0 的两个背景输入，分别是临床背景和治疗偏好变体。两者原分数均为 +0.5，标签均为“否”；ASTER 分数分别为 -3.75 和 -3.0。其余 608 个测试输入的预测与完整阅读相同。

直接逐输入核查发现，完整阅读单路校准、random_13、原输入参考均值这三项，在全部 610 个测试输入上的分类均与 ASTER 相同。单路校准把完整阅读“是”阈值从 0 移至约 0.639，足以纠正同样的两个边界错误。此处只是本次测试的分类一致，分数和内部机制并不相同。

均值差消融和 random_73 的宏平均为 97.074%，ASTER 为 97.079%，都为 603/610 正确，但错误位置不同。正交擦除为 96.954%，LEACE 为 96.819%。去 C 保护的宏平均与 ASTER 一样，但少正确一个输入；不能仅凭宏平均持平断言 C 保护毫无作用。现有差异很小，尚不足以证明完整三模块具有稳定的额外分类优势。

## 4. 选参缺少区分力

18 个配置在开发宏平均及原输入准确率上全部并列，最终依预设规则选择较低编辑秩和较大夹角。开发 C 只有 1 对。该规则被正确执行，但这次数据并未为“秩 4、45 度最好”提供比较证据，且恰好选择了较弱的干预。

主测试宏平均提高 0.5102 个百分点，按指南重采样的差值 95% 区间为 [0, 1.5625] 个百分点。两处纠正集中在同一个指南的同一节点，应按一个来源上的局部改善理解，不能当作多来源一致的提升。

## 5. H3 与局部理论没有补足缺失证据

H3 的线性探针在原模型 9 个测试错误上全部预测“是”，正确 4/9；标签中“否”有 5 个，“是”有 4 个。原输入错误子集为 0/1。该结果不支持“错误样本中普遍保留了可有效读出的正确答案”。样本少，且这些错误是困难条件子集，不能据此证明保护空间完全没有信号。开发集信号放大候选也全部同分，最后选倍数 1。

算子代数检查成立：最大信号保持误差约 1.94e-8、最大擦除误差约 2.52e-8，算子范数不超过 1.412。但这些保证只适用于已估计空间及固定局部表示，不保证下游非线性判定或自主路径正确。

固定 20 个测试节点的局部诊断中，平均绝对一阶预测变化为 0.345，真实顺序编辑变化为 0.813；跨层变化为 0.494，总预测误差为 0.585，超过一阶变化本身。说明静态局部近似不足以精确描述最终编辑效果。该诊断可解释为何代数正确不自动带来决策保护，但不能单独确定每个路径退化病例的原因。

## 建议优先级

1. 先解决“应保留的信号与有作用的干扰方向高度重叠”这一问题，分析被夹角筛掉的方向实际承载什么，再决定是否放宽几何要求。直接增大秩不能保证通过后续筛选。
2. 将简单校准作为核心对照，并重点解释同一节点两个边界错误；不要把这两例当作完整机制有效的主要证据。
3. 下一轮预先设计能区分候选的开发评价，尤其是 C 和真实路径泛化；本轮测试结果只用于问题分析，不回头选新配置或挑样本。
4. 若后续修改算子，应重新评价历史数值诊断与完整自主路径，因为局部代数性质不等于任务级保真。

可复算证据见 mechanism_evidence.json；脚本为 analyze_mechanisms.py。关键实现位置：operators.py:52（能量基与秩上限）、operators.py:102（夹角筛选与斜投影）、operators.py:305（干扰／保护空间合并）、existing.py:167（四分量联合修补）、evaluation.py:453（H3 探针）、engine.py:142（逐层目标头干预）。
