# ASTER 现成数据实验报告

本实验仅复用已有数据。主实验保留原 200 个节点、来源划分及种子 20261105，仅移除已登记的 7 条明确错误和 2 条有歧义的 C 变体。
共使用 1,290 个输入、1,053 个配对。拟合、开发、测试输入分别为 561、119、610 个；未新增病例、条件或标签。

固定配置：grid_11，能量目标 0.95，单类秩上限 4，夹角 45 度，51 个头，总编辑秩 120。
开发 C 只有 1 对；有 18 个配置在主指标和原输入准确率上并列。最终选择遵循预设的头数、总编辑秩和较大夹角规则，不能据此认定所选参数充分优于其他参数。
开发集选择的信号放大倍数为 1；输出层对照中选中的方法为 cad_direct。
